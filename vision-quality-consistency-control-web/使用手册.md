## 1. 系统介绍

视觉检测影像质量一致性管控系统是一套面向影像质量检测业务场景的专业管控平台，围绕影像采集、指标定义、检测任务执行、合格判定与不合格品处置的完整闭环流程，同时集成 AI 智能体调度能力，支持视觉检测、尺寸测量、缺陷识别等多类型智能体的统一接入与任务分发。

核心能力：

- 质量指标统一定义与状态管理（新增、编辑、启用/停用、删除）
- 标准模板管理（关联多个质量指标，适用于不同检测场景）
- 检测任务全生命周期管理（创建、开始、完成、取消）
- 检测记录提交与合格自动判定（超标自动生成不合格品记录）
- 不合格品处置流程（待处置→处置中→已处置/已忽略）
- 一致性分析与偏差报告（单任务分析 + 多任务对比）
- 趋势报表（合格率趋势、不合格类型分布、检测对象对比）
- 智能体注册、调度与状态监控
- 系统管理（用户、角色、菜单）

## 4. 质量管理

### 4.1 质量指标

功能说明：定义影像质量检测的各类指标，设定正常范围阈值，供标准模板引用。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 查询指标 | 查询 | 按指标名称、状态筛选指标列表。 |
| 新增指标 | 新增指标 | 填写指标名称、类型、单位、范围、重要性后保存。 |
| 编辑指标 | 编辑 | 修改指标配置信息。 |
| 启用/停用 | 启用 / 停用 | 切换指标的可用状态；停用后在模板中不可被新引用。 |
| 删除指标 | 删除 | 永久删除指标，操作前需二次确认。 |

指标类型说明：

- 数值型（NUMERIC）：需设置正常范围下限与上限，检测时按实测值自动判断是否超标。
- 等级型（GRADE）：按等级分类记录，不做数值范围校验。

重要性说明：

- 高（HIGH）
- 中（MEDIUM）
- 低（LOW）

操作结果：

指标维护完成，可在标准模板中关联使用。

### 4.3 检测任务

功能说明：管理影像质量检测任务的全生命周期，从创建到执行完成。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 查询任务 | 查询 | 按任务名称、状态筛选任务列表。 |
| 创建任务 | 创建任务 | 填写任务名称、检测对象、质量标准模板、影像数量、优先级、备注后提交。 |
| 开始任务 | 开始 | 将待执行任务切换为执行中状态。 |
| 完成任务 | 完成 | 将执行中任务标记为已完成。 |
| 取消任务 | 取消 | 取消待执行或执行中的任务，操作前需二次确认。 |
| 查看详情 | 详情 | 查看任务基础信息及该任务下的所有检测记录。 |

任务状态说明：

- 待执行（PENDING）：任务已创建，尚未开始。
- 执行中（RUNNING）：任务已开始，正在进行检测。
- 已完成（COMPLETED）：任务完成，可查看检测结果与合格率。
- 已取消（CANCELLED）：任务已取消，不再执行。

优先级说明：

- 高（HIGH）
- 中（MEDIUM）
- 低（LOW）

注意：

检测记录提交后，系统将自动对比实测值与指标范围，若任意指标超出阈值则判定为不合格，并自动生成不合格品记录。

操作结果：

任务执行完成后，可在任务详情中查看各影像的检测结果及整体合格率。

## 5. 不合格品管理

功能说明：展示所有自动识别或手动录入的不合格影像记录，支持处置流程跟踪与历史溯源。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 查询记录 | 查询 | 按处置状态筛选不合格品列表。 |
| 查看详情 | 详情 | 查看不合格品基础信息及处置历史时间轴。 |
| 填写处置 | 处置 | 为待处置或处置中的记录填写处置方案和结果说明。 |
| 忽略记录 | 忽略 | 将待处置记录标记为已忽略，操作前需二次确认。 |

处置状态说明：

- 待处置（PENDING）：系统自动生成，尚未处理。
- 处置中（DISPOSING）：已分配处置人员，正在处理。
- 已处置（DISPOSED）：处置完成。
- 已忽略（IGNORED）：主动忽略，不再跟踪。

处置方案说明：

- 重新采集（RECOLLECT）：重新进行影像采集。
- 参数调整（ADJUST）：调整检测参数或设备设置。
- 设备维护（MAINTAIN）：对采集设备进行检修。
- 接受（ACCEPT）：评估后接受该偏差，等同忽略。

操作结果：

不合格品处置全流程可追溯，处置状态实时更新。

## 9. 常见问题

### 9.1 登录后跳回登录页

排查建议：

- 检查后端服务是否可达（默认端口 19912）
- 检查 Token 是否失效，尝试重新登录
- 清空浏览器本地存储（localStorage）后重新登录

### 9.2 页面列表显示为空

排查建议：

- 检查后端接口是否正常返回（浏览器开发者工具 → Network）
- 确认数据库中是否存在对应数据
- 检查筛选条件是否过严，尝试清空后重新查询

### 9.3 检测记录提交后未生成不合格品

排查建议：

- 确认提交的实测值（measuredValues JSON）包含对应指标的测量数据
- 检查质量指标中该指标的 minValue / maxValue 是否已正确配置
- 查看后端日志确认是否存在异常

### 9.4 智能体无法调度

排查建议：

- 确认目标智能体状态不为离线（0），需先执行"上线"操作
- 检查是否已存在待调度的检测任务
- 查看接口响应是否返回权限不足错误

### 9.5 趋势报表图表无数据

排查建议：

- 确认所选时间范围内存在已完成的检测任务及检测记录
- 切换统计粒度（日/周/月）后重新查询
- 检查统计接口是否返回正常数据

### 9.6 页面提示无权限

排查建议：

- 检查当前用户角色是否具备对应菜单权限
- 检查角色菜单中是否已关联对应操作按钮权限节点
- 重新登录以刷新最新权限信息
