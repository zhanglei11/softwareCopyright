# 视觉检测影像质量一致性管控系统
## 软件需求文档 v1.0

---

## 一、系统概述

### 1.1 项目背景

在工业视觉检测场景中，多台相机、多条产线采集的影像质量往往存在差异，包括亮度不均、对比度偏差、分辨率不一致等问题。这些质量差异会直接影响缺陷检测算法的准确性与稳定性，导致误检、漏检。视觉检测影像质量一致性管控系统通过建立影像质量标准体系，对采集影像的质量进行自动化评估与一致性分析，帮助企业及时发现质量偏差并进行处置，保障视觉检测的可靠性。

### 1.2 系统目标

- 建立并维护影像质量标准指标体系
- 支持影像质量检测任务的创建与执行监控
- 提供一致性分析，定量评估与标准的偏差情况
- 记录和管理不合格影像，支持偏差处置跟踪
- 统计质量趋势，帮助管理层掌握质量动态
- 集成用户权限管理，实现多角色分级访问控制

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** vision-quality-consistency-control-web
- **后端仓库名：** vision-quality-consistency-control
- **开发库名：** vision_quality_consistency_control_dev

### 1.4 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 系统管理员 | 用户管理、权限配置、系统参数设置 |
| 质量标准工程师 | 定义质量标准指标，配置检测任务 |
| 检测操作员 | 执行检测任务，查看检测结果 |
| 管理人员 | 查看质量趋势统计，掌握一致性管控整体状态 |

### 1.5 运行环境

- **客户端**：PC Web 浏览器（Chrome 90+、Edge 90+）
- **操作系统**：Windows 10 及以上
- **分辨率**：1920×1080 及以上

## 三、基础管理模块

### 3.1 用户管理

#### 3.1.1 功能描述

系统管理员对平台用户账号进行全生命周期管理。

#### 3.1.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 用户列表 | 分页展示用户，支持按姓名、账号、角色、状态筛选 |
| 新增用户 | 填写姓名、账号、手机号、部门、初始密码，绑定角色 |
| 编辑用户 | 修改用户基本信息及关联角色 |
| 禁用/启用 | 切换账号状态，禁用后不可登录 |
| 重置密码 | 重置为系统默认初始密码 |
| 删除用户 | 逻辑删除，操作日志保留 |

#### 3.1.3 字段规则

- 登录账号：6~20 位字母数字，全局唯一
- 密码：8~20 位，须包含大小写字母与数字
- 手机号：11 位国内手机号格式校验

### 3.2 角色管理

| 功能项 | 描述 |
|--------|------|
| 角色列表 | 展示角色名称、标识、状态、关联用户数 |
| 新增角色 | 填写名称、标识、描述 |
| 角色授权 | 为角色分配菜单权限与按钮权限 |
| 删除角色 | 仅允许删除无绑定用户的角色 |

**内置角色：**

| 角色名称 | 标识 | 权限范围 |
|---------|------|---------|
| 超级管理员 | SUPER_ADMIN | 全部权限 |
| 质量标准工程师 | QUALITY_ENG | 质量标准、检测任务全权限 |
| 检测操作员 | OPERATOR | 检测任务执行、结果查看 |
| 管理人员 | MANAGER | 统计看板只读、报表导出 |

### 3.3 权限管理

采用 RBAC 模型，支持菜单级、按钮级权限控制。

| 权限层级 | 说明 |
|---------|------|
| 菜单权限 | 控制导航菜单的可见性 |
| 按钮权限 | 控制新增、编辑、删除、导出按钮的可见性 |

### 3.4 菜单管理

| 功能项 | 描述 |
|--------|------|
| 菜单树展示 | 树形展示目录、菜单、按钮节点 |
| 新增菜单 | 选择节点类型，填写名称、路径、图标、排序 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 仅可删除无子节点的叶子菜单 |

## 四、质量标准管理模块

### 4.1 质量指标定义

定义影像质量评估的度量指标，作为检测与一致性分析的基准。

| 字段 | 说明 |
|------|------|
| 指标编号 | 系统自动生成 |
| 指标名称 | 如：平均亮度、对比度、清晰度、噪点水平 |
| 指标类型 | 数值型 / 等级型 |
| 计量单位 | 如：灰度值、比率、无量纲 |
| 正常范围下限 | 数值型指标的合格下限 |
| 正常范围上限 | 数值型指标的合格上限 |
| 等级描述 | 等级型指标的各等级定义（优/良/差）|
| 重要性 | 高 / 中 / 低 |
| 备注 | 指标说明与测量方法 |

**功能：** 新增指标、编辑指标、停用指标（已被标准模板引用的指标不可删除）。

### 4.2 标准模板管理

将多个质量指标组合为一套标准模板，供检测任务引用。

| 字段 | 说明 |
|------|------|
| 模板编号 | 系统自动生成 |
| 模板名称 | 描述性名称 |
| 适用场景 | 如：产线 A、产品类型 B |
| 包含指标 | 从质量指标库中多选 |
| 状态 | 启用 / 停用 |
| 创建人 | 自动记录 |

**功能：** 新增模板、编辑模板（修改指标组合）、停用模板、查看模板详情（含各指标范围）。

## 五、检测任务管理模块

### 5.1 任务创建

创建影像质量检测任务，定义检测对象与标准。

| 字段 | 说明 |
|------|------|
| 任务编号 | 系统自动生成 |
| 任务名称 | 描述性名称 |
| 检测对象 | 待检测的影像来源（如：产线 A 相机、批次编号）|
| 质量标准模板 | 关联标准模板 |
| 影像数量 | 本次检测的影像文件数量 |
| 计划执行时间 | 任务预计开始时间 |
| 优先级 | 高 / 中 / 低 |
| 备注 | 任务说明 |
| 创建人 | 自动记录 |
| 状态 | 待执行 / 执行中 / 已完成 / 已取消 |

### 5.2 任务执行监控

实时查看正在执行的检测任务进度。

- 展示当前任务名称、执行状态、整体进度（百分比）
- 已检测数量 / 总数量
- 当前已发现的不合格数量（超出标准范围的影像数）
- 预计完成时间
- 支持手动终止任务

### 5.3 检测记录查询

查询历次检测任务的执行记录与汇总结果。

| 筛选条件 | 说明 |
|---------|------|
| 任务名称 | 模糊搜索 |
| 检测对象 | 模糊搜索 |
| 标准模板 | 下拉选择 |
| 执行时间 | 时间范围筛选 |
| 合格率范围 | 数值区间筛选 |

**列表字段：** 任务编号、任务名称、检测对象、标准模板、执行时间、检测总数、合格数、不合格数、合格率、操作

## 六、一致性分析模块

### 6.1 偏差分析报告

对检测任务结果生成一致性分析报告，量化影像质量与标准的偏差。

**报告内容：**

| 分析维度 | 说明 |
|---------|------|
| 各指标达标情况 | 每项质量指标的平均值及达标比例 |
| 偏差最大指标 | 偏差最大的 TOP3 指标 |
| 不合格影像占比 | 不合格影像数 / 总检测数 |
| 偏差分布直方图 | 各指标测量值分布可视化 |
| 改善建议 | 根据偏差情况给出文字说明 |

**功能：** 查看指定检测任务的偏差分析报告，导出 PDF 或 Excel。

### 6.2 多维度对比分析

支持跨时间段、跨检测对象的质量一致性对比。

- 选择 2 个或多个检测任务，对比各质量指标的平均值差异
- 同一检测对象不同时期的质量变化趋势图（折线图）
- 不同检测对象（相机/产线）同一指标的横向对比（柱状图）

## 七、不合格品管理模块

### 7.1 不合格品登记

记录在检测过程中发现的不合格影像信息。

| 字段 | 说明 |
|------|------|
| 不合格记录编号 | 系统自动生成 |
| 关联检测任务 | 来源任务编号 |
| 影像标识 | 影像文件名或编号 |
| 超标指标 | 哪些质量指标超出标准范围 |
| 超标值 | 各超标指标的实测值 |
| 标准范围 | 对应指标的合格范围 |
| 发现时间 | 自动记录 |
| 处置状态 | 待处置 / 处置中 / 已处置 / 已忽略 |

**功能：** 系统自动录入（检测任务完成时自动生成）、手动补录、查看详情、筛选查询。

### 7.2 处置跟踪

跟踪不合格品的处置过程与结果。

| 字段 | 说明 |
|------|------|
| 处置方案 | 重新采集 / 参数调整 / 设备维护 / 接受（忽略）|
| 处置人 | 关联系统用户 |
| 处置时间 | 操作时间 |
| 处置结果说明 | 处置过程与结果描述 |
| 验证状态 | 待验证 / 已验证合格 / 验证不合格 |

**功能：** 填写处置信息、更新处置状态、查看处置历史记录。

## 八、质量趋势统计模块

### 8.1 质量统计看板

| 指标卡片 | 说明 |
|---------|------|
| 本月检测总数 | 当月累计检测影像数量 |
| 本月合格率 | 当月整体合格比例 |
| 本月不合格数 | 当月不合格影像数量 |
| 本月处置完成率 | 已处置不合格品 / 总不合格品 |
| 各质量指标达标率 | 雷达图展示各指标达标情况 |
| 近 30 天合格率趋势 | 折线图，按日展示 |

### 8.2 趋势报表分析

| 报表类型 | 说明 |
|---------|------|
| 合格率趋势报表 | 按日/周/月统计合格率变化 |
| 不合格类型分布 | 按超标指标分类统计不合格影像数量 |
| 检测对象质量对比 | 各产线/相机合格率横向对比 |
| 处置效率报表 | 不合格品从发现到处置的平均时长 |

**功能：** 选择时间范围、按检测对象或标准模板筛选，查看图表，导出 Excel。
