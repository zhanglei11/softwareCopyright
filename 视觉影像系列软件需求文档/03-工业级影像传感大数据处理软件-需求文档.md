# 多场景影像传感设备资源协同调度系统
## 软件需求文档 v1.0

---

## 一、系统概述

### 1.1 项目背景

工业生产环境中，影像传感设备持续产生海量图像与视频数据，涵盖质量检测、设备监控、流程记录等多个场景。这些数据体量庞大、格式多样，单靠人工或传统工具难以高效处理。多场景影像传感设备资源协同调度系统提供数据接入、存储、加工、分析的一体化管理平台，帮助工业企业构建影像数据资产体系，释放数据价值。

### 1.2 系统目标

- 统一接入和管理来自多类型影像传感设备的数据
- 支持数据处理任务的配置、执行与结果管理
- 提供数据存储空间管理，掌握数据资产规模
- 提供数据统计分析功能，可视化数据全貌
- 集成用户权限管理，实现多角色分级访问控制

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** industrial-imaging-data-platform-web
- **后端仓库名：** industrial-imaging-data-platform
- **开发库名：** industrial_imaging_data_platform_dev

### 1.4 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 系统管理员 | 用户管理、权限配置、系统参数设置 |
| 数据工程师 | 数据源配置、处理任务管理、结果查看 |
| 业务分析师 | 数据查询、报表查看、数据导出 |
| 管理人员 | 查看数据统计看板、掌握数据资产概况 |

### 1.5 运行环境

- **客户端**：PC Web 浏览器（Chrome 90+、Edge 90+）
- **操作系统**：Windows 10 及以上
- **分辨率**：1920×1080 及以上

## 三、基础管理模块

### 3.1 用户管理

#### 3.1.1 功能描述

系统管理员对平台用户账号进行全生命周期管理。

#### 3.1.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 用户列表 | 分页展示用户，支持按姓名、账号、角色、状态筛选 |
| 新增用户 | 填写姓名、账号、手机号、部门、初始密码，绑定角色 |
| 编辑用户 | 修改用户基本信息及关联角色 |
| 禁用/启用 | 切换账号状态，禁用后不可登录 |
| 重置密码 | 重置为系统默认初始密码 |
| 删除用户 | 逻辑删除，操作日志保留 |

#### 3.1.3 字段规则

- 登录账号：6~20 位字母数字，全局唯一
- 密码：8~20 位，须包含大小写字母与数字
- 手机号：11 位国内手机号格式校验

### 3.2 角色管理

| 功能项 | 描述 |
|--------|------|
| 角色列表 | 展示角色名称、标识、状态、关联用户数 |
| 新增角色 | 填写名称、标识、描述，设置状态 |
| 角色授权 | 为角色分配菜单权限与按钮权限 |
| 删除角色 | 仅允许删除无绑定用户的角色 |

**内置角色：**

| 角色名称 | 标识 | 权限范围 |
|---------|------|---------|
| 超级管理员 | SUPER_ADMIN | 全部权限 |
| 数据工程师 | DATA_ENG | 数据源、接入、处理任务全权限 |
| 业务分析师 | ANALYST | 数据查询、报表查看、导出 |
| 管理人员 | MANAGER | 看板只读权限 |

### 3.3 权限管理

采用 RBAC 模型，支持菜单级、按钮级权限控制。

| 权限层级 | 说明 |
|---------|------|
| 菜单权限 | 控制导航菜单的可见性 |
| 按钮权限 | 控制新增、编辑、删除、导出操作按钮的可见性 |

### 3.4 菜单管理

| 功能项 | 描述 |
|--------|------|
| 菜单树展示 | 树形展示目录、菜单、按钮节点 |
| 新增菜单 | 选择节点类型，填写名称、路径、图标、排序 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 仅可删除无子节点的叶子菜单 |

## 四、数据源管理模块

### 4.1 数据源配置

配置影像传感设备或存储系统作为数据来源，支持多种接入方式。

| 字段 | 说明 |
|------|------|
| 数据源编号 | 系统自动生成 |
| 数据源名称 | 显示名称 |
| 数据源类型 | 设备直连 / 文件服务器 / 数据库 / 对象存储 |
| 连接地址 | IP 地址或 URL |
| 端口 | 连接端口号 |
| 认证方式 | 无认证 / 账号密码 / 密钥 |
| 数据格式 | JPEG / PNG / RAW / MP4 / 其他 |
| 负责人 | 关联系统用户 |
| 状态 | 启用 / 停用 |
| 备注 | 描述信息 |

**功能：** 新增数据源、编辑数据源、停用数据源、连通性测试（测试能否成功建立连接）。

### 4.2 连接状态监控

- 实时展示所有数据源的连接状态（正常 / 异常 / 未知）
- 展示最近一次连通性测试结果与时间
- 异常数据源高亮显示，提供快速定位入口

## 五、数据接入管理模块

### 5.1 接入任务配置

定义从数据源抓取数据的接入任务。

| 字段 | 说明 |
|------|------|
| 任务名称 | 描述性名称 |
| 数据源 | 关联数据源 |
| 接入方式 | 实时接入 / 定时接入 |
| 调度周期 | 定时接入时设置，如每小时、每日固定时间 |
| 数据过滤条件 | 时间范围、文件类型、文件名规则 |
| 存储目录 | 数据写入的目标目录 |
| 状态 | 启用 / 停用 |

**功能：** 新增接入任务、编辑任务、启用/停用任务、手动触发执行。

### 5.2 接入记录查询

查询每次接入任务的执行情况。

| 字段 | 说明 |
|------|------|
| 记录编号 | 自动生成 |
| 任务名称 | 关联接入任务 |
| 执行时间 | 开始时间 |
| 完成时间 | 结束时间 |
| 接入数量 | 本次接入文件数 |
| 数据大小 | 本次接入数据总大小 |
| 执行状态 | 成功 / 失败 / 部分成功 |
| 失败原因 | 异常时展示错误说明 |

**功能：** 按任务名称、时间范围、执行状态筛选查询，查看记录详情，支持导出 Excel。

## 六、数据处理管理模块

### 6.1 处理任务配置

定义对已接入数据执行的处理加工逻辑。

| 字段 | 说明 |
|------|------|
| 任务名称 | 描述性名称 |
| 输入数据目录 | 待处理数据所在目录 |
| 处理类型 | 图像压缩 / 格式转换 / 分辨率调整 / 批量重命名 / 质量过滤 |
| 处理参数 | 根据处理类型展示对应参数配置项 |
| 输出目录 | 处理结果写入目录 |
| 执行方式 | 手动触发 / 定时执行 |
| 调度周期 | 定时执行时配置 |
| 状态 | 启用 / 停用 |

**处理类型参数说明：**

| 处理类型 | 参数 |
|---------|------|
| 图像压缩 | 压缩质量（0~100） |
| 格式转换 | 目标格式（JPEG/PNG/BMP） |
| 分辨率调整 | 目标宽度、目标高度（像素） |
| 批量重命名 | 命名规则（日期+序号等模板） |
| 质量过滤 | 最小文件大小阈值（KB），过滤无效图像 |

### 6.2 任务执行监控

实时监控当前正在执行的处理任务。

- 展示任务名称、执行状态、处理进度（百分比）
- 已处理文件数 / 总文件数
- 预计完成时间
- 支持手动终止正在执行的任务

### 6.3 处理结果查看

查询每次处理任务的执行结果。

| 字段 | 说明 |
|------|------|
| 执行编号 | 自动生成 |
| 任务名称 | 关联处理任务 |
| 执行时间 | 开始时间 |
| 完成时间 | 结束时间 |
| 处理文件总数 | 本次处理文件数量 |
| 成功数量 | 处理成功文件数 |
| 失败数量 | 处理失败文件数 |
| 执行状态 | 完成 / 失败 / 已终止 |
| 输出大小 | 处理结果总大小 |

**功能：** 按任务、时间范围、状态筛选，查看详情（含失败文件清单），导出 Excel。

## 七、数据存储管理模块

### 7.1 存储空间统计

展示系统整体存储资源使用情况。

| 指标 | 说明 |
|------|------|
| 总存储容量 | 系统配置的存储总量 |
| 已用空间 | 当前已使用存储量 |
| 可用空间 | 剩余可用存储量 |
| 使用率 | 已用 / 总量百分比，进度条展示 |
| 各目录占用大小 | 按目录分组展示存储占用 |

### 7.2 数据清理管理

配置和执行数据清理策略，防止存储空间耗尽。

| 字段 | 说明 |
|------|------|
| 清理规则名称 | 描述性名称 |
| 目标目录 | 清理的数据目录 |
| 清理条件 | 超过 N 天未访问 / 早于某日期 / 文件大小大于 N MB |
| 执行方式 | 手动执行 / 定时执行 |
| 清理后操作 | 永久删除 / 移动到归档目录 |
| 状态 | 启用 / 停用 |

**功能：** 新增清理规则、编辑规则、手动触发清理（需确认操作）、查看清理日志。

## 八、统计分析模块

### 8.1 数据总览看板

| 指标卡片 | 说明 |
|---------|------|
| 数据源总数 | 已配置的数据源数量 |
| 今日接入量 | 今日接入文件数与数据大小 |
| 今日处理量 | 今日处理任务执行文件数 |
| 存储使用率 | 当前存储使用百分比 |
| 近 30 天接入量趋势 | 折线图，按日展示 |
| 处理任务成功率 | 近 30 天处理任务成功率折线图 |

### 8.2 处理任务统计

| 指标 | 说明 |
|------|------|
| 任务总执行次数 | 指定周期内执行次数 |
| 成功率 | 成功执行次数 / 总执行次数 |
| 各类处理类型分布 | 饼图 |
| 各任务执行频次排行 | 柱状图 |

### 8.3 数据趋势分析

- 按时间段（日/周/月）查看接入数据量变化趋势
- 按数据源查看各来源数据贡献比例
- 按文件类型统计数据分布

## 九、非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 ≤ 3 秒；大批量任务列表查询 ≤ 3 秒 |
| 安全 | JWT 认证、操作日志全量记录、敏感配置（密码/密钥）加密存储 |
| 可用性 | 系统可用率 ≥ 99%；批量操作前提供操作确认弹窗 |
| 兼容性 | 支持 Chrome、Edge 主流版本 |
| 数据 | 接入与处理记录保留 1 年；存储数据保留策略由用户自定义 |
