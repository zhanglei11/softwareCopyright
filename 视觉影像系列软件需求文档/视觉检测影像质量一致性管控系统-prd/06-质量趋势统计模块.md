# 质量趋势统计模块 PRD

> 所属系统：视觉检测影像质量一致性管控系统
> 文档版本：V1.0 | 创建日期：2026-05-26

---

## 一、模块概述

质量趋势统计模块为管理层和质量工程师提供可视化的质量动态看板与趋势报表，支持多维度筛选、图表展示和数据导出，帮助掌握整体质量管控状态。

---

## 二、功能清单

| 功能点 | 优先级 | 说明 | 涉及角色 |
|--------|--------|------|----------|
| 质量统计看板 | P0 | 关键指标卡片 + 雷达图 + 合格率趋势折线图 | 全部角色 |
| 合格率趋势报表 | P0 | 按日/周/月统计合格率变化 | QUALITY_ENG, MANAGER |
| 不合格类型分布 | P0 | 按超标指标分类统计不合格数量 | QUALITY_ENG, MANAGER |
| 检测对象质量对比 | P0 | 各产线/相机合格率横向对比 | QUALITY_ENG, MANAGER |
| 处置效率报表 | P1 | 不合格品从发现到处置的平均时长 | QUALITY_ENG, MANAGER |
| 报表导出 | P1 | 导出 Excel | QUALITY_ENG, MANAGER |

## 三、质量统计看板说明

### 3.1 指标卡片

| 卡片名称 | 计算口径 | 刷新频率 |
|---------|---------|---------|
| 本月检测总数 | 当月所有任务累计检测影像数 | 实时 |
| 本月合格率 | 当月所有合格数 / 总检测数 | 实时 |
| 本月不合格数 | 当月所有不合格影像数量 | 实时 |
| 本月处置完成率 | 当月（已处置+已忽略）/ 总不合格数 | 实时 |

### 3.2 各质量指标达标率雷达图

- 以各质量指标名称为雷达图维度
- 展示当月整体达标率（0%~100%）
- 支持按检测对象或标准模板筛选

### 3.3 近 30 天合格率趋势折线图

- X 轴：近 30 天日期
- Y 轴：合格率（%）
- 支持按检测对象筛选

## 四、趋势报表分析说明

### 4.1 合格率趋势报表

| 维度 | 说明 |
|------|------|
| 时间粒度 | 按日 / 周 / 月 |
| 筛选条件 | 时间范围 + 检测对象（可选）+ 标准模板（可选）|
| 图表 | 折线图 |
| 表格字段 | 日期、检测总数、合格数、不合格数、合格率 |

### 4.2 不合格类型分布

| 维度 | 说明 |
|------|------|
| 分类依据 | 按超标指标分类 |
| 筛选条件 | 时间范围 + 检测对象（可选）|
| 图表 | 柱状图 / 饼图 |
| 表格字段 | 指标名称、不合格影像数、占比 |

### 4.3 检测对象质量对比

| 维度 | 说明 |
|------|------|
| X 轴 | 各检测对象（产线/相机）|
| Y 轴 | 合格率 |
| 筛选条件 | 时间范围 + 标准模板（可选）|
| 图表 | 柱状图 |

### 4.4 处置效率报表

| 字段 | 说明 |
|------|------|
| 平均处置时长 | 从不合格品发现到首次处置的平均时长（小时）|
| 平均验证时长 | 从处置完成到验证通过的平均时长（小时）|
| 处置完成率 | 已处置 / 总不合格数 |
| 逾期未处置数 | 超过 48 小时未处置的不合格品数量 |

## 五、接口设计

### 5.1 质量统计看板接口

#### 获取看板概览数据

```
GET /api/v1/stats/overview?detectionTarget=&templateId=
Authorization: Bearer {token}

Query 参数：
- detectionTarget  string  否  检测对象筛选
- templateId       long    否  标准模板筛选

响应：
{
  "code": 200,
  "data": {
    "monthTotalCount": 12500,
    "monthQualifiedRate": 97.2,
    "monthUnqualifiedCount": 350,
    "monthDisposeCompletionRate": 88.5,
    "metricRadar": [
      { "metricName": "平均亮度", "qualifiedRate": 98.5 },
      { "metricName": "对比度", "qualifiedRate": 95.2 },
      { "metricName": "清晰度", "qualifiedRate": 96.8 },
      { "metricName": "噪点水平", "qualifiedRate": 91.3 }
    ]
  }
}
```

#### 获取近 30 天合格率趋势

```
GET /api/v1/stats/trend/daily?detectionTarget=&templateId=
Authorization: Bearer {token}

响应：
{
  "code": 200,
  "data": [
    { "date": "2026-04-27", "totalCount": 420, "qualifiedRate": 97.8 },
    { "date": "2026-04-28", "totalCount": 380, "qualifiedRate": 96.1 },
    { "date": "2026-05-26", "totalCount": 510, "qualifiedRate": 97.6 }
  ]
}
```

### 5.2 趋势报表接口

#### 合格率趋势报表

```
GET /api/v1/stats/trend?startDate=&endDate=&granularity=day&detectionTarget=&templateId=
Authorization: Bearer {token}

Query 参数：
- startDate        string  是  开始日期 yyyy-MM-dd
- endDate          string  是  结束日期 yyyy-MM-dd
- granularity      string  否  day/week/month，默认 day
- detectionTarget  string  否  检测对象筛选
- templateId       long    否  标准模板筛选

响应：
{
  "code": 200,
  "data": {
    "summary": {
      "totalCount": 52300,
      "qualifiedCount": 50750,
      "unqualifiedCount": 1550,
      "avgQualifiedRate": 97.0
    },
    "series": [
      {
        "date": "2026-05-01",
        "totalCount": 1800,
        "qualifiedCount": 1755,
        "unqualifiedCount": 45,
        "qualifiedRate": 97.5
      }
    ]
  }
}
```

```
  Content-Disposition: attachment; filename="quality-report-{type}-{date}.xlsx"
```

## 七、异常流程

| 异常场景 | 触发条件 | 处理方式 | 用户提示 |
|----------|----------|----------|----------|
| 时间范围过大 | 查询跨度超过 1 年 | 返回 400 | "查询时间范围不可超过 1 年" |
| 无数据 | 指定条件下无检测记录 | 返回空列表，不报错 | 图表显示"暂无数据" |
| 导出超时 | 数据量过大 | 后台异步生成，通知下载 | "报表生成中，完成后自动下载" |
