# 产线智能视觉缺陷分类与追溯管理系统
## 软件需求文档 v1.0

---

## 一、系统概述

### 1.1 项目背景

在工业制造领域，产品外观质量直接影响品牌形象与客户满意度。传统人工目检方式效率低、漏检率高、主观性强，难以满足现代化产线高速、高精度检测需求。产线智能视觉缺陷分类与追溯管理系统通过对视觉检测数据的结构化管理，实现缺陷的自动分类记录、多维度统计分析与全链路追溯，帮助企业快速定位质量问题根源，持续优化生产工艺。

### 1.2 系统目标

- 对产线采集的缺陷影像数据进行统一管理与分类记录
- 支持按产线、产品型号、班次、时间维度进行缺陷追溯查询
- 提供缺陷统计报表与趋势分析，辅助质量管理决策
- 构建标准化缺陷标签体系，支持自定义缺陷分类
- 集成用户权限管理，实现多角色分级访问控制

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** vision-defect-traceability-web
- **后端仓库名：** vision-defect-traceability
- **开发库名：** vision_defect_traceability_dev

### 1.4 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 系统管理员 | 用户管理、权限配置、系统参数设置 |
| 质量工程师 | 缺陷分类配置、追溯查询、报表导出 |
| 产线操作员 | 查看本产线缺陷记录、上报异常 |
| 管理人员 | 查看统计看板、导出报告 |

### 1.5 运行环境

- **客户端**：PC Web 浏览器（Chrome 90+、Edge 90+）
- **操作系统**：Windows 10 及以上
- **分辨率**：1920×1080 及以上

## 三、基础管理模块

### 3.1 用户管理

#### 3.1.1 功能描述

系统管理员对平台用户账号进行全生命周期管理，包括新增、编辑、禁用、重置密码等操作。

#### 3.1.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 用户列表 | 分页展示所有用户，支持按姓名、账号、状态筛选 |
| 新增用户 | 填写用户姓名、登录账号、手机号、所属部门、初始密码，关联角色 |
| 编辑用户 | 修改用户基本信息及关联角色 |
| 禁用/启用 | 切换用户账号状态，禁用后不可登录 |
| 重置密码 | 管理员将用户密码重置为初始默认密码 |
| 删除用户 | 逻辑删除用户账号，历史操作记录保留 |

#### 3.1.3 字段规则

- 登录账号：6~20 位字母数字，全局唯一，创建后不可修改
- 密码：8~20 位，须包含大小写字母与数字
- 手机号：11 位国内手机号格式校验

### 3.2 角色管理

#### 3.2.1 功能描述

定义系统内的角色类型，并为角色分配菜单权限与数据权限。

#### 3.2.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 角色列表 | 展示所有角色名称、标识、状态及关联用户数 |
| 新增角色 | 填写角色名称、标识、描述，设置状态 |
| 编辑角色 | 修改角色基本信息 |
| 角色授权 | 为角色分配可访问的菜单及按钮权限 |
| 删除角色 | 仅允许删除无绑定用户的角色 |

#### 3.2.3 内置角色

| 角色名称 | 标识 | 说明 |
|---------|------|------|
| 超级管理员 | SUPER_ADMIN | 拥有全部权限，不可删除 |
| 质量工程师 | QUALITY_ENG | 可配置缺陷分类、查看全产线数据 |
| 产线操作员 | LINE_OPERATOR | 仅可查看本产线相关数据 |
| 管理人员 | MANAGER | 只读权限，可查看统计看板与导出报告 |

### 3.3 权限管理

#### 3.3.1 功能描述

采用 RBAC（基于角色的访问控制）模型，通过角色关联菜单与操作权限。

#### 3.3.2 权限粒度

| 权限层级 | 说明 |
|---------|------|
| 菜单权限 | 控制导航菜单的可见性 |
| 按钮权限 | 控制页面内操作按钮（新增、编辑、删除、导出）的可见性 |
| 数据权限 | 产线操作员只能查看其归属产线的数据 |

### 3.4 菜单管理

#### 3.4.1 功能描述

维护系统导航菜单的树形结构，支持目录、菜单、按钮三种节点类型。

#### 3.4.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 菜单树展示 | 树形结构展示所有菜单节点 |
| 新增菜单 | 选择节点类型（目录/菜单/按钮），填写名称、路径、图标、排序 |
| 编辑菜单 | 修改菜单基本信息 |
| 删除菜单 | 仅允许删除无子节点的叶子节点 |
| 显示/隐藏 | 控制菜单是否在导航栏显示 |

## 五、缺陷管理模块

### 5.1 缺陷分类配置

支持管理员自定义缺陷类别，构建标准化缺陷标签体系。

| 字段 | 说明 |
|------|------|
| 缺陷编码 | 如 DEF-001 |
| 缺陷名称 | 如划痕、凹坑、色差、毛刺 |
| 缺陷级别 | 致命 / 严重 / 一般 |
| 缺陷描述 | 文字说明 |
| 示例图片 | 上传参考图片（最多 5 张） |
| 状态 | 启用 / 停用 |

### 5.2 缺陷记录查询

展示所有缺陷检测记录，支持多条件组合筛选。

**筛选条件：**
- 产线、产品型号、缺陷类型、缺陷级别
- 检测时间范围
- 检测结果（合格 / 不合格）
- 班次

**列表字段：** 记录编号、产品序列号、产线、产品型号、缺陷类型、缺陷级别、检测时间、班次、处置状态

**操作：** 查看详情、导出 Excel

### 5.3 缺陷影像浏览

- 查看缺陷记录关联的原始影像
- 支持影像缩放、平移
- 展示缺陷标注区域（矩形框标注）
- 支持按日期、产线批量浏览

## 六、追溯管理模块

### 6.1 批次追溯

根据生产批次号查询该批次内所有产品的检测结果与缺陷分布。

**查询输入：** 批次号、生产日期范围、产线

**输出信息：**
- 批次总产量、合格率、缺陷数量统计
- 各类缺陷分布饼图
- 该批次详细检测记录列表

### 6.2 产品追溯

根据单个产品的序列号查询其完整检测历史。

**查询输入：** 产品序列号

**输出信息：**
- 产品基本信息（型号、生产时间、所属批次、产线）
- 全部检测节点记录
- 缺陷影像列表
- 最终处置结论

## 七、统计报表模块

### 7.1 缺陷统计看板

首页看板展示核心质量指标：

| 指标卡片 | 说明 |
|---------|------|
| 今日检测总量 | 当日检测产品件数 |
| 今日合格率 | 当日合格品比例 |
| 今日缺陷总数 | 按缺陷记录条数统计 |
| 本月合格率趋势 | 折线图，按日展示 |
| 缺陷类型分布 | 饼图，展示各类缺陷占比 |
| 各产线缺陷对比 | 柱状图，各产线缺陷数量对比 |

### 7.2 趋势分析

- 按时间段（日/周/月）查看合格率趋势
- 按产线查看缺陷数量变化趋势
- 按缺陷类型查看发生频率趋势

### 7.3 报表导出

- 支持导出 Excel 格式的缺陷明细报表
- 支持导出 PDF 格式的质量分析报告
- 支持自定义导出时间范围和产线范围

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载时间 ≤ 3 秒；列表查询响应时间 ≤ 2 秒 |
