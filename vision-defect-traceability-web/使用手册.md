## 1. 系统介绍

产线智能视觉缺陷分类与追溯管理系统是一套面向工业生产线视觉检测业务场景的专业管理平台，围绕缺陷检测记录入库、缺陷分类维护、产线与产品型号管理、告警规则配置、统计趋势分析及批次全链路追溯的完整闭环流程，支持对各产线检测结果的集中管控与数据驱动决策。

核心能力：

- 缺陷记录统一管理（检测结果查询、缺陷处置流转）
- 缺陷分类体系维护（等级划分、编码管理）
- 产线信息管理（产线档案、产品型号绑定）
- 告警规则配置（合格率预警、缺陷数超量预警、统计周期与等级设定）
- 告警记录跟踪（告警内容查阅、处理说明登记）
- 统计报表（检测数量与合格率趋势折线图、双轴对比）
- 批次追溯查询（按批次号全链路追溯检测明细）
- 系统管理（用户、角色）

## 4. 缺陷管理

### 4.1 缺陷记录

功能说明：统一查看所有产线的视觉检测记录，支持按批次号、序列号、检测结果、处置状态多维筛选，并提供缺陷处置流转功能。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 查询记录 | 搜索 | 按批次号、序列号、检测结果、处置状态筛选列表。 |
| 重置筛选 | 重置 | 清空筛选条件并刷新列表。 |
| 查看详情 | 详情 | 查看该条检测记录的完整信息。 |
| 处置缺陷 | 处置 | 对检测结果为不合格且尚未处置的记录填写处置说明，提交后更新处置状态为已处置。 |

列表字段说明：

| 字段 | 说明 |
| --- | --- |
| 序列号 | 单个产品的唯一编号 |
| 批次号 | 所属生产批次编号 |
| 产线 | 检测所在产线名称 |
| 产品型号 | 所属产品型号 |
| 缺陷分类 | 识别出的缺陷类型（如划痕、裂纹等） |
| 缺陷等级 | 轻微 / 一般 / 严重 |
| 检测结果 | 合格（绿色）/ 不合格（红色） |
| 班次 | 检测所在班次（A/B/C 班） |
| 检测时间 | 视觉检测完成时间 |
| 处置状态 | 待处置（橙色）/ 已处置（绿色） |

处置状态说明：

- 待处置：检测结果为不合格，尚未完成处置登记。
- 已处置：已填写处置说明，完成问题闭环。

注意：

检测结果为合格的记录不显示"处置"按钮；已处置的记录处置按钮不再出现。

操作结果：

缺陷处置说明提交成功，记录状态实时更新为已处置。

### 4.2 缺陷分类

功能说明：维护系统内缺陷类型的分类体系，包括名称、编码、等级，供检测记录关联使用。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 新增分类 | 新增 | 填写分类名称、分类编码（如 DEF-SCRATCH）、缺陷等级、描述后保存。 |
| 编辑分类 | 编辑 | 修改分类名称、编码、等级、描述及启用状态。 |
| 删除分类 | 删除 | 删除不再使用的缺陷分类，操作前需二次确认。 |

缺陷等级说明：

- 轻微（1）：对产品功能影响较小，可在线处理或接受。
- 一般（2）：对产品质量有一定影响，需安排处置。
- 严重（3）：对产品功能有重大影响，需立即停线排查。

状态说明：

- 启用（绿色）：该分类可在检测记录中正常引用。
- 禁用（灰色）：该分类已停用，不影响历史记录显示。

操作结果：

分类体系更新完成，新建检测记录时可按更新后的分类归类。

## 6. 告警管理

### 6.1 告警规则

功能说明：配置产线的质量预警条件，系统将按规则自动触发告警并生成告警记录，便于及时发现产线质量异常。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 新增规则 | 新增 | 配置告警规则（规则名称、产线、触发条件、阈值、统计周期、告警等级）后保存。 |
| 编辑规则 | 编辑 | 修改规则配置参数及启用状态。 |
| 删除规则 | 删除 | 删除不再使用的告警规则，操作前需二次确认。 |
| 启用/禁用 | 开关 | 快速切换规则的启用状态，禁用后该规则不再触发告警。 |

告警规则配置说明：

| 配置项 | 说明 |
| --- | --- |
| 规则名称 | 告警规则的描述性名称 |
| 产线 | 该规则监控的目标产线（下拉选择） |
| 触发条件 | 合格率低于阈值 / 缺陷数超过阈值（二选一） |
| 阈值 | 触发告警的临界值（合格率填 0~1 小数，缺陷数填整数） |
| 统计周期 | 1小时 / 4小时 / 8小时（统计窗口大小） |
| 告警等级 | 低（蓝色）/ 中（橙色）/ 高（红色） |

操作结果：

规则配置保存后生效，满足触发条件时将自动生成告警记录。

【图片位置：图6-2 新增/编辑告警规则弹窗】

### 6.2 告警记录

功能说明：查看系统自动触发的所有告警事件，并对待处理告警进行处理确认，完成质量问题的闭环跟踪。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 查看记录 | - | 列表展示全部告警记录，按告警时间倒序排列，支持分页浏览。 |
| 处理告警 | 处理 | 对待处理状态的告警填写处理说明后提交，告警状态更新为已处理。 |

列表字段说明：

| 字段 | 说明 |
| --- | --- |
| 告警规则 | 触发本次告警的规则名称 |
| 告警内容 | 告警的具体描述，如"A1号产线合格率下降至72.3%，低于预警阈值80%" |
| 告警等级 | 低 / 中 / 高（对应蓝色/橙色/红色标签） |
| 处理状态 | 待处理（橙色）/ 已处理（绿色） |
| 产线 | 告警所属产线 |
| 告警时间 | 告警触发的时间 |

处理状态说明：

- 待处理：告警已触发，尚未完成人工确认处理。
- 已处理：操作人员已填写处理说明，完成闭环。

注意：

已处理的告警记录不再显示"处理"按钮，仅供历史查阅。

操作结果：

告警处理说明提交成功，记录状态实时更新为已处理。

## 7. 统计报表

功能说明：按指定日期范围对产线检测数据进行汇总统计，以折线图形式直观展示检测数量与合格率的双轴趋势，辅助质量管理分析与决策。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 设置日期范围 | 开始日期 / 结束日期 | 点击日期选择器选择查询的起止日期。 |
| 查询数据 | 查询 | 按所选日期范围刷新报表数据与图表。 |

报表内容：

| 指标 | 说明 |
| --- | --- |
| 检测总数 | 所选时间范围内全部检测记录的数量 |
| 平均合格率（%） | 所选时间范围内所有记录的合格率均值 |
| 趋势折线图 | 双轴图，左轴为每日检测数量，右轴为每日合格率（%），二者叠加展示 |

趋势图说明：

- 蓝色折线（检测数量）：反映产线日产量或检测投入量。
- 橙色折线（合格率）：反映每日产品质量水平，低于预警阈值的日期可在对应日期的告警记录中查询。

注意：

开始日期与结束日期均为必填项，不填写时点击查询无效。

操作结果：

报表数据加载完成，可根据趋势图快速识别质量波动节点。

## 8. 追溯查询

功能说明：根据生产批次号，全量追溯该批次内所有产品的视觉检测情况，输出批次汇总指标与逐条检测明细，为质量追溯和客户投诉处理提供完整数据依据。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 输入批次号 | - | 在输入框中填写完整批次号（如 B20260528），也可按 Enter 直接触发查询。 |
| 查询批次 | 查询 | 根据批次号检索该批次全部检测记录并汇总统计。 |

查询结果说明：

**批次汇总信息：**

| 字段 | 说明 |
| --- | --- |
| 批次号 | 查询的批次编号 |
| 产线 | 该批次所在产线 |
| 检测总数 | 该批次参与检测的产品总数 |
| 合格数 | 检测结果为合格的数量 |
| 缺陷数 | 检测结果为不合格的数量 |
| 合格率 | 合格数 / 检测总数 × 100%（保留一位小数） |

**检测明细列表：**

| 字段 | 说明 |
| --- | --- |
| 序列号 | 单个产品唯一编号 |
| 产品型号 | 该产品所属型号 |
| 缺陷分类 | 识别出的缺陷类型（合格品为空） |
| 检测结果 | 合格 / 不合格 |
| 检测时间 | 视觉检测完成时间 |

注意：

批次号为必填项，输入后点击"查询"或按回车键均可触发查询。若批次号不存在则提示无结果。

操作结果：

批次内所有检测记录展示完毕，可结合缺陷分类与序列号进行逐条问题定位。

## 9. 系统管理

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 新增用户 | 新增 | 填写登录账号、真实姓名、手机号、部门、登录密码（至少8位）、角色、状态后保存。 |

新增和编辑用户时均需为用户分配一个或多个角色，角色决定用户可访问的功能菜单范围。

注意：

登录账号（用户名）在新增时填写后不可再次修改，请确认后保存。

### 9.2 角色管理

功能说明：维护系统角色信息，角色用于对用户进行权限分组，统一控制功能访问范围。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 新增角色 | 新增 | 填写角色名称、角色标识（如 operator、viewer）、描述后保存。 |
| 编辑角色 | 编辑 | 修改角色名称、描述及状态。 |
| 删除角色 | 删除 | 删除不再使用的角色，操作前需二次确认。 |

角色状态说明：

- 正常（绿色）：角色有效，可分配给用户。
- 禁用（红色）：角色已停用，不可分配给新用户，已分配的用户权限同步受限。

角色标识说明：

角色标识（roleKey）为系统内部识别角色的唯一编码，建议使用英文小写，如 `admin`、`operator`、`viewer`，创建后请勿随意修改。

操作结果：

角色信息维护完成，在用户管理中可为用户分配对应角色。

## 10. 常见问题

### 10.1 登录后跳回登录页

排查建议：

- 检查后端服务是否可达（默认端口 19916）
- 检查 Token 是否失效，尝试重新登录
- 清空浏览器本地存储（localStorage 中的 `vision_token` 字段）后重新登录

### 10.2 首页仪表盘统计数据为 0

排查建议：

- 确认数据库 `defect_record` 表中存在 `detect_time` 为今日的检测记录
- 检查后端 `/api/v1/stats/dashboard` 接口是否正常返回（浏览器开发者工具 → Network）
- 确认后端服务正在运行（日志路径：`vision-defect-traceability/logs/app.log`）

### 10.3 缺陷记录列表为空

排查建议：

- 检查筛选条件是否过严，点击"重置"后重新查询
- 确认数据库中是否存在检测记录数据
- 查看浏览器控制台是否有接口报错

### 10.4 告警记录页面报错 500

排查建议：

- 检查 `alert_record` 表中 `handle_by` 字段是否存储了字符串（如 'admin'），该字段应为数字类型（用户 ID）
- 执行 SQL：`UPDATE alert_record SET handle_by = '1' WHERE handle_by = 'admin';` 修复存量数据

### 10.5 统计报表图表不显示

排查建议：

- 确认已填写"开始日期"和"结束日期"，二者均为必填项
- 确认所选日期范围内有检测记录数据
- 检查 `/api/v1/stats/trend` 接口是否返回正常数据

### 10.6 追溯查询无结果

排查建议：

- 确认输入的批次号格式正确（如 B20260528），注意大写字母和日期格式
- 确认该批次号在 `defect_record` 表中确实存在对应记录
- 若批次号存在但仍无结果，检查后端 `/api/v1/trace/batch` 接口响应

### 10.7 告警规则产线下拉为空

排查建议：

- 前往"产线管理 → 产线信息"，确认已维护产线数据且状态为启用
- 检查 `/api/v1/lines` 接口是否正常返回产线列表

### 10.8 新增用户时提示"请选择角色"

排查建议：

- 前往"系统管理 → 角色管理"，确认已创建状态为"正常"的角色
- 新增用户时在角色下拉框中搜索并选择对应角色后再保存
