## 1. 系统介绍

多场景影像传感设备资源协同调度系统系统是一套面向工业影像设备统一管理与智能调度的专业平台，围绕影像设备接入、场景分组管理、采集任务全生命周期管理、设备调度执行及多维度统计分析的完整业务闭环，支持多场景下的影像设备统一纳管与自动化任务调度，实现影像采集资源的高效利用与可视化管控。

核心能力：

- 影像设备统一接入与状态监控（工业相机、激光雷达、X射线仪、超声波探头等）
- 场景分组管理（按生产区域、质检线等业务场景对设备进行分组归属）
- 采集任务全生命周期管理（新建、分配设备、启动、完成、取消）
- 设备调度执行可视化（调度日志、甘特图、调度配置）
- 多维度统计分析（设备状态分布、任务趋势、故障统计、场景任务分布）
- 系统管理（用户、角色、菜单、操作权限）

## 4. 设备管理

功能说明：统一管理系统接入的影像采集设备，支持新增、编辑、删除及设备参数配置。

### 4.1 设备列表

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 搜索设备 | 查询 | 按设备名称或设备编码关键词筛选列表；按状态下拉筛选在线/离线/故障设备。 |
| 重置筛选 | 重置 | 清空筛选条件并刷新列表。 |
| 新增设备 | 新增设备 | 填写设备基础信息后保存，新设备默认为离线状态。 |
| 编辑设备 | 编辑 | 修改设备名称、型号规格、IP 地址、安装位置等信息。 |
| 配置参数 | 参数 | 打开设备参数配置弹窗，维护该设备的自定义键值对参数（如分辨率、帧率、曝光时间等）。 |
| 删除设备 | 删除 | 永久删除设备记录，操作前需二次确认。 |

设备类型说明：

- 工业相机（1）：视觉影像采集设备，用于零件外观检测、尺寸测量等场景。
- 激光雷达（2）：激光点云采集设备，用于三维空间扫描与测距。
- X射线仪（3）：X光无损检测设备，用于零件内部缺陷探伤。
- 超声波探头（4）：超声波无损检测设备，用于材料内部检测。

设备状态说明：

- 在线（绿色）：设备连接正常，心跳保持活跃，可被任务调度使用。
- 离线（灰色）：设备连接断开或心跳超时，无法参与任务调度。
- 故障（红色）：设备检测到异常，需要维护处理。

## 5. 场景管理

功能说明：按业务区域对影像设备进行分组管理，通过"场景分组→场景"两级结构组织设备归属关系，便于按生产区域进行设备调度与任务下发。

### 5.1 场景分组

| 字段 | 必填 | 说明 |

| 分组名称 | 是 | 场景分组的业务名称，如"生产线A区"。 |
| 分组编码 | 否 | 分组的系统编码，用于接口对接与唯一标识。 |

## 6. 任务管理

功能说明：管理影像采集任务的全生命周期，支持任务创建、设备分配、状态推进与取消操作。

### 6.1 任务列表

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 搜索任务 | 查询 | 按任务名称或任务编码关键词筛选；按状态下拉筛选特定状态任务。 |
| 重置筛选 | 重置 | 清空筛选条件并刷新列表。 |
| 新增任务 | 新增任务 | 填写任务信息后保存，新建任务默认为"待执行"状态。 |
| 编辑任务 | 编辑 | 修改任务基础信息，仅待执行状态的任务可编辑。 |
| 分配设备 | 分配设备 | 从当前可用（在线空闲）设备中勾选设备分配给该任务。 |
| 启动任务 | 启动 | 将待执行任务推进为"进行中"状态，开始执行采集作业。 |
| 完成任务 | 完成 | 将进行中任务标记为"已完成"，释放占用设备资源。 |
| 取消任务 | 取消 | 取消待执行或进行中任务，释放资源，操作前需确认。 |

任务状态流转说明：

```
新建 → 待执行(10) → 已分配(20) → 进行中(30) → 已完成(50)
                              ↓
                         已取消(-20)
```

| 状态 | 说明 |
| --- | --- |
| 待执行（10） | 任务已创建，尚未分配设备或启动。 |
| 已分配（20） | 任务已完成设备分配，等待启动指令。 |
| 进行中（30） | 任务已启动，设备正在执行采集作业。 |
| 已完成（50） | 任务采集作业已结束，设备资源已释放。 |
| 已取消（-20） | 任务被手动取消，不再执行。 |

任务优先级说明：

| 优先级 | 标识颜色 | 说明 |
| --- | --- | --- |
| 高（3） | 红色 | 紧急任务，优先分配资源、优先调度执行。 |
| 中（2） | 橙色 | 常规优先级，按正常调度顺序执行。 |
| 低（1） | 灰色 | 低优先级，在高/中优先级任务完成后再调度。 |

### 6.2 新增/编辑任务

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 任务编码 | 是 | 任务唯一标识编码。 |
| 任务名称 | 是 | 任务的业务名称描述。 |
| 任务类型 | 否 | 常规采集（1）/ 紧急检测（2）/ 周期巡检（3）。 |
| 优先级 | 否 | 低（1）/ 中（2）/ 高（3），默认中。 |
| 计划开始时间 | 否 | 任务预计开始执行时间，格式：yyyy-MM-dd HH:mm:ss。 |
| 计划结束时间 | 否 | 任务预计完成时间，超过此时间未完成将产生超时预警。 |
| 所需设备数 | 否 | 任务执行所需的最少设备数量，默认为1。 |
| 描述 | 否 | 任务的补充说明信息。 |

### 6.3 分配设备

点击"分配设备"按钮后，弹窗展示当前在线空闲的影像设备列表，勾选所需设备后点击确定完成分配。

注意：

- 仅"在线"且未被其他进行中任务占用的设备会出现在可选列表中。
- 分配完成后任务状态变更为"已分配"，设备进入占用状态。

操作结果：

任务分配设备后可启动执行，完成后设备资源自动释放。

## 7. 调度管理

功能说明：查看和管理设备调度执行情况，包括调度日志记录、设备甘特图可视化及全局调度参数配置。

### 7.1 调度日志

功能说明：记录系统所有调度操作的执行日志，包括任务创建、设备分配、启动、完成、取消等操作的完整流水。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 搜索日志 | 查询 | 按任务名称关键词筛选调度日志记录。 |
| 翻页 | 分页器 | 按页浏览历史调度日志记录。 |

列表字段说明：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 本次调度操作关联的任务名称 |
| 操作 | 调度动作描述（如：任务启动、设备分配、任务完成等） |
| 涉及设备 | 本次调度操作所涉及的设备 ID 列表 |
| 操作人 | 执行本次调度操作的用户名 |
| 时间 | 调度操作的发生时间 |

### 7.2 甘特图

功能说明：以横向时间轴可视化展示各设备的任务占用时间段，直观呈现设备调度排期与资源占用情况。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 刷新数据 | 刷新 | 重新加载当日设备甘特图数据。 |
| 查看任务 | 鼠标悬停色块 | 悬停在任务色块上可查看任务名称与时间信息。 |

甘特图说明：

- 纵轴：设备列表（每行代表一台设备）
- 横轴：时间（按小时划分当日时间段）
- 色块：该设备在对应时间段执行的任务区间，宽度代表任务持续时间

### 7.3 调度配置

功能说明：配置系统全局调度参数，包括任务并发限制、超时阈值及调度策略等，影响全系统的设备调度行为。

| 配置项 | 说明 |
| --- | --- |
| 最大设备数/任务 | 单个任务最多可分配的设备数量上限。 |
| 任务超时时间（分钟） | 任务从计划结束时间起超过多少分钟未完成时触发超时预警。 |
| 自动调度 | 开启后系统将根据调度策略自动为待执行任务匹配可用设备；关闭后需手动分配设备。 |
| 调度策略 | 先进先出（FIFO）：按任务创建顺序依次调度；优先级优先（PRIORITY）：高优先级任务优先获得设备资源；负载均衡（LOAD_BALANCE）：将任务均匀分配到设备负载较低的设备。 |
| 预警阈值（分钟） | 任务计划结束时间前多少分钟开始在仪表盘显示超时预警提示。 |

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 保存配置 | 保存配置 | 将当前填写的配置项保存并立即生效。 |

操作结果：

调度配置保存后实时影响后续任务的自动调度与超时预警判断。

## 8. 统计分析

功能说明：通过多维度图表直观展示系统运行状态，包括设备状态分布、任务执行趋势、场景任务分布及设备故障统计，为设备运维与任务管理提供数据支撑。

| 图表 | 类型 | 说明 |
| --- | --- | --- |
| 设备状态分布 | 饼图 | 展示当前所有设备中在线空闲、忙碌、离线、故障设备的数量占比。 |
| 任务状态分布 | 饼图 | 展示系统内进行中、已完成、待执行、已分配、已取消任务的数量占比。 |
| 设备利用率趋势（近7天） | 折线图 | 按天展示近7日每日被调度使用的不重复设备数量变化趋势。 |
| 任务趋势（近7天） | 柱状图 | 按天展示近7日每日新建任务数与完成任务数的对比情况。 |
| 各场景任务数 | 横向柱状图 | 展示各业务场景下关联任务数量的分布情况，按任务数降序排列。 |
| 设备故障统计 | 柱状图（红色） | 展示近30天各设备的故障次数，按故障次数降序排列，用于识别高故障设备。 |

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 查看图表 | - | 进入统计分析页后自动加载所有图表数据。 |
| 鼠标悬停 | - | 悬停在图表上可查看各数据点的具体数值提示。 |

操作结果：

## 10. 常见问题

### 10.1 登录后跳回登录页

排查建议：

- 检查后端服务是否可达（默认端口 19913）
- 检查 Token 是否失效，尝试重新登录
- 清空浏览器本地存储（localStorage）后重新登录

### 10.2 仪表盘数据全部显示为0

排查建议：

- 检查后端 `/api/v1/dispatch/overview` 接口是否正常返回
- 确认数据库中存在设备与任务记录
- 检查后端日志（`/tmp/ids-backend.log`）确认服务是否正常启动

### 10.3 设备状态长期显示离线

排查建议：

- 确认设备网络连接正常，IP 地址填写正确
- 后端心跳检测服务可能未向该 IP 发送探活请求，检查服务配置
- 可通过手动调用 `PATCH /api/v1/devices/{id}/status` 接口临时更新设备状态

### 10.4 任务无法分配设备（可选设备列表为空）

排查建议：

- 确认系统中存在状态为"在线"的设备（仪表盘在线设备数 > 0）
- 确认目标设备未被其他正在进行中的任务占用
- 通过设备管理页检查设备状态，确认无设备被卡在"进行中"状态

### 10.5 统计分析页面图表为空

排查建议：

- 图表数据需要有历史任务记录支撑，确认系统存在已创建的任务数据
- 检查 `/api/v1/statistics/device/status`、`/api/v1/statistics/task/trend` 等接口是否正常返回数据
- 尝试刷新页面重新加载图表数据

### 10.6 甘特图无数据显示

排查建议：

- 甘特图展示的是通过任务-设备关联表（`task_device_rel`）记录的设备分配数据
- 确认存在已分配设备的任务记录
- 点击"刷新"按钮重新加载当日数据

### 10.7 调度配置保存失败

排查建议：

- 确认各配置项填写值在有效范围内（数值字段不能为空或零）
- 检查当前用户是否具备调度配置的编辑权限
- 查看浏览器开发者工具的网络请求，确认 `PUT /api/v1/dispatch/config` 接口返回状态

### 10.8 超时预警未触发

排查建议：

- 确认任务已设置计划结束时间（`planEndTime` 字段）
- 检查调度配置中"预警阈值（分钟）"是否已正确设置
- 仪表盘超时预警卡片基于 `dispatch/alerts/timeout` 接口，确认该接口返回数据正常

### 10.9 页面提示无权限

排查建议：

- 检查当前用户角色是否具备对应菜单权限
- 检查角色菜单中是否已关联对应操作按钮权限节点
- 重新登录以刷新最新权限信息
