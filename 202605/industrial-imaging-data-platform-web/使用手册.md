## 1. 系统介绍

工业级影像传感大数据处理软件是一套面向工业影像数据全生命周期管理的专业平台，围绕影像数据的采集接入、自动化处理、存储管控及多维度统计分析构建完整业务闭环，支持多类型数据源统一接入与调度，实现工业影像数据的高效汇聚、智能处理与安全存储。

核心能力：

- 多类型数据源统一管理（FTP、SFTP、SMB、S3、本地等）
- 数据采集任务全生命周期管理（Cron 定时调度、手动触发、采集记录追踪）
- 数据处理任务自动化执行（图像压缩、格式转换、质量检测、元数据提取）
- 数据存储容量监控与自动清理规则管理
- 系统运行统计分析（采集趋势、文件类型分布、数据源贡献、处理任务汇总）
- 系统管理（用户、角色、菜单权限精细化控制）
- 操作日志全程记录与审计

## 4. 数据源管理

功能说明：统一管理平台接入的影像数据源，支持新增、编辑、删除、连接测试及启用/停用操作。数据源是数据采集任务的基础依赖，需先完成数据源配置后才可创建采集任务。

### 4.1 数据源列表

| 操作         | 点击按钮 | 说明                                                             |
| ------------ | -------- | ---------------------------------------------------------------- |
| 搜索数据源   | 查询     | 按数据源名称关键词筛选列表；按类型下拉筛选特定协议类型的数据源。 |
| 重置筛选     | 重置     | 清空筛选条件并刷新列表。                                         |
| 新增数据源   | 新增     | 填写数据源连接信息后保存，新数据源默认为启用状态。               |
| 测试连接     | 测试     | 验证当前数据源的网络连通性与认证信息是否正确。                   |
| 编辑数据源   | 编辑     | 修改数据源连接配置信息。                                         |
| 切换启用状态 | 状态开关 | 启用后数据源可被采集任务使用；停用后该数据源不参与任务调度。     |
| 删除数据源   | 删除     | 永久删除数据源记录，操作前需二次确认。                           |

数据源类型说明：

- FTP：标准文件传输协议，默认端口 21。
- SFTP：基于 SSH 的安全文件传输协议，默认端口 22。
- SMB：Windows 共享文件协议，适用于局域网文件共享场景。
- S3：兼容 Amazon S3 协议的对象存储，支持云存储接入。
- LOCAL：本地文件系统路径，适用于本机或挂载目录的数据采集。

### 4.2 新增/编辑数据源

| 字段   | 必填 | 说明                                                   |
| ------ | ---- | ------------------------------------------------------ |
| 名称   | 是   | 数据源的业务名称，建议简短易识别。                     |
| 类型   | 是   | 选择数据源协议类型：FTP / SFTP / SMB / S3 / LOCAL。    |
| 主机   | 是   | 数据源服务器的 IP 地址或域名（LOCAL 类型填本地路径）。 |
| 端口   | 否   | 服务端口号，FTP 默认 21，SFTP 默认 22。                |
| 路径   | 否   | 数据源根目录路径，采集任务以此路径为起始扫描位置。     |
| 用户名 | 否   | 登录数据源服务器的账号（匿名访问可留空）。             |
| 密码   | 否   | 登录密码（密文存储，编辑时留空则不修改原有密码）。     |
| 描述   | 否   | 数据源的补充说明信息。                                 |

操作结果：

数据源配置完成后，可在新增采集任务时通过数据源 ID 进行关联绑定。

## 5. 数据接入

功能说明：管理影像数据采集任务的配置与调度执行，通过 Cron 定时表达式实现自动化周期采集，同时提供采集记录查询功能便于追踪每次采集执行情况。

页面包含两个子标签页：**采集任务**与**采集记录**。

### 5.1 采集任务

| 操作     | 点击按钮 | 说明                                                       |
| -------- | -------- | ---------------------------------------------------------- |
| 搜索任务 | 查询     | 按任务名称关键词筛选；按状态下拉筛选启用/停用任务。        |
| 重置筛选 | 重置     | 清空筛选条件并刷新列表。                                   |
| 新增任务 | 新增     | 填写采集任务配置信息后保存，任务按照 Cron 表达式定时触发。 |
| 立即触发 | 立即触发 | 不等待定时调度，立即执行一次该任务的数据采集操作。         |
| 编辑任务 | 编辑     | 修改任务配置信息。                                         |
| 删除任务 | 删除     | 永久删除采集任务，操作前需二次确认。                       |

#### 新增/编辑采集任务

| 字段             | 必填 | 说明                                                                                |
| ---------------- | ---- | ----------------------------------------------------------------------------------- |
| 任务名称         | 是   | 采集任务的业务名称描述。                                                            |
| 数据源ID         | 是   | 关联已配置的数据源，通过数据源 ID 进行绑定。                                        |
| Cron表达式       | 是   | 定时触发规则，格式为标准 Cron（如 `0 0/30 * * * ?` 表示每30分钟执行一次）。       |
| 文件类型过滤     | 否   | 只采集指定格式文件，多个类型用逗号分隔（如 `jpg,png,tiff`）；留空则采集所有文件。 |
| 文件大小上限(MB) | 否   | 单文件大小上限，超过该阈值的文件将跳过不采集。                                      |
| 描述             | 否   | 任务补充说明信息。                                                                  |

Cron 表达式常用示例：

| 表达式             | 含义                        |
| ------------------ | --------------------------- |
| `0 0/30 * * * ?` | 每30分钟执行一次            |
| `0 0 2 * * ?`    | 每天凌晨2点执行             |
| `0 0 8-18 * * ?` | 每天8点到18点每小时执行一次 |
| `0 0/5 * * * ?`  | 每5分钟执行一次             |

### 5.2 采集记录

采集记录自动记录每次任务执行的详细情况，用于采集状态追踪与问题排查。

| 操作       | 点击按钮 | 说明                                 |
| ---------- | -------- | ------------------------------------ |
| 按任务筛选 | 查询     | 输入任务 ID 筛选指定任务的采集记录。 |
| 按状态筛选 | 状态下拉 | 筛选成功 / 失败 / 进行中的采集记录。 |

采集记录状态说明：

| 状态              | 标识颜色 | 说明                                       |
| ----------------- | -------- | ------------------------------------------ |
| SUCCESS（成功）   | 绿色     | 本次采集任务正常完成，数据已写入存储。     |
| FAILED（失败）    | 红色     | 本次采集发生异常，可查看错误信息排查原因。 |
| RUNNING（进行中） | 蓝色     | 采集任务正在执行中，等待完成。             |

操作结果：

采集任务按计划运行，每次执行结果自动写入采集记录，可随时查询追踪。

## 6. 数据处理

功能说明：管理影像数据的后处理任务，支持图像压缩、格式转换、质量检测、元数据提取等多种处理类型，通过 Cron 定时调度自动运行，同时提供执行记录与进度追踪功能。

页面包含两个子标签页：**处理任务**与**执行记录**。

### 6.1 处理任务

| 操作     | 点击按钮 | 说明                                                       |
| -------- | -------- | ---------------------------------------------------------- |
| 新增任务 | 新增     | 填写处理任务配置信息后保存，任务按照 Cron 表达式定时触发。 |
| 触发     | 触发     | 不等待定时调度，立即执行一次该处理任务。                   |
| 编辑任务 | 编辑     | 修改处理任务配置信息。                                     |
| 删除任务 | 删除     | 永久删除处理任务，操作前需二次确认。                       |

#### 新增/编辑处理任务

| 字段       | 必填 | 说明                                                                           |
| ---------- | ---- | ------------------------------------------------------------------------------ |
| 任务名称   | 是   | 处理任务的业务名称描述。                                                       |
| 处理类型   | 是   | 从下拉选项选择处理算法类型（见下表说明）。                                     |
| Cron表达式 | 否   | 定时触发规则，格式为标准 Cron 表达式。                                         |
| 参数JSON   | 否   | 处理算法的参数配置，以 JSON 格式填写（如 `{"quality":80}` 表示压缩质量80）。 |
| 描述       | 否   | 任务补充说明信息。                                                             |

处理类型说明：

| 类型       | 代码             | 说明                                                       |
| ---------- | ---------------- | ---------------------------------------------------------- |
| 图像压缩   | IMAGE_COMPRESS   | 对采集到的影像文件进行有损/无损压缩，减少存储空间占用。    |
| 格式转换   | FORMAT_CONVERT   | 将影像文件转换为目标格式（如 TIFF 转 JPEG、PNG 转 WebP）。 |
| 质检       | QUALITY_CHECK    | 对影像文件进行质量评估，检测模糊、欠曝、过曝等质量问题。   |
| 元数据提取 | METADATA_EXTRACT | 从影像文件中提取 EXIF、拍摄参数等元数据信息并结构化存储。  |

### 6.2 执行记录

执行记录自动记录每次处理任务的运行详情，支持实时进度查看与异常终止操作。

| 操作     | 点击按钮 | 说明                                             |
| -------- | -------- | ------------------------------------------------ |
| 查看进度 | -        | 进行中的任务显示实时进度条，直观展示完成百分比。 |
| 终止执行 | 终止     | 对状态为"进行中"的执行记录，可手动终止该次执行。 |

执行记录状态说明：

| 状态                 | 标识颜色 | 说明                               |
| -------------------- | -------- | ---------------------------------- |
| RUNNING（进行中）    | 蓝色     | 处理任务正在执行，进度条实时更新。 |
| SUCCESS（成功）      | 绿色     | 处理任务正常完成。                 |
| FAILED（失败）       | 红色     | 处理任务执行失败，可查看错误信息。 |
| TERMINATED（已终止） | 橙色     | 处理任务被手动终止。               |

操作结果：

处理任务按配置自动运行，执行结果记录可查，异常可手动干预。

## 7. 数据存储

功能说明：监控平台存储空间使用情况，并通过自动化清理规则管理存储容量，防止磁盘空间耗尽影响采集任务正常运行。

页面顶部展示存储概览指标，下方包含两个子标签页：**清理规则**与**清理日志**。

### 7.1 存储概览

页面顶部看板展示当前存储状态：

| 指标       | 说明                                           |
| ---------- | ---------------------------------------------- |
| 总文件数   | 当前存储系统中影像文件的总数量。               |
| 已使用(GB) | 当前已占用的存储空间大小（GB）。               |
| 总容量(GB) | 存储系统的总容量上限（GB）。                   |
| 使用率     | 已使用空间占总容量的百分比，超过阈值时需关注。 |

### 7.2 清理规则

清理规则定义了哪些文件应当被自动清理，以及清理的触发时机。

| 操作     | 点击按钮 | 说明                                                   |
| -------- | -------- | ------------------------------------------------------ |
| 新增规则 | 新增     | 填写清理规则配置后保存，规则按 Cron 计划自动执行。     |
| 立即清理 | 立即清理 | 不等待定时触发，立即对该规则指定路径执行一次清理操作。 |
| 编辑规则 | 编辑     | 修改清理规则配置信息。                                 |
| 删除规则 | 删除     | 永久删除清理规则，操作前需二次确认。                   |

#### 新增/编辑清理规则

| 字段         | 必填 | 说明                                                                                 |
| ------------ | ---- | ------------------------------------------------------------------------------------ |
| 规则名称     | 是   | 清理规则的业务名称描述。                                                             |
| 存储路径     | 是   | 需要进行清理管理的目录路径。                                                         |
| 文件保留天数 | 是   | 超过此天数的文件将被自动清理，例如填 30 表示保留近30天的文件。                       |
| 最大存储(GB) | 否   | 该路径的存储上限，超过此容量时触发清理（优先删除最旧文件）。                         |
| Cron表达式   | 否   | 定时清理触发规则，格式为标准 Cron 表达式（如 `0 0 3 * * ?` 表示每天凌晨3点执行）。 |
| 启用         | 否   | 规则是否启用，停用状态下不会自动触发清理。                                           |
| 描述         | 否   | 规则补充说明信息。                                                                   |

### 7.3 清理日志

清理日志自动记录每次规则执行的结果，便于审计和效果追踪。

| 字段         | 说明                                        |
| ------------ | ------------------------------------------- |
| 规则ID       | 本次清理执行的规则标识。                    |
| 清理文件数   | 本次执行清理的文件总数量。                  |
| 释放空间(MB) | 本次清理释放的磁盘空间大小（MB）。          |
| 状态         | 执行结果：SUCCESS（成功）/ FAILED（失败）。 |
| 执行时间     | 本次清理操作的发生时间。                    |

操作结果：

存储空间按规则自动维护，防止磁盘满影响采集服务正常运行。

## 8. 系统管理

### 8.1 用户管理

功能说明：维护系统用户账号信息及登录状态，控制人员访问权限。

| 操作     | 点击按钮 | 说明                                                                   |
| -------- | -------- | ---------------------------------------------------------------------- |
| 查询用户 | 查询     | 按用户名关键词筛选用户列表。                                           |
| 新增用户 | 新增用户 | 填写用户名、密码、真实姓名、邮箱、手机号后保存，新用户默认为启用状态。 |
| 编辑用户 | 编辑     | 修改用户基础信息（用户名在编辑时不可修改）。                           |
| 重置密码 | 重置密码 | 为指定用户设置新密码，操作前需二次确认。                               |
| 切换状态 | 状态开关 | 启用账号允许正常登录；禁用后账号无法登录系统。                         |

用户状态说明：

- 正常（开关开启）：账号可正常登录。
- 禁用（开关关闭）：账号被锁定，无法登录系统。

#### 新增/编辑用户字段说明

| 字段     | 必填         | 说明                                         |
| -------- | ------------ | -------------------------------------------- |

## 10. 常见问题

### 10.1 登录后跳回登录页

排查建议：

- 检查后端服务是否可达（默认端口 19910），确认服务进程正在运行
- 检查 Token 是否失效，尝试重新登录
- 清空浏览器本地存储（localStorage）后重新登录：打开开发者工具 → Application → Local Storage → 全部清除

### 10.2 仪表盘数据全部显示为 0

排查建议：

- 检查后端 `/api/stats/overview` 接口是否正常返回数据
- 确认数据库中存在数据源与采集记录
- 检查后端日志（`/tmp/iidp-backend.log`）确认服务是否正常启动
- 确认当前登录用户具备 `stats:overview:view` 权限

### 10.3 数据源测试连接失败

排查建议：

- 确认主机地址、端口填写正确，服务器网络可达
- 确认用户名与密码信息正确，账号未被锁定
- FTP/SFTP 类型需确认防火墙已放行对应端口
- S3 类型需确认 Access Key 与 Secret Key 填写正确，Bucket 已存在

### 10.4 采集任务未按计划执行

排查建议：

- 确认 Cron 表达式格式正确（可使用在线 Cron 解析工具验证）
- 确认任务状态为"启用"，未启用的任务不会触发
- 检查关联的数据源是否已启用且连接正常
- 查看采集记录中是否有失败记录，确认失败原因

### 10.5 采集记录显示 FAILED

排查建议：

- 确认关联数据源连接正常（可通过"测试"按钮验证）
- 确认数据源路径下存在满足文件类型过滤条件的文件
- 检查文件大小是否超出配置的"文件大小上限"
- 查看后端日志获取详细错误堆栈信息

### 10.6 处理任务执行失败

排查建议：

- 确认"参数JSON"格式合法，为有效的 JSON 字符串
- 确认处理类型与参数配置匹配（如 IMAGE_COMPRESS 需填写 `quality` 参数）
- 确认存储中存在待处理的文件
- 查看执行记录中的错误信息，定位具体失败原因

### 10.7 存储使用率持续升高

排查建议：

- 检查是否已配置存储清理规则，若无则新增清理规则
- 检查已有清理规则是否处于启用状态
- 确认清理规则的 Cron 表达式合法，已按计划触发
- 可点击"立即清理"按钮手动触发一次清理操作
- 查看清理日志确认清理执行情况

### 10.8 页面提示无权限（403）

排查建议：

- 检查当前用户角色是否具备访问该功能的菜单权限
- 检查角色关联的菜单中是否包含对应操作按钮的权限节点
- 联系管理员在角色管理中为该角色分配相应权限
- 重新登录以刷新最新权限信息

### 10.9 系统管理菜单不可见

排查建议：

- 系统管理默认仅对具备 `system:user:list`、`system:role:list`、`system:menu:list` 权限之一的用户显示
- 联系超级管理员（admin）为当前用户角色分配系统管理权限
- 重新登录刷新菜单权限列表
