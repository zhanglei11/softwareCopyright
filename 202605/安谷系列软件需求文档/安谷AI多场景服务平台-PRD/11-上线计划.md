## 11.2 分期建议

| 期次 | 包含内容 | 交付目标 |
|------|----------|----------|
| P0（必须） | 基础管理 + AI 场景管理 + AI 模型配置 + 智能对话 + 场景广场 | 核心 AI 服务跑通，用户可使用智能对话 |
| P1（重要） | 知识库管理 + 场景 RAG 配置 + 知识问答 | 私有知识 AI 化，支持 RAG 问答 |
| P2（重要） | 文档分析 + 内容生成 + 使用量看板 | AI 功能补全，管理决策有数据支撑 |
| P3（锦上添花） | 历史会话管理 + 场景调用统计 + 数据导出 + 每日限额 | 精细化运营与管控 |

## 11.4 关键依赖与风险

| 风险 | 说明 | 应对措施 |
|------|------|----------|
| AI 模型 API 稳定性 | 依赖第三方服务，可能超时或限流 | 配置超时重试机制；多模型备用切换 |
| 向量数据库运维 | Milvus 部署与维护有一定门槛 | 可先用 Chroma（轻量级）替代，验证后迁移 Milvus |
| 文档解析准确性 | 复杂 PDF 排版解析效果有限 | 明确告知用户，降低预期；提供重试能力 |
| Token 消耗成本 | 大量调用产生 Token 费用 | 每日限额机制；Token 消耗实时监控 |
