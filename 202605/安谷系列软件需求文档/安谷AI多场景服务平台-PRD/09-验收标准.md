# 九、验收标准

## 9.1 认证模块

**TC-001 正常登录**
- Given: 用户账号启用，密码正确，验证码正确
- When: 提交登录表单
- Then: 返回 accessToken + refreshToken；页面跳转首页

**TC-002 密码锁定**
- Given: 正常账号
- When: 连续 5 次密码错误
- Then: 第 6 次请求返回 423，提示"账号已锁定，请 30 分钟后重试"

**TC-003 Token 刷新**
- Given: accessToken 已过期，refreshToken 有效
- When: 前端自动调用 /api/auth/refresh
- Then: 返回新 accessToken，用户无感知

## 9.2 AI 场景管理

**TC-010 场景创建与上架**
- Given: AI 管理员登录，进入场景配置
- When: 创建场景填写必填字段后保存（状态=DRAFT），点击"上架"
- Then: 状态变为 ONLINE；场景广场中当前用户可看到该场景

**TC-011 场景下架**
- Given: 一个 ONLINE 场景
- When: 点击"下架"
- Then: 状态变为 OFFLINE；用户端场景广场中不再显示；已进行中的会话不被中断

**TC-012 删除非草稿场景**
- Given: 一个 ONLINE 场景
- When: 尝试删除
- Then: 返回 400，提示"请先下架再删除"

## 9.3 AI 服务功能

**TC-020 智能对话流式输出**
- Given: 普通用户进入智能对话页
- When: 发送消息"你好"
- Then: AI 回复以打字机效果逐字呈现；完成后消息出现在历史列表

**TC-021 停止生成**
- Given: AI 正在流式输出
- When: 点击"停止"按钮
- Then: 输出立即中断，已输出内容保留

**TC-022 每日调用限额**
- Given: 用户每日限额设为 10 次，当日已调用 10 次
- When: 第 11 次发送消息
- Then: 返回 429，提示"今日调用次数已达上限（10 次）"

**TC-023 文档分析上传**
- Given: 上传一个 5MB 的 PDF 文件
- When: 上传完成
- Then: 文件解析完毕，可对其进行摘要/问答操作

**TC-024 文档分析大小限制**
- Given: 准备上传一个 25MB 的文件
- When: 选择文件并点击上传
- Then: 前端提示"文件大小不能超过 20MB"，阻止上传

## 9.4 知识库管理

**TC-030 文档向量化**
- Given: 知识库已创建，上传一个 TXT 文档
- When: 等待解析
- Then: 文档状态从 PENDING → PROCESSING → DONE；`chunk_count > 0`

**TC-031 检索测试**
- Given: 知识库有已完成的文档
- When: 在检索测试页输入问题
- Then: 返回相关度最高的知识片段列表，每条含相似度分数

**TC-032 删除有引用的知识库**
- Given: 知识库 A 被场景 B 引用
- When: 删除知识库 A
- Then: 返回 409，提示"该知识库被 1 个场景引用，请先解除关联"

## 9.5 API 管理

**TC-040 连通性测试成功**
- Given: 配置一个有效的 OpenAI 模型，API Key 正确
- When: 点击"连通性测试"
- Then: 返回 `{success: true}`，提示"连通测试通过"

**TC-041 连通性测试失败**
- Given: API Key 填写错误
- When: 点击"连通性测试"
- Then: 返回 `{success: false, message: "Incorrect API key provided"}`；不抛 500

**TC-042 API 密钥脱敏**
- Given: 已配置模型，API Key 为 `sk-abcdef1234567890`
- When: 查看模型列表或详情
- Then: 返回的 api_key 字段显示为 `****7890`

## 9.6 统计报表

**TC-050 看板数据**
- Given: 当日有 AI 调用记录
- When: 访问首页使用量看板
- Then: "今日调用总次数"与数据库 `ai_call_log` 当日记录数一致

## 9.7 权限

**TC-060 普通用户越权**
- Given: 普通用户已登录
- When: 调用 `GET /api/system/users`（用户管理接口）
- Then: 返回 403

**TC-061 场景权限隔离**
- Given: 普通用户角色未授权场景 S
- When: 场景广场不显示场景 S；直接调用 `POST /api/app/conversations/{id}/messages` 并指定 sceneId=S
- Then: 场景广场不可见；API 调用返回 403
