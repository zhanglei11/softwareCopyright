# 四、业务边界

## 4.1 系统内部边界

| 边界说明 | 处理方式 |
|----------|----------|
| 已下架场景不可被用户调用 | 接口层拦截，返回 403 |
| 用户每日调用超限额 | 接口层校验，返回 429，提示"今日调用次数已达上限" |
| 禁用用户无法登录 | 登录接口返回 423 |
| 内置角色（SUPER_ADMIN 等）不可删除 | 接口层返回 403 |
| 关联了场景的角色不可删除 | 场景权限解绑后方可删除 |
| 有绑定用户的角色不可删除 | 接口层返回 409，提示"请先解绑用户" |
| 有子节点的菜单不可删除 | 接口层返回 400 |
| 有场景引用的知识库不可删除 | 接口层返回 409，提示"知识库被 N 个场景引用" |
| 已下架场景可被配置引用知识库，但修改不立即生效 | 需重新上架后生效 |
| 模型 API 密钥展示时脱敏 | 仅返回末尾4位明文，其余显示 `****` |
| 文件解析失败不阻断上传 | 文档状态标记 FAILED，提示重试 |
| 文档分析会话内临时文件 | 会话结束后自动清理，不长期保存 |

## 4.2 系统外部边界（本期不涉及）

- 不对接企业 SSO / LDAP 登录
- 不提供对外公开 API 接口（无 API 开放平台）
- 不支持移动端（APP / 小程序）
- 不集成邮件/短信通知
- 不自研 AI 模型，仅接入第三方 AI API

## 4.3 数据边界

| 数据 | 保留策略 |
|------|----------|
| 历史会话消息 | 长期保留（逻辑删除，物理数据不清除） |
| AI 调用日志 | 保留 12 个月，超期归档或删除 |
| 文档分析临时文件 | 会话关闭后 24h 内清除 |
| 知识库向量数据 | 随知识库/文档删除同步清除 |
