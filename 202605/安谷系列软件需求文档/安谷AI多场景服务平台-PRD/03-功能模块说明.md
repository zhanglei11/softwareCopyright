# 三、功能模块说明

## 3.1 基础管理模块

### 3.1.1 用户管理

| 功能点 | 说明 |
|--------|------|
| 用户列表 | 分页展示，支持按姓名/账号/状态/角色筛选 |
| 新增用户 | 填写基本信息，分配角色及可使用的 AI 场景权限 |
| 编辑用户 | 修改用户信息与角色（登录账号不可修改） |
| 删除用户 | 逻辑删除，保留历史对话记录 |
| 启用/禁用 | 禁用后该账号无法登录 |
| 重置密码 | 管理员为用户生成新密码 |
| 查看用量 | 查看指定用户当日/本月 AI 调用次数与 Token 消耗 |

**用户字段定义：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 用户姓名 | VARCHAR(64) | 是 | |
| 登录账号 | VARCHAR(32) | 是 | 唯一，6-20 位字母数字 |
| 登录密码 | VARCHAR(255) | 是 | BCrypt 加密存储，8位以上含大小写+数字+特殊字符 |
| 手机号码 | VARCHAR(20) | 是 | |
| 邮箱地址 | VARCHAR(128) | 否 | |
| 所属部门 | VARCHAR(64) | 否 | |
| 用户角色 | 多选关联 | 是 | 关联 sys_role |
| 每日调用限额 | INT | 否 | null 则不限制 |
| 用户状态 | TINYINT | 是 | 0 禁用 / 1 启用 |

### 3.1.2 角色管理

| 功能点 | 说明 |
|--------|------|
| 角色列表 | 展示所有角色名称、标识、描述、状态 |
| 新增角色 | 配置角色名称、描述，分配菜单权限 |
| 编辑角色 | 修改角色配置（内置角色标识不可修改） |
| 删除角色 | 删除无关联用户的角色；内置角色不可删除 |
| 菜单权限配置 | 树形勾选可访问菜单与操作按钮 |
| 场景权限配置 | 配置该角色可使用的 AI 场景列表（多选） |

### 3.1.3 菜单管理

| 功能点 | 说明 |
|--------|------|
| 菜单树 | 树形结构展示所有目录/菜单/按钮节点 |
| 新增菜单 | 配置类型（目录/菜单/按钮）、名称、路由、图标、权限标识、排序 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 有子节点时拒绝删除 |
| 排序 | 同级节点支持 sort 字段排序 |

## 3.2 AI 场景管理模块

### 3.2.1 场景分类管理

| 功能点 | 说明 |
|--------|------|
| 分类列表 | 展示所有场景分类（名称/图标/场景数/排序） |
| 新增分类 | 填写分类名称、图标、排序 |
| 编辑分类 | 修改基本信息 |
| 删除分类 | 该分类下无场景时才允许删除 |

**内置分类：**

| 分类名称 | 说明 |
|----------|------|
| 智能对话 | 通用对话类 AI 场景 |
| 文档处理 | 文档分析、摘要、问答 |
| 内容创作 | 文章、报告、邮件生成 |
| 知识问答 | 基于知识库的精准问答 |
| 数据分析 | 数据解读与图表说明 |

### 3.2.2 AI 场景配置

**场景状态流转：** `DRAFT（草稿）→ ONLINE（已上架）→ OFFLINE（已下架）`

| 功能点 | 说明 |
|--------|------|
| 场景列表 | 分页展示，支持按分类/状态筛选 |
| 新增场景 | 填写场景基本信息 + 配置提示词与参数 |
| 编辑场景 | 修改场景配置（已上架场景编辑后须重新发布） |
| 上架 | DRAFT/OFFLINE → ONLINE；用户端可见 |
| 下架 | ONLINE → OFFLINE；用户端隐藏，已进行中的会话不中断 |
| 删除场景 | 仅 DRAFT/OFFLINE 状态可删除 |
| 场景预览 | 管理员在保存前可测试场景效果（不计入统计） |

**场景配置字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 场景名称 | VARCHAR(128) | 是 | 如：会议纪要生成助手 |
| 场景分类 | FK | 是 | 关联 ai_scene_category |
| 场景图标 | VARCHAR(512) | 否 | 图标 URL 或图标名 |
| 场景描述 | VARCHAR(512) | 是 | 简要说明用途 |
| 使用说明 | TEXT | 否 | 富文本，告知用户如何输入 |
| 关联模型 | FK | 是 | 关联 ai_model_config |
| 关联知识库 | FK | 否 | 关联 kb_knowledge_base，开启 RAG |
| 系统提示词 | TEXT | 是 | 固定的 System Prompt |
| 用户提示词模板 | TEXT | 否 | 带变量模板，如 `请分析以下文本：{{input}}` |
| 输入变量定义 | JSON | 否 | 变量名与说明列表 |
| 最大输出 Token | INT | 否 | 默认 2048 |
| 温度参数 | DECIMAL(3,2) | 否 | 0.00-1.00，默认 0.70 |
| 是否支持多轮对话 | TINYINT | 是 | 0 单轮 / 1 多轮 |
| 场景状态 | VARCHAR(20) | 是 | DRAFT / ONLINE / OFFLINE |

## 3.3 AI 服务功能模块

### 3.3.1 智能对话

通用 AI 对话界面，支持多轮自由对话，适用于通用问答、日常助手等场景。

| 功能点 | 说明 |
|--------|------|
| 发送消息 | 文本输入，支持 Shift+Enter 换行，Enter 发送 |
| 流式输出 | AI 回复以打字机效果逐字呈现（SSE / WebSocket） |
| 新建会话 | 开启新对话，不继承历史上下文 |
| 历史会话 | 左侧列表，点击可继续对话 |
| 消息复制 | 一键复制单条 AI 回复 |
| 停止生成 | 点击按钮中断正在生成的回复 |
| Markdown 渲染 | 支持代码高亮、表格、列表等格式化展示 |
| 会话重命名 | 双击会话名称可编辑 |
| 删除会话 | 删除历史对话记录 |

### 3.3.2 场景应用中心

| 功能点 | 说明 |
|--------|------|
| 场景广场 | 卡片形式展示所有当前用户有权使用的已上架场景 |
| 分类过滤 | 按场景分类标签过滤展示 |
| 场景搜索 | 按名称/描述关键字搜索 |
| 进入场景 | 点击场景卡片进入对应 AI 操作页 |
| 收藏场景 | 收藏常用场景，在个人工作台快速访问 |
| 我的工作台 | 展示用户收藏的场景列表 |

### 3.3.3 文档分析

| 功能点 | 说明 |
|--------|------|
| 文档上传 | 支持 PDF/Word/TXT，单文件 ≤ 20MB |
| 内容解析 | 自动提取文档文本内容（Apache POI + PDFBox） |
| 智能摘要 | 一键生成文档核心内容摘要 |
| 关键信息提取 | 按预设模板提取合同要素、报告关键指标等 |
| 文档问答 | 针对已上传文档进行自然语言提问（单会话内有效） |
| 分析结果复制 | 一键复制分析结果 |

**支持格式：** `.pdf` / `.doc` / `.docx` / `.txt`

### 3.3.4 内容生成

| 功能点 | 说明 |
|--------|------|
| 选择模板场景 | 选择内容类型（工作汇报/产品介绍/会议邮件等） |
| 填写生成参数 | 根据场景变量定义填写关键信息 |
| 一键生成 | 提交后由 AI 流式生成完整内容 |
| 结果在线编辑 | 生成结果支持二次编辑 |
| 重新生成 | 不满意可重新触发生成 |
| 导出内容 | 导出为 TXT 或复制到剪贴板 |

## 3.4 知识库管理模块

企业私有知识库管理，通过向量化技术将文档转化为可检索知识片段，为 AI 提供精准领域知识支撑。

### 3.4.1 知识库管理

| 功能点 | 说明 |
|--------|------|
| 知识库列表 | 展示所有知识库及文档数量、状态 |
| 新建知识库 | 填写名称、描述，选择适用场景 |
| 编辑知识库 | 修改基本信息 |
| 删除知识库 | 同时删除其所有文档及向量数据 |

### 3.4.2 文档管理

| 功能点 | 说明 |
|--------|------|
| 文档列表 | 展示知识库内所有文档及解析状态 |
| 批量上传 | 支持 PDF/Word/TXT/Markdown，多文件同时上传 |
| 解析状态 | PENDING（排队中）/ PROCESSING（处理中）/ DONE（完成）/ FAILED（失败） |
| 重新解析 | FAILED 文档可触发重试 |
| 删除文档 | 删除文档文件及向量数据库中的对应向量 |

**支持格式：** `.pdf` / `.doc` / `.docx` / `.txt` / `.md`

### 3.4.3 知识检索测试

| 功能点 | 说明 |
|--------|------|
| 输入测试问题 | 输入问题验证知识库检索效果 |
| 召回片段展示 | 展示相关度最高的知识片段（默认 Top5）及相似度分数 |
| 参数调整 | 调整 TopK（1-20）与相似度阈值（0.00-1.00） |

## 3.6 API 管理模块

### 3.6.1 AI 模型配置

| 功能点 | 说明 |
|--------|------|
| 模型列表 | 展示已配置的 AI 模型（名称/提供商/状态） |
| 新增模型 | 配置模型接入信息 |
| 编辑模型 | 修改模型配置 |
| 启用/禁用 | 禁用后该模型不可被场景选用 |
| 连通性测试 | 验证 API 密钥与接口是否正常连通 |

**模型配置字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 模型名称 | VARCHAR(128) | 是 | 显示名，如：GPT-4o |
| 模型标识 | VARCHAR(128) | 是 | API 中使用的 model ID |
| 服务提供商 | VARCHAR(32) | 是 | OpenAI / Azure OpenAI / 通义千问 / 文心一言 / 其他 |
| API 地址 | VARCHAR(512) | 是 | 接口 URL |
| API 密钥 | VARCHAR(512) | 是 | AES 加密存储，接口返回时脱敏（末尾4位可见） |
| 最大上下文 Token | INT | 否 | 模型支持的最大上下文长度 |
| 备注 | VARCHAR(255) | 否 | |
| 状态 | TINYINT | 是 | 0 禁用 / 1 启用 |

## 3.7 统计报表模块

### 3.7.1 使用量看板

| 指标名称 | 图表类型 | 说明 |
|----------|----------|------|
| 今日调用总次数 | 数字卡片 | 实时刷新 |

| 功能点 | 说明 |
