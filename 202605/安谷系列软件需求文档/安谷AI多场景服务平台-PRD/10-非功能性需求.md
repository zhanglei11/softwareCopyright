# 十、非功能性需求

## 10.1 性能指标

| 指标 | 要求 |
|------|------|
| 页面首次加载 | ≤ 3s |
| AI 接口首字延迟 | ≤ 5s（取决于下游模型，超时告警） |
| 文件上传（20MB） | ≤ 60s |
| 知识库文档解析（5MB） | ≤ 120s |
| 管理页面列表加载（<1000条） | P99 ≤ 1s |
| 并发在线用户 | 支持 100 用户同时在线 |
| AI 模型接口超时阈值 | 30s，超时标记失败并记录日志 |

## 10.2 安全需求

| 类别 | 要求 |
|------|------|
| 身份认证 | 账号密码 + 图形验证码；JWT 双 Token（accessToken 8h + refreshToken 7d） |
| 密码安全 | BCrypt 加密存储；强制复杂度：8位+大小写+数字+特殊字符 |
| 会话锁定 | 连续 5 次密码错误锁定 30 分钟 |
| API 密钥保护 | AES 加密存储；接口返回时脱敏（仅末尾4位明文） |
| RBAC 授权 | 未授权请求返回 403 |
| 调用限流 | 支持按用户设置每日调用次数上限（`daily_limit`） |
| 输入过滤 | 用户输入经基础 XSS/SQL 注入过滤；JPA 参数化查询 |
| HTTPS | 生产环境强制 TLS 1.2+ |
| 操作审计 | 记录关键操作日志（配置变更/用户管理/数据导出），保留 12 个月 |
| 敏感字段脱敏 | 手机号、邮箱在列表页部分脱敏 |

## 10.3 兼容性需求

| 维度 | 要求 |
|------|------|
| 浏览器 | Chrome / Edge / Firefox 最新版及向前 2 个主版本 |
| 分辨率 | 最低 1280×800 |
| 终端 | PC 端，暂不要求移动端适配 |

## 10.4 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Vue 3 + Element Plus | Vite 构建 |
| 后端框架 | Spring Boot 3.x | |
| 数据库 | MySQL 8.0 | |
| 向量数据库 | Milvus 或 Chroma | 知识库检索 |
| 缓存 | Redis | 会话/验证码/调用计数/分布式锁 |
| 文件存储 | 本地存储 / 阿里云 OSS | 可配置切换 |
| AI 接入层 | LangChain4j 或 Spring AI | RAG 检索增强生成 |
| 权限框架 | Sa-Token | |
| 文档解析 | Apache POI + PDFBox | Word/PDF 解析 |
| 流式输出 | SSE（Server-Sent Events） | AI 打字机效果 |
| 接口文档 | OpenAPI 3.0（Swagger UI） | |
