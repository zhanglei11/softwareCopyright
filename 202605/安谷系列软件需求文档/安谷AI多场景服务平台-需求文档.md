## 一、项目概述

### 1.1 项目背景

随着大型语言模型（LLM）技术的快速发展，AI能力正在向各行各业渗透。企业在日常运营中面临大量重复性、知识密集型任务，需要借助AI提升工作效率。安谷AI多场景服务平台旨在将AI能力与企业实际业务场景深度融合，提供覆盖对话问答、文档处理、内容生成等多种应用场景的统一服务平台，降低AI能力使用门槛，让业务人员无需技术背景即可便捷使用AI工具。

### 1.2 项目目标

- 构建支持多种AI应用场景的统一服务平台
- 提供可视化的AI场景配置与管理能力
- 支持知识库建设，实现企业私有知识的AI化检索
- 内置用户、账号、权限、菜单等基础管理功能
- 记录AI服务调用情况，提供用量统计与分析

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** angu-ai-service-platform-web
- **后端仓库名：** angu-ai-service-platform
- **开发库名：** angu_ai_service_platform_dev
- **目标用户：** 企业员工（AI服务使用者）、AI管理员（场景配置）、系统管理员
- **运行环境：** 主流浏览器（Chrome、Edge、Firefox）

## 三、功能模块详细说明

### 3.1 基础管理模块

#### 3.1.1 用户管理

**功能描述：** 对平台使用人员进行统一管理，支持用户全生命周期操作。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 用户列表 | 分页展示用户，支持按姓名、账号、状态、角色筛选 |
| 新增用户 | 填写基本信息，分配角色及可使用的AI场景权限 |
| 编辑用户 | 修改用户信息与角色 |
| 删除用户 | 逻辑删除，保留历史记录 |
| 启用/禁用 | 控制用户访问权限 |
| 重置密码 | 管理员为用户重置密码 |
| 查看用量 | 查看指定用户的AI调用使用情况 |

**用户字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 用户姓名 | 文本 | 是 | |
| 登录账号 | 文本 | 是 | 唯一，6-20位字母数字 |
| 登录密码 | 文本 | 是 | 加密存储，8位以上 |
| 手机号码 | 文本 | 是 | |
| 邮箱地址 | 文本 | 否 | |
| 所属部门 | 文本 | 否 | |
| 用户角色 | 多选 | 是 | |
| 每日调用限额 | 数字 | 否 | 限制单用户每日AI调用次数，空则不限 |
| 用户状态 | 枚举 | 是 | 启用/禁用 |

#### 3.1.2 角色管理

**功能描述：** 基于RBAC模型管理系统角色，将功能菜单权限与AI场景使用权限绑定到角色。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 角色列表 | 展示所有角色 |
| 新增角色 | 配置角色名称、描述，分配菜单权限 |
| 编辑角色 | 修改角色配置 |
| 删除角色 | 删除未关联用户的角色 |
| 菜单权限配置 | 树形勾选可访问菜单与操作按钮 |
| 场景权限配置 | 配置该角色可使用的AI场景列表 |

**预设角色：**

| 角色名称 | 说明 |
|----------|------|
| 超级管理员 | 拥有全部权限，系统内置 |
| AI管理员 | 负责AI场景、知识库、模型配置的管理 |
| 普通用户 | 使用已授权的AI服务场景 |

#### 3.1.3 权限管理

**功能描述：** 对系统操作权限进行细粒度控制，支持菜单级和按钮级权限。

| 权限类型 | 说明 |
|----------|------|
| 菜单权限 | 控制侧边栏菜单可见性 |
| 操作权限 | 控制新增、编辑、删除、发布等按钮级权限 |
| 场景权限 | 控制用户可使用的AI应用场景 |

#### 3.1.4 菜单管理

**功能描述：** 动态维护系统导航菜单，支持多级菜单配置。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 菜单列表 | 树形结构展示 |
| 新增菜单 | 配置菜单名称、图标、路径、类型、排序 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 删除叶子节点菜单 |
| 菜单排序 | 调整同级菜单顺序 |

### 3.2 AI场景管理模块

#### 3.2.1 场景分类管理

**功能描述：** 对AI应用场景进行分类组织，便于用户快速找到所需工具。

| 功能点 | 说明 |
|--------|------|
| 分类列表 | 展示所有场景分类 |
| 新增分类 | 填写分类名称、图标、排序 |
| 编辑分类 | 修改分类信息 |
| 删除分类 | 删除空分类 |

**内置分类示例：**

| 分类名称 | 说明 |
|----------|------|
| 智能对话 | 通用对话类AI场景 |
| 文档处理 | 文档分析、摘要、问答 |
| 内容创作 | 文章、报告、邮件生成 |
| 知识问答 | 基于知识库的精准问答 |
| 数据分析 | 数据解读与图表说明 |

#### 3.2.2 AI场景配置

**功能描述：** 创建和管理具体的AI应用场景，每个场景对应一个特定的AI使用模式与提示词配置。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 场景列表 | 展示所有已配置场景，支持按分类、状态筛选 |
| 新增场景 | 填写场景基本信息并配置提示词与参数 |
| 编辑场景 | 修改场景配置 |
| 上架/下架 | 控制场景对用户是否可见 |
| 删除场景 | 删除已下架场景 |
| 场景预览 | 管理员在保存前可预览测试场景效果 |

**场景配置字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 场景名称 | 文本 | 是 | 如：会议纪要生成助手 |
| 场景分类 | 下拉 | 是 | 关联场景分类 |
| 场景图标 | 图片/图标 | 否 | 展示用图标 |
| 场景描述 | 文本域 | 是 | 简要说明场景用途 |
| 使用说明 | 富文本 | 否 | 告知用户如何输入 |
| 关联模型 | 下拉 | 是 | 选择底层AI模型 |
| 关联知识库 | 下拉 | 否 | 若需要RAG检索则关联知识库 |
| 系统提示词 | 文本域 | 是 | 固定的 System Prompt |
| 用户提示词模板 | 文本域 | 否 | 带变量的用户输入模板，如：`请分析以下文本：{{input}}` |
| 输入变量定义 | 动态列表 | 否 | 定义模板中的变量名与说明 |
| 最大输出Token | 数字 | 否 | 控制单次输出长度 |
| 温度参数 | 滑块 | 否 | 0-1，控制输出随机性 |
| 是否支持多轮对话 | 开关 | 是 | 开启后保留上下文 |
| 场景状态 | 枚举 | 是 | 草稿/已上架/已下架 |

### 3.3 AI服务功能模块

#### 3.3.1 智能对话

**功能描述：** 通用AI对话界面，支持多轮自由对话，适用于通用问答、日常助手等场景。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 发送消息 | 输入框发送文本消息，支持 Shift+Enter 换行 |
| 流式输出 | AI回复以打字机效果逐步呈现 |
| 新建会话 | 开启新的对话，不继承历史上下文 |
| 历史会话 | 左侧展示历史会话列表，点击可继续对话 |
| 消息复制 | 一键复制单条AI回复内容 |
| 停止生成 | 点击停止按钮中断正在生成的回复 |
| Markdown渲染 | AI输出内容支持Markdown格式化展示（代码高亮、表格等） |
| 会话重命名 | 双击会话名称可编辑 |
| 删除会话 | 删除历史会话记录 |

#### 3.3.2 场景应用中心

**功能描述：** 展示所有已上架且当前用户有权限使用的AI场景，用户可快速进入场景开始使用。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 场景广场 | 以卡片形式展示所有可用场景，支持按分类过滤 |
| 场景搜索 | 按场景名称/描述关键字搜索 |
| 进入场景 | 点击场景卡片进入对应的AI操作页面 |
| 收藏场景 | 收藏常用场景，在个人工作台快速访问 |
| 我的工作台 | 展示用户收藏的场景 |

#### 3.3.3 文档分析

**功能描述：** 上传文档后，AI对文档内容进行智能分析，支持文档摘要、关键信息提取与内容问答。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 文档上传 | 支持 PDF、Word、TXT 格式，单文件不超过20MB |
| 内容解析 | 自动提取文档文本内容 |
| 智能摘要 | 一键生成文档核心内容摘要 |
| 关键信息提取 | 按预设模板提取合同要素、报告关键指标等 |
| 文档问答 | 针对已上传文档进行自然语言提问 |
| 分析结果复制 | 一键复制分析结果 |

**支持文档格式：** `.pdf` / `.doc` / `.docx` / `.txt`

#### 3.3.4 内容生成

**功能描述：** 基于预设场景模板，填写关键参数后由AI生成规范化内容，如邮件、报告、通知等。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 选择模板场景 | 选择内容类型（如：工作汇报、产品介绍、会议邮件） |
| 填写生成参数 | 根据场景定义的变量填写关键信息 |
| 一键生成 | 提交后由AI生成完整内容 |
| 结果编辑 | 生成结果支持在线二次编辑 |
| 重新生成 | 不满意可重新生成 |
| 导出内容 | 导出为 TXT 或复制到剪贴板 |

### 3.4 知识库管理模块

**功能描述：** 企业私有知识库管理，通过向量化技术将文档转化为可检索的知识片段，为AI提供精准的领域知识支撑。

#### 3.4.1 知识库管理

| 功能点 | 说明 |
|--------|------|
| 知识库列表 | 展示所有知识库及其文档数量、状态 |
| 新建知识库 | 填写知识库名称、描述，选择适用场景 |
| 编辑知识库 | 修改基本信息 |
| 删除知识库 | 删除知识库及其所有文档 |

#### 3.4.2 文档管理

| 功能点 | 说明 |
|--------|------|
| 文档列表 | 展示知识库内所有文档 |
| 上传文档 | 支持批量上传 PDF、Word、TXT、Markdown 文件 |
| 文档解析状态 | 展示文档向量化处理进度（处理中/完成/失败） |
| 删除文档 | 从知识库中删除文档及其向量数据 |

#### 3.4.3 知识检索测试

| 功能点 | 说明 |
|--------|------|
| 输入测试问题 | 输入问题验证知识库检索效果 |
| 查看召回片段 | 展示相关度最高的知识片段及其相似度分数 |
| 参数调整 | 调整检索数量（TopK）与相似度阈值 |

### 3.6 API管理模块

#### 3.6.1 AI模型配置

**功能描述：** 管理平台接入的底层AI大语言模型，支持多模型配置，各场景可灵活选用。

| 功能点 | 说明 |
|--------|------|

| 连通性测试 | 验证API密钥与接口是否正常连通 |

**模型配置字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 模型名称 | 文本 | 是 | 显示名称，如：GPT-4o |
| 模型标识 | 文本 | 是 | API中使用的模型ID |
| 服务提供商 | 下拉 | 是 | OpenAI / Azure OpenAI / 通义千问 / 文心一言 / 其他 |
| API地址 | 文本 | 是 | 接口URL |
| API密钥 | 密文 | 是 | 加密存储，展示时脱敏 |
| 最大上下文Token | 数字 | 否 | 模型支持的最大上下文长度 |
| 备注 | 文本 | 否 | |

## 四、非功能性需求

### 4.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面首次加载 | ≤ 3秒 |
| AI接口响应首字延迟 | ≤ 5秒（取决于下游模型） |
| 文件上传（20MB） | ≤ 60秒 |
| 并发在线用户 | 支持100用户同时在线 |

### 4.2 安全需求

| 要求 | 说明 |
|------|------|
| 身份认证 | 账号密码登录 + 图形验证码 |
| 会话管理 | JWT Token，默认8小时过期 |
| 密码安全 | BCrypt加密存储，强制复杂度 |
| API密钥保护 | 模型API密钥加密存储，接口返回时脱敏 |
| 操作审计 | 记录关键操作日志（配置变更、用户管理、数据导出） |
| 调用限流 | 支持按用户设置每日调用次数上限 |
| 输入过滤 | 对用户输入进行基础安全过滤，防止注入类攻击 |

### 4.3 兼容性需求

| 浏览器 | 版本要求 |
|--------|----------|
| Chrome | 最新版及往前2个主版本 |
| Edge | 最新版及往前2个主版本 |
| Firefox | 最新版及往前2个主版本 |
