# 四、业务边界

## 4.1 系统内部边界

| 边界说明 | 处理方式 |
|----------|----------|
| 已关闭的职位不接收新投递 | 接口层拦截，返回 400 |
| 同一简历对同一职位不可重复投递 | 查重后提示，不允许创建重复投递 |
| 逻辑删除简历后关联投递记录保留 | 投递记录展示"简历已删除"占位符 |
| 删除角色须先解绑所有用户 | 接口层校验，有绑定用户时返回 409 |
| 内置角色（SUPER_ADMIN 等）不可删除 | 接口层校验，返回 403 |
| 有子菜单的菜单不可删除 | 接口层校验，返回 400 |

## 4.2 系统外部边界（本期不涉及）

- 不对接外部招聘平台（BOSS 直聘、智联招聘等）
- 不提供候选人自助投递入口
- 不集成邮件/短信通知发送
