# 七、异常流程

| 场景 | HTTP状态码 | 处理逻辑 |
|------|-----------|----------|
| 登录密码错误 ≥ 5 次 | 423 | 账号锁定 30 分钟，提示"账号已锁定，请 30 分钟后重试" |
| Access Token 过期 | 401 | 前端自动用 refreshToken 换新 token |
| Refresh Token 过期 | 401 | 前端跳转登录页 |
| 简历文件解析失败 | 200 | 不阻断流程，返回空 parseResult + parseSuccess=false，提示手动填写 |
| 上传文件格式不支持 | 400 | 提示"仅支持 PDF、DOC、DOCX 格式" |
| 文件大小超限（>10MB） | 400 | 提示"文件大小不能超过 10MB" |
| 投递时职位已关闭 | 400 | 提示"该职位已关闭，无法创建投递" |
| 重复投递同一职位 | 409 | 提示"该简历已投递此职位，当前状态：xxx" |
| 删除有绑定用户的角色 | 409 | 提示"该角色下有 N 个用户，请先解绑用户" |
| 删除有子菜单的菜单项 | 400 | 提示"请先删除子菜单" |
| 权重配置总和 ≠ 100% | 422 | 提示"各维度权重总和必须等于 100%" |
| 无操作权限 | 403 | 提示"无权限执行此操作" |
| 服务器内部错误 | 500 | 提示"系统异常，请联系管理员" |
