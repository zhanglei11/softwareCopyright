# 一、背景与目标

## 1.1 背景

企业招聘规模扩大，传统人工筛选简历效率低、成本高、主观性强，难以实现精准人岗匹配。HR 每天需要处理大量简历，关键信息散落在多种格式文件中，缺乏统一的结构化管理与智能辅助决策能力。

## 1.2 目标

| 目标 | 衡量指标 |
|------|----------|
| 简历处理效率提升 | HR 筛选候选人时间缩短 50% |
| 匹配准确率 | 智能匹配推荐候选人进入面试率 ≥ 60% |
| 流程可追踪 | 从投递到录用全程状态可查，无断点 |
| 数据决策支撑 | 提供多维度招聘漏斗与来源分析报表 |

## 1.3 系统定位

- **类型：** PC 端 Web 应用（内部管理系统）
- **前端仓库名：** angu-resume-job-matcher-web
- **后端仓库名：** angu-resume-job-matcher
- **开发库名：** angu_resume_job_matcher_dev
- **目标用户：** HR 专员、招聘负责人、系统管理员
- **运行环境：** Chrome / Edge / Firefox 最新版及往前 2 个主版本
