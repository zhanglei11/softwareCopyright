## 1. 系统介绍

跨场景影像传感数据融合与决策支持系统是一套面向多传感器数据融合与智能决策业务场景的专业分析平台，围绕传感器数据源接入、多传感器数据融合方案配置、融合结果管理、决策规则引擎及多维度统计分析的完整闭环流程，支持多种场景下的跨传感器数据融合与自动化决策，实现传感数据的高效处理与智能决策支持。

核心能力：

- 多类型传感数据源统一接入与状态监控（摄像头、雷达、激光雷达、GPS 等）
- 融合方案全生命周期管理（方案配置、多算法支持、权重与预处理规则）
- 融合结果存储与查询（数据质量评分、原始融合数据可视化）
- 决策规则引擎（阈值规则、逻辑规则、机器学习规则，支持优先级排序）
- 决策结果全链路溯源（触发值、溯源信息、置信度追踪）
- 统计分析看板（融合执行趋势、决策命中分布、按粒度聚合分析）
- 系统管理（用户、角色、菜单、操作权限）

## 4. 数据源管理

功能说明：统一管理系统接入的传感器数据源，支持新增、编辑、状态切换与连接测试。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 搜索数据源 | 搜索 | 按数据源名称、启用状态筛选列表。 |
| 重置筛选 | 重置 | 清空筛选条件并刷新列表。 |
| 新增数据源 | 新增数据源 | 填写数据源信息（名称、类型、连接地址、状态等）后保存。 |
| 编辑数据源 | 编辑 | 修改数据源名称、连接配置等信息。 |
| 切换启用状态 | 启用/禁用开关 | 启用后数据源参与融合方案；禁用后不再被新方案引用。 |
| 测试连接 | 测试连接 | 验证数据源连接地址是否可达，返回连通性测试结果。 |
| 删除数据源 | 删除 | 永久删除数据源配置，操作前需二次确认。 |

数据源类型说明：

- 摄像头（CAMERA）：视觉影像传感器，采集图像/视频流数据。
- 雷达（RADAR）：毫米波雷达传感器，采集目标距离与速度数据。
- 激光雷达（LIDAR）：激光点云传感器，采集三维空间扫描数据。
- GPS：定位传感器，采集坐标与时间戳数据。
- 其他（OTHER）：其他类型传感器。

连接状态说明：

- 在线（绿色）：数据源当前连接正常，可正常接收数据。
- 离线（红色）：数据源连接已断开，需检查网络或设备状态。
- 未知（灰色）：数据源尚未完成连接检测。

操作结果：

数据源配置完成，可在融合方案中引用。

## 5. 融合方案

### 5.1 方案列表

功能说明：管理多传感器数据融合方案，包括方案创建、融合算法选择及规则权重配置。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 搜索方案 | 搜索 | 按方案名称、启用状态筛选列表。 |
| 重置筛选 | 重置 | 清空筛选条件并刷新列表。 |
| 新增方案 | 新增方案 | 填写方案名称、融合算法、描述等信息后保存。 |
| 编辑方案 | 编辑 | 修改方案基础信息与算法配置。 |
| 规则配置 | 规则配置 | 打开规则配置抽屉，管理该方案下各数据源的权重与预处理规则。 |
| 切换启用状态 | 启用/禁用开关 | 启用后方案参与融合执行；禁用后不再触发融合流程。 |
| 删除方案 | 删除 | 永久删除融合方案，操作前需二次确认。 |

融合算法说明：

- 加权平均（WEIGHTED_AVG）：按各数据源配置的权重值对多路数据求加权平均，适用于同类传感器数据合并。
- 卡尔曼滤波（KALMAN）：基于状态预测与观测更新的动态融合算法，适用于连续时间序列数据（如 GPS 与加速度计融合）。
- D-S 证据理论（DEMPSTER_SHAFER）：基于信度函数的不确定性推理融合方法，适用于多源异构数据的置信度合成。

操作结果：

融合方案配置完成，系统将按方案规则自动执行多传感器数据融合。

## 7. 决策规则

功能说明：管理系统内的智能决策规则，支持多种规则类型配置，按优先级触发对应决策动作。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 搜索规则 | 搜索 | 按规则名称、启用状态筛选列表。 |
| 重置筛选 | 重置 | 清空筛选条件并刷新列表。 |
| 新增规则 | 新增规则 | 填写规则名称、类型、关联方案、优先级、规则表达式、决策动作与描述后保存。 |
| 编辑规则 | 编辑 | 修改规则的配置信息与表达式内容。 |
| 切换启用状态 | 启用/禁用开关 | 启用后规则参与实时决策评估；禁用后跳过该规则。 |
| 删除规则 | 删除 | 永久删除决策规则，操作前需二次确认。 |

规则类型说明：

- 阈值规则（THRESHOLD）：当融合数据的某项指标超过预设阈值时触发决策，如速度超限、温度异常等。
- 逻辑规则（LOGIC）：基于布尔逻辑表达式（AND/OR/NOT 组合）对多项指标进行联合判断后触发决策。
- 机器学习（ML）：调用预训练机器学习模型对融合数据进行推理，输出决策分类结果。

字段说明：

- 关联方案 ID：规则评估时所依赖的融合方案，决策输入来自该方案的融合结果。
- 优先级：数字越小优先级越高，多条规则同时满足时按优先级顺序执行。
- 规则表达式：定义触发条件的逻辑表达式或配置 JSON。
- 决策动作：规则命中后执行的动作描述（如告警通知、状态标记、联动控制等）。

操作结果：

规则配置完成后，系统实时对融合数据进行评估，命中规则后自动生成决策结果记录。

| 操作 | 点击按钮 | 说明 |

| 溯源 | 溯源 | 查看触发本条决策的完整溯源链路，展示从融合数据到规则触发的完整上下文信息。 |

列表字段说明：

- ID：决策结果唯一标识

## 9. 统计分析

功能说明：按时间范围与统计粒度查询融合执行与决策执行的汇总统计数据，支持每日/每小时粒度切换，展示趋势表格与规则命中分布。

| 操作 | 点击按钮 | 说明 |
| --- | --- | --- |
| 设置时间范围 | 时间范围选择器 | 选择开始日期与结束日期，不填则查询全量历史数据。 |
| 切换统计粒度 | 按天 / 按小时 | 选择按天或按小时聚合统计数据。 |
| 查询统计 | 查询 | 按所选条件刷新统计数据。 |
| 重置条件 | 重置 | 清空查询条件并恢复默认统计。 |

**融合执行统计**

| 指标 | 说明 |
| --- | --- |
| 总执行次数 | 所选时间范围内融合方案的执行总次数 |
| 成功次数 | 执行成功（融合数据正常输出）的次数 |
| 失败次数 | 执行异常或未正常输出的次数 |
| 成功率 | 成功次数占总执行次数的百分比 |
| 每日趋势表格 | 按日期展示各天的总执行次数（cnt）与成功次数（success_cnt） |

**决策执行统计**

| 指标 | 说明 |
| --- | --- |
| 总触发次数 | 所选时间范围内决策规则的总触发次数 |
| 平均响应时长 | 所有规则触发到决策输出的平均耗时（秒） |
| 规则命中分布表格 | 按规则名称展示各规则的触发次数，用于分析高频触发规则 |

操作结果：

全局掌握融合与决策业务整体执行质量，为规则优化与方案调整提供数据支撑。

- 按钮（F）：页面内的细粒度操作权限（如新增、编辑、删除），不展示在导航中。

操作结果：

导航结构与权限配置更新完成，刷新后对关联角色生效。

## 11. 常见问题

### 11.1 登录后跳回登录页

排查建议：

- 检查后端服务是否可达（默认端口 19014）
- 检查 Token 是否失效，尝试重新登录
- 清空浏览器本地存储（localStorage）后重新登录

### 11.2 仪表盘数据源全部显示为0

排查建议：

- 检查后端 `/api/datasource/status-overview` 接口是否正常返回
- 确认数据库中存在已配置的数据源记录
- 检查数据源的 `connStatus` 字段是否有效（1=在线，0=离线）

### 11.3 融合方案中规则配置无法保存

排查建议：

- 确认数据源 ID 填写正确，且数据库中存在对应的数据源记录
- 权重字段需为 0~1 之间的小数
- 预处理规则若填写，确认为合法 JSON 格式

### 11.4 创建融合方案后未见融合结果生成

排查建议：

- 确认方案状态已切换为"启用"
- 确认方案下已配置至少一条数据源规则
- 查看后端日志（默认路径 logs/sfd-app.log）确认是否有融合执行异常
- 确认数据源当前连接状态为"在线"

### 11.5 决策规则已启用但无决策结果生成

排查建议：

- 确认规则关联的融合方案 ID 正确，且该方案已启用并正常产生融合结果
- 检查规则表达式是否语法正确，可通过后端日志查看规则解析异常
- 确认融合数据的字段与规则表达式中引用的字段名一致

### 11.6 统计分析页面图表/表格无数据

排查建议：

- 确认所选时间范围内存在融合或决策执行记录
- 尝试清空时间条件查询全量数据，确认系统是否存在历史数据
- 检查 `/api/stats/fusion/summary` 或 `/api/stats/decision/summary` 接口返回是否正常

### 11.7 决策结果溯源信息为空

排查建议：

- 溯源信息依赖融合执行时写入的上下文数据，确认后端融合服务在执行时已正确记录 `traceInfo` 字段
- 查看后端日志确认融合执行链路是否完整无误
- 部分旧版数据若创建时未记录溯源字段，溯源信息将显示为空，属正常情况

### 11.8 页面提示无权限

排查建议：

- 检查当前用户角色是否具备对应菜单权限
- 检查角色菜单中是否已关联对应操作按钮权限节点
- 重新登录以刷新最新权限信息

### 11.9 数据源测试连接失败

排查建议：

- 确认传感器设备当前处于开机并正常工作状态
- 检查连接地址（IP/端口）填写是否正确
- 确认后端服务所在服务器与传感器设备之间的网络路由正常，防火墙未屏蔽对应端口
