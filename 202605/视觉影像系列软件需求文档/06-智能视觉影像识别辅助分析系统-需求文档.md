# 智能视觉影像识别辅助分析系统
## 软件需求文档 v1.0

---

## 一、系统概述

### 1.1 项目背景

随着深度学习与计算机视觉技术的成熟，工业场景中的影像识别能力已大幅提升。然而，识别结果的解读、标注管理与分析汇总往往依赖人工处理，效率低下。智能视觉影像识别辅助分析系统以影像管理为基础，整合识别任务调度、结果呈现与标注、辅助分析报告等能力，帮助算法工程师与影像分析员高效管理识别工作流，快速洞察识别结果，提升智能视觉应用落地效率。

### 1.2 系统目标

- 统一管理待识别影像，支持上传、分类与浏览
- 支持识别任务的创建、提交与状态追踪
- 展示识别结果，支持人工标注与结果修正
- 生成辅助分析报告，提供置信度与识别汇总数据
- 管理模型版本信息，跟踪模型迭代
- 集成用户权限管理，实现多角色分级访问控制

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** smart-vision-analysis-web
- **后端仓库名：** smart-vision-analysis
- **开发库名：** smart_vision_analysis_dev

### 1.4 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 系统管理员 | 用户管理、权限配置、系统参数设置 |
| 算法工程师 | 模型版本管理、识别任务配置、结果分析 |
| 影像分析员 | 影像上传、识别任务提交、结果标注与查看 |
| 只读用户 | 查看识别结果与分析报告，不可修改 |

### 1.5 运行环境

- **客户端**：PC Web 浏览器（Chrome 90+、Edge 90+）
- **操作系统**：Windows 10 及以上
- **分辨率**：1920×1080 及以上

## 三、基础管理模块

### 3.1 用户管理

#### 3.1.1 功能描述

系统管理员对平台用户账号进行全生命周期管理。

#### 3.1.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 用户列表 | 分页展示用户，支持按姓名、账号、角色、状态筛选 |
| 新增用户 | 填写姓名、账号、手机号、部门、初始密码，绑定角色 |
| 编辑用户 | 修改用户基本信息及关联角色 |
| 禁用/启用 | 切换账号状态，禁用后不可登录 |
| 重置密码 | 重置为系统默认初始密码 |
| 删除用户 | 逻辑删除，操作日志保留 |

#### 3.1.3 字段规则

- 登录账号：6~20 位字母数字，全局唯一
- 密码：8~20 位，须包含大小写字母与数字
- 手机号：11 位国内手机号格式校验

### 3.2 角色管理

| 功能项 | 描述 |
|--------|------|
| 角色列表 | 展示角色名称、标识、状态、关联用户数 |
| 新增角色 | 填写名称、标识、描述 |
| 角色授权 | 为角色分配菜单权限与按钮权限 |
| 删除角色 | 仅允许删除无绑定用户的角色 |

**内置角色：**

| 角色名称 | 标识 | 权限范围 |
|---------|------|---------|
| 超级管理员 | SUPER_ADMIN | 全部权限 |
| 算法工程师 | ALGO_ENG | 模型管理、任务配置、结果分析全权限 |
| 影像分析员 | IMG_ANALYST | 影像管理、任务提交、结果标注 |
| 只读用户 | READONLY | 结果查看、报告只读 |

### 3.3 权限管理

采用 RBAC 模型，支持菜单级、按钮级权限控制。

| 权限层级 | 说明 |
|---------|------|
| 菜单权限 | 控制导航菜单的可见性 |
| 按钮权限 | 控制新增、编辑、删除、导出按钮的可见性 |

### 3.4 菜单管理

| 功能项 | 描述 |
|--------|------|
| 菜单树展示 | 树形展示目录、菜单、按钮节点 |
| 新增菜单 | 选择节点类型，填写名称、路径、图标、排序 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 仅可删除无子节点的叶子菜单 |

## 四、影像管理模块

### 4.1 影像上传

支持将待识别影像批量上传至系统。

| 字段 | 说明 |
|------|------|
| 影像编号 | 系统自动生成 |
| 文件名 | 原始文件名，自动获取 |
| 所属分类 | 关联影像分类 |
| 文件格式 | JPEG / PNG / BMP（系统校验）|
| 文件大小 | 自动获取，单个文件不超过 50MB |
| 上传人 | 自动记录当前用户 |
| 上传时间 | 自动记录 |
| 备注 | 可选填写 |

**功能：** 单张上传、批量上传（ZIP 解压入库）、上传进度展示、上传结果汇总（成功数/失败数）。

### 4.2 影像分类管理

定义和维护影像的分类目录，便于分类存储与筛选查询。

| 字段 | 说明 |
|------|------|
| 分类编号 | 系统自动生成 |
| 分类名称 | 如：焊点影像、包装外观、标签识别 |
| 父级分类 | 支持二级分类结构 |
| 影像数量 | 该分类下的影像总数（只读）|
| 创建人 | 自动记录 |

**功能：** 新增分类、编辑分类名称、删除空分类（有影像的分类不可删除）、分类树展示。

### 4.3 影像浏览与查询

| 筛选条件 | 说明 |
|---------|------|
| 影像分类 | 树形选择 |
| 文件名 | 模糊搜索 |
| 上传时间 | 时间范围 |
| 上传人 | 下拉选择 |
| 识别状态 | 未识别 / 已识别 |

**展示方式：** 支持列表视图与缩略图视图切换。点击影像可在弹窗中预览大图。

## 五、识别任务管理模块

### 5.1 任务创建

创建影像识别任务，定义识别范围与模型配置。

| 字段 | 说明 |
|------|------|
| 任务编号 | 系统自动生成 |
| 任务名称 | 描述性名称 |
| 影像范围 | 按分类选择 或 手动勾选影像（支持多选）|
| 识别模型版本 | 关联模型版本 |
| 置信度阈值 | 识别结果采信的最低置信度（0.0~1.0）|
| 备注 | 任务说明 |
| 创建人 | 自动记录 |
| 状态 | 待提交 / 识别中 / 已完成 / 已取消 |

### 5.2 任务状态查询

查看正在执行或等待执行的识别任务。

- 展示任务名称、当前状态、进度（百分比）
- 已处理影像数 / 总影像数
- 预计完成时间
- 支持手动取消未开始的任务

### 5.3 任务历史记录

查询历次任务的执行情况。

| 筛选条件 | 说明 |
|---------|------|
| 任务名称 | 模糊搜索 |
| 模型版本 | 下拉选择 |
| 执行时间 | 时间范围 |
| 任务状态 | 多选筛选 |

**列表字段：** 任务编号、任务名称、模型版本、影像总数、完成时间、平均置信度、任务状态、操作

## 六、识别结果管理模块

### 6.1 结果查看与标注

查看每张影像的识别结果，并支持人工标注修正。

**结果展示内容：**

| 字段 | 说明 |
|------|------|
| 影像预览 | 显示原始影像，支持缩放与拖拽 |
| 识别框 | 在影像上叠加显示矩形识别框 |
| 识别标签 | 每个识别框的分类标签 |
| 置信度 | 每个识别结果的置信度数值 |
| 识别状态 | 待审核 / 已确认 / 已修正 |

**标注操作：**

| 操作 | 说明 |
|------|------|
| 添加标注框 | 在影像上手动拖拽绘制矩形框并添加标签 |
| 编辑标签 | 修改已有识别框的分类标签 |
| 删除识别框 | 删除误识别的框 |
| 确认结果 | 标记当前影像识别结果为已确认 |

### 6.2 结果审核

对识别结果进行批量审核，确认或驳回识别结论。

- 列表展示待审核影像及识别结果摘要（识别框数量、最低置信度）
- 批量选择并批量确认或标记为需修正
- 审核人与审核时间自动记录

## 七、辅助分析报告模块

### 7.1 单次任务分析报告

为每个已完成的识别任务生成分析报告。

**报告内容：**

| 分析项 | 说明 |
|--------|------|
| 任务基本信息 | 任务名称、模型版本、执行时间、影像总数 |
| 识别结果概况 | 识别成功数、识别失败数、平均置信度 |
| 置信度分布 | 直方图展示置信度区间分布（0.5~1.0 各段占比）|
| 各类别识别数量 | 各识别标签类别的数量统计 |
| 低置信度影像清单 | 置信度低于阈值的影像列表，支持跳转查看 |

**功能：** 查看报告详情，导出 PDF 或 Excel。

### 7.2 批量汇总报告

跨多个任务汇总分析识别结果趋势。

| 指标 | 说明 |
|------|------|
| 各任务平均置信度对比 | 柱状图 |
| 识别标签类别趋势 | 按时间段展示各类别识别数量变化 |
| 模型版本效果对比 | 不同模型版本的识别准确率对比 |
| 审核修正率趋势 | 人工修正占识别结果的比例变化 |

**功能：** 选择时间范围与任务范围，生成汇总报告，支持导出 Excel。

## 八、模型版本管理模块

### 8.1 模型信息维护

维护已部署识别模型的版本信息，供识别任务配置时引用。

| 字段 | 说明 |
|------|------|
| 模型编号 | 系统自动生成 |
| 模型名称 | 如：焊点缺陷检测模型 |
| 版本号 | 如：v1.0.0、v2.1.0 |
| 适用场景 | 模型的适用识别场景说明 |
| 支持识别类别 | 模型可识别的标签类别列表 |
| 发布时间 | 模型版本发布日期 |
| 状态 | 可用 / 已废弃 |
| 备注 | 版本更新说明 |

**功能：** 新增模型版本、编辑版本信息、废弃版本（已被任务使用的版本不可删除）。

### 8.2 版本列表查看

- 展示所有模型及其版本列表
- 支持按模型名称、状态筛选
- 点击版本可查看该版本的使用历史（关联的识别任务列表）

## 九、非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 ≤ 3 秒；影像缩略图列表加载 ≤ 3 秒 |
| 安全 | JWT 认证、操作日志全量记录、文件上传格式严格校验 |
| 可用性 | 系统可用率 ≥ 99%；批量操作前提供操作确认 |
| 兼容性 | 支持 Chrome、Edge 主流版本 |
| 数据 | 影像文件保留 2 年；识别结果数据保留 2 年 |
