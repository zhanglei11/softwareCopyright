## 一、背景与目标

### 1.1 背景

在工业生产、安防监控、智慧园区等多元应用场景中，影像传感设备（工业相机、CMOS 传感器、深度相机等）往往分布在不同区域，执行不同任务。由于设备种类繁杂、任务需求动态变化，各设备之间缺乏统一的调度协调机制，导致资源利用率低、任务冲突频繁、响应时效差。

**核心痛点**：
- 设备分散管理，缺乏统一视图，运维人员无法快速掌握设备整体状态
- 任务与设备之间依赖人工协调，分配效率低下，易出现冲突和漏分配
- 调度过程缺乏记录，出现问题难以溯源和追责
- 不同角色（管理员、运维、操作员）访问权限混乱，数据安全风险高

### 1.2 目标

**功能目标**：
- 统一管理不同场景下的影像传感设备，实时掌握设备状态
- 支持任务创建与设备手动匹配分配
- 提供可视化调度看板，监控任务执行进度
- 记录完整调度日志，支持历史任务回溯
- 集成用户权限管理，实现多角色分级访问控制

**业务目标（上线后）**：
- 设备资源利用率提升 20% 以上
- 任务分配响应时间从手工操作的分钟级降至秒级
- 调度日志 100% 可追溯，满足审计要求

**非目标（本期不涉及）**：
- 设备自动调度（AI 智能推荐分配）
- 设备远程控制（下发拍摄指令）
- 移动端 App

### 1.3 系统定位

- **类型：** PC 端 Web 应用（设备调度前端系统）
- **前端仓库名：** imaging-device-scheduler-web
- **后端仓库名：** imaging-device-scheduler
- **开发库名：** imaging_device_scheduler_dev

## 二、用户角色

| 角色 | 标识 | 描述 | 核心诉求 |
|------|------|------|----------|
| 超级管理员 | SUPER_ADMIN | 拥有全部权限 | 系统整体可控，权限分配灵活 |
| 调度管理员 | DISPATCH_ADMIN | 负责场景、设备、任务、调度全生命周期管理 | 高效分配设备资源，监控任务进度 |
| 设备运维人员 | DEVICE_OPS | 负责设备注册、状态维护、故障上报 | 快速定位设备问题，及时变更设备状态 |
| 业务操作员 | OPERATOR | 查看任务状态，查询调度记录 | 获取实时任务进展，支撑业务决策 |

## 四、运行环境

| 环境 | 要求 |
|------|------|
| 客户端 | PC Web 浏览器（Chrome 90+、Edge 90+） |
| 操作系统 | Windows 10 及以上 |
| 分辨率 | 1920×1080 及以上 |
| 后端技术栈 | Spring Boot 4.x |
| 数据库 | MySQL 9.x |
| 认证方式 | JWT（Access Token + Refresh Token） |

## 五、非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 ≤ 3 秒；设备状态刷新延迟 ≤ 5 秒；接口 P99 响应 < 500ms |
| 安全 | JWT 认证；操作日志全量记录；密码 BCrypt 加密存储；RBAC 权限控制 |
| 可用性 | 系统可用率 ≥ 99%；关键操作有二次确认提示 |
| 兼容性 | 支持 Chrome、Edge 主流版本（90+） |
| 数据保留 | 调度日志保留 1 年；任务记录保留 2 年 |
| 并发 | 支持 100 并发用户同时操作 |

## 七、统一接口规范说明

所有接口遵循以下规范：

**统一响应格式**：
```json
{
  "code": 200,
  "message": "ok",
  "data": { }
}
```

**分页响应格式**：
```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "total": 100,
    "page": 1,
    "pageSize": 10,
    "records": [ ]
  }
}
```

**标准错误码**：

| code | HTTP Status | 含义 |
|------|-------------|------|
| 200 | 200 | 成功 |
| 400 | 400 | 请求参数错误 |
| 401 | 401 | 未登录 / Token 无效 |
| 403 | 403 | 无权限 |
| 404 | 404 | 资源不存在 |
| 409 | 409 | 资源冲突（数据重复） |
| 422 | 422 | 业务规则校验失败 |
| 500 | 500 | 服务器内部错误 |
