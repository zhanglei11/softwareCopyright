# 统计报表模块 产品需求文档

> 所属系统：多场景影像传感设备资源协同调度系统
> 文档版本：V1.0 | 创建日期：2026-05-26

---

## 一、背景与目标

统计报表模块为管理层提供设备运行效率和任务完成质量的数据洞察，支持日/周/月多时间维度的数据分析和 Excel 报表导出。

**功能目标**：
- 提供设备在线率、利用率等核心效率指标的可视化统计
- 提供任务完成率、状态分布等任务质量指标统计
- 支持按时间维度和日期范围灵活查询
- 支持 Excel 报表导出

## 三、功能详细说明

### 3.1 设备利用率统计

**指标说明**：

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| 设备在线率 | 在线时长 ÷ 统计周期总时长 × 100% | 在线时长 = 状态为在线或占用中的累计时长 |
| 设备利用率 | 任务占用时长 ÷ 在线时长 × 100% | 任务占用时长 = 设备处于"占用中"状态的累计时长 |
| 故障次数 | 统计周期内故障记录条数 | 按设备维度统计 |

**时间维度**：日 / 周 / 月，支持自定义日期范围。

**可视化图表**：
- 各设备在线率折线图（时间维度趋势）
- 各场景设备利用率对比柱状图
- 设备故障次数排名柱状图（Top 10）

---

### 3.2 任务完成情况报表

**指标说明**：

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| 任务总数 | COUNT(tasks) | 指定周期内创建的任务总数 |
| 按时完成率 | 按时完成数 ÷ 总完成数 × 100% | 实际结束时间 ≤ 计划结束时间则为按时 |
| 平均执行时长 | AVG(实际结束时间 - 实际开始时间) | 仅已完成任务参与统计 |

**可视化图表**：
- 任务状态分布饼图（待分配/已分配/执行中/已完成/已取消占比）
- 各场景任务数量对比柱状图
- 任务数量趋势折线图（按时间维度）

## 四、数据模型

统计报表数据从以下业务表汇总计算，不新增统计专用表：

| 数据来源 | 用途 |
|---------|------|
| `device_info` | 设备基础信息 |
| `device_fault_record` | 设备故障次数统计 |
| `task_info` | 任务数量、完成率统计 |
| `task_device_rel` | 设备任务占用时长计算 |
| `dispatch_log` | 操作记录辅助校验 |

> **注意**：当前版本设备在线时长依赖心跳记录计算，需确保心跳数据完整存储（在线期间每 5 分钟记录一次心跳）。

#### 设备统计概览

**说明**：获取设备利用率等核心指标概览数据

**鉴权**：需要 | **权限标识**：`stats:view`

```
GET /api/v1/statistics/device/overview?granularity=day&startDate=2026-05-20&endDate=2026-05-26
Authorization: Bearer {accessToken}

Query 参数：
- granularity  string  否   统计粒度：day/week/month，默认 day
- startDate    string  是   起始日期（yyyy-MM-dd）
- endDate      string  是   结束日期（yyyy-MM-dd），与 startDate 最大跨度 365 天

响应：
{
  "code": 200,
  "data": {
    "avgOnlineRate": 95.2,         // 平均在线率(%)
    "avgUtilizationRate": 68.5,    // 平均利用率(%)
    "totalFaultCount": 12,         // 总故障次数
    "totalDeviceCount": 50,        // 统计设备总数
    "dateRange": {
      "startDate": "2026-05-20",
      "endDate": "2026-05-26"
    }
  }
}
```

## 六、业务边界

### In Scope（本期做）
- ✅ 设备在线率、利用率统计图表
- ✅ 各场景设备利用率对比柱状图
- ✅ 设备故障次数统计
- ✅ 任务总数、完成率、状态分布统计
- ✅ 各场景任务数量对比
- ✅ 统计数据 Excel 导出

### Out of Scope（本期不做）
- ❌ 实时数据大屏（数据大屏另行设计）
- ❌ 预测分析（如：设备故障预测）
- ❌ 自定义报表模板

### 前置依赖
- 设备管理模块已运行一段时间，存在足够的心跳历史数据
- 任务管理模块已完成，存在任务历史数据

## 八、异常流程

| 异常场景 | 触发条件 | 处理方式 | 用户提示 |
|----------|----------|----------|----------|
| 查询日期范围过大 | startDate 到 endDate 超过 365 天 | 返回 400 | "查询时间范围不能超过 365 天" |
| 导出数据量过大 | 导出记录超过 10000 条 | 返回 422 | "数据量过大，请缩小查询范围" |
| 无历史数据 | 指定时间范围内无业务数据 | 返回空数据结构 | 图表展示"暂无数据" |

## 九、验收标准

**AC-001 设备利用率计算正确性**
- Given：设备在统计周期内在线 20 小时，执行任务 15 小时
- When：查看该设备的统计数据
- Then：在线率 = 20 ÷ 统计周期总时长 × 100%，利用率 = 15 ÷ 20 × 100% = 75%

**AC-002 任务按时完成率计算**
- Given：统计周期内完成 10 个任务，其中 8 个在计划时间内完成
- When：查看任务统计概览
- Then：按时完成率显示 80%

**AC-003 图表时间维度切换**
- Given：查看近 30 天的设备利用率趋势
- When：切换统计粒度从"日"改为"周"
- Then：趋势图 X 轴变为按周展示，数据聚合为周均值

**AC-004 报表导出内容完整**
- Given：查询近 7 天设备统计数据，有 30 台设备
- When：点击导出
- Then：下载 Excel 文件，包含 30 行设备数据，字段完整
  - And：文件名包含查询日期范围

**AC-005 空数据处理**
- Given：选择未来日期范围（无历史数据）
- When：查询统计报表
- Then：图表显示"暂无数据"，不报错
  - And：导出时提示"暂无可导出的数据"
