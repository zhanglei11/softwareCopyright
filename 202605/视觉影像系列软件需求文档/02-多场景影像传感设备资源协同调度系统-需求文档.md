# 多场景影像传感设备资源协同调度系统
## 软件需求文档 v1.0

---

## 一、系统概述

### 1.1 项目背景

在工业生产、安防监控、智慧园区等多元应用场景中，影像传感设备（工业相机、CMOS 传感器、深度相机等）往往分布在不同区域，执行不同任务。由于设备种类繁杂、任务需求动态变化，各设备之间缺乏统一的调度协调机制，导致资源利用率低、任务冲突频繁、响应时效差。多场景影像传感设备资源协同调度系统通过统一的设备注册、任务分配与调度引擎，实现多场景下影像设备的智能化协同管理。

### 1.2 系统目标

- 统一管理不同场景下的影像传感设备，实时掌握设备状态
- 支持任务创建与设备自动或手动匹配分配
- 提供可视化调度看板，监控任务执行进度
- 记录完整调度日志，支持历史任务回溯
- 集成用户权限管理，实现多角色分级访问控制

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** imaging-device-scheduler-web
- **后端仓库名：** imaging-device-scheduler
- **开发库名：** imaging_device_scheduler_dev

### 1.4 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 系统管理员 | 用户管理、权限配置、系统参数设置 |
| 调度管理员 | 场景配置、任务创建、设备分配调度 |
| 设备运维人员 | 设备注册、状态维护、故障上报 |
| 业务操作员 | 查看任务状态、查询调度记录 |

### 1.5 运行环境

- **客户端**：PC Web 浏览器（Chrome 90+、Edge 90+）
- **操作系统**：Windows 10 及以上
- **分辨率**：1920×1080 及以上

## 三、基础管理模块

### 3.1 用户管理

#### 3.1.1 功能描述

系统管理员对平台所有用户账号进行全生命周期管理。

#### 3.1.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 用户列表 | 分页展示用户，支持按姓名、账号、角色、状态筛选 |
| 新增用户 | 填写姓名、账号、手机号、部门、初始密码，绑定角色 |
| 编辑用户 | 修改用户基本信息及角色 |
| 禁用/启用 | 切换用户账号状态 |
| 重置密码 | 重置为系统默认初始密码 |
| 删除用户 | 逻辑删除，历史操作日志保留 |

#### 3.1.3 字段规则

- 登录账号：6~20 位字母数字，全局唯一
- 密码：8~20 位，须包含大小写字母与数字
- 手机号：11 位国内手机号格式校验

### 3.2 角色管理

| 功能项 | 描述 |
|--------|------|
| 角色列表 | 展示角色名称、标识、状态、关联用户数 |
| 新增角色 | 填写角色名称、标识、描述 |
| 角色授权 | 为角色分配菜单权限与按钮权限 |
| 删除角色 | 仅允许删除无绑定用户的角色 |

**内置角色：**

| 角色名称 | 标识 | 权限范围 |
|---------|------|---------|
| 超级管理员 | SUPER_ADMIN | 全部权限 |
| 调度管理员 | DISPATCH_ADMIN | 场景、设备、任务、调度全权限 |
| 设备运维 | DEVICE_OPS | 设备管理读写权限 |
| 业务操作员 | OPERATOR | 任务查询、调度记录只读 |

### 3.3 权限管理

采用 RBAC 模型，支持菜单级、按钮级权限控制。

| 权限层级 | 说明 |
|---------|------|
| 菜单权限 | 控制导航菜单的可见性 |
| 按钮权限 | 控制新增、编辑、删除、导出按钮的可见性 |
| 数据权限 | 运维人员只能管理本人注册的设备 |

### 3.4 菜单管理

| 功能项 | 描述 |
|--------|------|
| 菜单树展示 | 树形展示目录、菜单、按钮节点 |
| 新增菜单 | 选择节点类型，填写名称、路径、图标、排序号 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 仅可删除无子节点的叶子菜单 |

## 四、场景管理模块

### 4.1 场景信息维护

管理系统内各应用场景的基本信息，为设备与任务提供分类归属。

| 字段 | 说明 |
|------|------|
| 场景编号 | 唯一标识，系统自动生成 |
| 场景名称 | 如：产线 A 质检、仓库入库检验 |
| 场景类型 | 质量检测 / 安防监控 / 物料识别 / 其他 |
| 所属分组 | 场景分组归类 |
| 负责人 | 关联系统用户 |
| 场景描述 | 文字说明 |
| 状态 | 运行中 / 停用 |

**功能：** 新增场景、编辑场景、停用场景、场景列表查询（支持名称、类型、状态筛选）。

### 4.2 场景分组管理

对场景进行分组归类，便于批量管理与授权。

| 字段 | 说明 |
|------|------|
| 分组编号 | 唯一标识 |
| 分组名称 | 如：产线组、仓储组 |
| 包含场景数 | 只读，自动统计 |
| 备注 | 分组说明 |

## 五、设备管理模块

### 5.1 设备注册

将影像传感设备录入系统，建立设备档案。

| 字段 | 说明 |
|------|------|
| 设备编号 | 唯一标识，如 DEV-CAM-001 |
| 设备名称 | 显示名称 |
| 设备类型 | 工业相机 / 深度相机 / 线扫相机 / 其他 |
| 型号规格 | 设备型号信息 |
| 所属场景 | 设备当前归属的应用场景 |
| IP 地址 | 设备网络地址 |
| 安装位置 | 设备物理安装位置描述 |
| 注册人 | 执行注册操作的用户 |
| 注册时间 | 自动记录 |
| 状态 | 在线 / 离线 / 故障 / 维护中 |

**功能：** 新增设备、编辑设备信息、注销设备（逻辑删除）、设备列表查询（支持场景、类型、状态筛选）。

### 5.2 设备状态监控

实时展示所有设备的在线状态和运行情况。

- 设备状态总览卡片：在线数、离线数、故障数、维护中数量
- 设备列表实时刷新（手动刷新或定时刷新，刷新间隔可配置）
- 点击设备查看详情：最近心跳时间、当前任务、历史故障记录

### 5.3 设备参数配置

为设备配置运行参数模板，供任务调度时引用。

| 参数项 | 说明 |
|--------|------|
| 分辨率 | 如 1920×1080 |
| 帧率 | 如 30fps |
| 曝光时间 | 毫秒单位 |
| 增益值 | 数值型 |
| 参数备注 | 适用场景说明 |

## 六、任务管理模块

### 6.1 任务创建

创建影像采集或检测任务，并定义任务执行要求。

| 字段 | 说明 |
|------|------|
| 任务编号 | 系统自动生成，如 TASK-20260526-001 |
| 任务名称 | 描述性名称 |
| 所属场景 | 关联场景 |
| 任务类型 | 单次采集 / 周期采集 / 持续监控 |
| 计划开始时间 | 任务预计开始时间 |
| 计划结束时间 | 任务预计结束时间（持续监控可不填）|
| 所需设备数量 | 执行该任务需要的设备数量 |
| 设备类型要求 | 限定设备类型 |
| 优先级 | 高 / 中 / 低 |
| 任务描述 | 详细说明 |
| 创建人 | 自动记录当前用户 |
| 状态 | 待分配 / 已分配 / 执行中 / 已完成 / 已取消 |

### 6.2 任务分配

为任务分配合适的设备资源。

- **手动分配**：调度管理员从设备列表中手动选择设备分配给任务
- **查看可用设备**：系统自动过滤出满足任务条件（场景、类型、在线状态）的可用设备
- **分配操作**：选定设备后，确认分配，设备状态更新为"占用中"
- **取消分配**：任务结束或取消时，释放设备资源

### 6.3 任务进度查询

| 筛选条件 | 说明 |
|---------|------|
| 任务名称 | 模糊搜索 |
| 所属场景 | 下拉选择 |
| 任务状态 | 多选筛选 |
| 时间范围 | 计划开始时间范围 |
| 优先级 | 高/中/低筛选 |

**列表字段：** 任务编号、任务名称、场景、状态、优先级、计划时间、已分配设备数、操作

## 七、调度管理模块

### 7.1 调度看板

可视化展示当前所有任务与设备的调度状态。

- **任务状态概览**：待分配、执行中、已完成任务数量卡片
- **设备占用情况**：在线设备中空闲/占用数量比例
- **任务时间轴**：以甘特图形式展示各设备的任务安排（当日视图）
- **实时告警提示**：设备离线、任务超时等异常提醒

### 7.2 调度规则配置

配置设备调度的基本规则，辅助任务分配决策。

| 规则项 | 说明 |
|--------|------|
| 优先级规则 | 高优先级任务优先获得资源 |
| 同场景优先 | 任务优先分配同场景下的设备 |
| 任务超时告警时长 | 超出计划时间多少分钟触发告警 |
| 设备空闲阈值 | 空闲时间超过 N 分钟触发提醒 |

### 7.3 调度日志查询

记录每次任务与设备的分配、执行、完成、取消操作。

| 字段 | 说明 |
|------|------|
| 日志编号 | 自动生成 |
| 操作类型 | 分配 / 开始执行 / 完成 / 取消 / 故障中断 |
| 任务编号 | 关联任务 |
| 设备编号 | 关联设备 |
| 操作人 | 执行操作的用户 |
| 操作时间 | 时间戳 |
| 备注 | 操作说明 |

**功能：** 按任务、设备、时间范围、操作类型筛选查询，支持导出 Excel。

## 八、统计报表模块

### 8.1 设备利用率统计

| 指标 | 说明 |
|------|------|
| 设备在线率 | 在线时长 / 统计周期总时长 |
| 设备利用率 | 任务占用时长 / 在线时长 |
| 各场景设备利用率对比 | 柱状图 |

### 8.2 任务完成情况报表

| 指标 | 说明 |
|------|------|
| 任务总数 | 指定周期内创建任务数 |
| 按时完成率 | 在计划时间内完成的比例 |
| 任务状态分布 | 饼图 |
| 各场景任务数量对比 | 柱状图 |

**功能：** 查看图表、导出 Excel 报表。

## 九、非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 ≤ 3 秒；设备状态刷新延迟 ≤ 5 秒 |
| 安全 | JWT 认证、操作日志全量记录、密码加密存储 |
| 可用性 | 系统可用率 ≥ 99%；关键操作有确认提示 |
| 兼容性 | 支持 Chrome、Edge 主流版本 |
| 数据 | 调度日志保留 1 年；任务记录保留 2 年 |
