# 一致性分析模块 PRD

> 所属系统：视觉检测影像质量一致性管控系统
> 文档版本：V1.0 | 创建日期：2026-05-26

---

## 一、模块概述

一致性分析模块对完成的检测任务生成偏差分析报告，并支持跨时间段、跨检测对象的多维度质量对比，帮助质量工程师和管理人员定量掌握影像质量与标准的偏差情况，发现问题产线或相机。

---

## 二、功能清单

| 功能点 | 优先级 | 说明 | 涉及角色 |
|--------|--------|------|----------|
| 偏差分析报告查看 | P0 | 查看指定任务的一致性分析报告 | QUALITY_ENG, OPERATOR, MANAGER |
| 报告导出（PDF/Excel） | P1 | 导出分析报告 | QUALITY_ENG, MANAGER |
| 多任务横向对比 | P0 | 对比 2 个或多个任务的各指标均值差异 | QUALITY_ENG, MANAGER |
| 时间趋势对比 | P0 | 同一检测对象不同时期的质量变化折线图 | QUALITY_ENG, MANAGER |
| 检测对象横向对比 | P0 | 不同检测对象（相机/产线）同一指标对比柱状图 | QUALITY_ENG, MANAGER |

---

## 三、偏差分析报告内容

| 分析维度 | 说明 | 可视化形式 |
|---------|------|-----------|
| 各指标达标情况 | 每项质量指标的平均值及达标比例 | 表格 + 达标率百分比 |
| 偏差最大指标 TOP3 | 偏差最大的 3 个指标 | 排行卡片 |
| 不合格影像占比 | 不合格数 / 总检测数 | 仪表盘 / 数值卡片 |
| 偏差分布直方图 | 各指标测量值分布可视化 | 直方图（每指标一张） |
| 改善建议 | 根据偏差情况生成的文字说明 | 文字段落 |

## 四、多维度对比分析说明

### 4.1 多任务横向对比

- 用户选择 2～5 个已完成的检测任务
- 系统以指标为 X 轴，以各任务均值为系列，生成**分组柱状图**
- 展示表格：指标名称 | 任务A均值 | 任务B均值 | 差值 | 差值百分比

### 4.2 同一检测对象趋势图

- 用户选择 1 个检测对象，指定时间范围
- 系统以时间为 X 轴，以各指标合格率 / 均值为 Y 轴，生成**折线图**
- 支持选择展示具体指标（多选）

### 4.3 不同检测对象横向对比

- 用户选择多个检测对象、1 个指标维度、时间范围
- 系统以检测对象为 X 轴，以指标均值或合格率为 Y 轴，生成**柱状图**

### 5.2 多维度对比分析接口

#### 多任务横向对比

```
POST /api/v1/quality/analysis/compare/tasks
Authorization: Bearer {token}
Content-Type: application/json

{
  "taskIds": [1001, 1002, 1003],   // 2~5 个已完成任务 ID
  "metricIds": [1, 2, 3, 4]        // 可选，不传则对比全部指标
}

响应：
{
  "code": 200,
  "data": {
    "tasks": [
      { "taskId": 1001, "taskName": "产线A-5月", "detectionTarget": "产线A相机01" },
      { "taskId": 1002, "taskName": "产线A-4月", "detectionTarget": "产线A相机01" }
    ],
    "comparison": [
      {
        "metricId": 1,
        "metricName": "平均亮度",
        "unit": "灰度值",
        "standardMin": 80.0,
        "standardMax": 200.0,
        "taskValues": [
          { "taskId": 1001, "avgValue": 165.3, "qualifiedRate": 98.0 },
          { "taskId": 1002, "avgValue": 158.7, "qualifiedRate": 96.5 }
        ]
      }
    ]
  }
}
```

#### 同一检测对象时间趋势

```
GET /api/v1/quality/analysis/compare/trend?detectionTarget=&metricIds=&startDate=&endDate=&granularity=
Authorization: Bearer {token}

Query 参数：
- detectionTarget  string  是  检测对象标识
- metricIds        string  否  指标 ID，逗号分隔，不传则取全部
- startDate        string  是  开始日期 yyyy-MM-dd
- endDate          string  是  结束日期 yyyy-MM-dd
- granularity      string  否  day / week / month，默认 day

响应：
{
  "code": 200,
  "data": {
    "detectionTarget": "产线A相机01",
    "series": [
      {
        "metricId": 1,
        "metricName": "平均亮度",
        "dataPoints": [
          { "date": "2026-04-01", "avgValue": 160.2, "qualifiedRate": 97.0 },
          { "date": "2026-05-01", "avgValue": 165.3, "qualifiedRate": 98.0 }
        ]
      }
    ]
  }
}
```

#### 不同检测对象横向对比

```
GET /api/v1/quality/analysis/compare/targets?metricId=&startDate=&endDate=
Authorization: Bearer {token}

Query 参数：
- metricId    long    是  对比的指标 ID
- startDate   string  是  开始日期 yyyy-MM-dd
- endDate     string  是  结束日期 yyyy-MM-dd

响应：
{
  "code": 200,
  "data": {
    "metricName": "平均亮度",
    "unit": "灰度值",
    "standardMin": 80.0,
    "standardMax": 200.0,
    "targets": [
      { "detectionTarget": "产线A相机01", "avgValue": 165.3, "qualifiedRate": 98.0 },
      { "detectionTarget": "产线A相机02", "avgValue": 145.8, "qualifiedRate": 89.0 },
      { "detectionTarget": "产线B相机01", "avgValue": 172.1, "qualifiedRate": 99.2 }
    ]
  }
}
```

## 七、异常流程

| 异常场景 | 触发条件 | 处理方式 | 用户提示 |
|----------|----------|----------|----------|
| 查看未完成任务报告 | 任务状态不为"已完成" | 返回 422 | "任务尚未完成，暂无分析报告" |
| 多任务对比参数不足 | 传入 taskIds 少于 2 个 | 返回 400 | "至少选择 2 个任务进行对比" |
| 多任务对比超出限制 | 传入 taskIds 超过 5 个 | 返回 400 | "最多同时对比 5 个任务" |
| 导出超时 | 数据量大导出耗时 | 后台异步生成，推送下载链接 | "报告生成中，完成后自动下载" |
