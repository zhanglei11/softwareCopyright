# 跨场景影像传感数据融合与决策支持系统
## 软件需求文档 v1.0

---

## 一、系统概述

### 1.1 项目背景

在复杂工业环境中，单一场景的影像传感数据往往不足以支撑全面准确的业务决策。来自质检产线、仓储、物流、安防等多个场景的影像数据具有不同的采集维度和语义特征，需要跨场景融合才能形成整体认知。跨场景影像传感数据融合与决策支持系统通过统一接入多场景数据，配置融合策略与决策规则，为业务人员提供全景化的数据融合结果与辅助决策依据，提升企业的综合管控能力。

### 1.2 系统目标

- 统一接入多场景影像传感数据源，构建跨场景数据视图
- 支持融合规则与权重的灵活配置，实现数据的多维融合
- 提供决策规则管理，基于融合结果自动触发决策输出
- 展示融合结果与决策结论，支持历史追溯
- 集成用户权限管理，实现多角色分级访问控制

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** sensor-fusion-decision-support-web
- **后端仓库名：** sensor-fusion-decision-support
- **开发库名：** sensor_fusion_decision_support_dev

### 1.4 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 系统管理员 | 用户管理、权限配置、系统参数设置 |
| 融合配置工程师 | 配置数据源接入、融合规则、权重参数 |
| 决策分析员 | 查看融合结果、分析决策输出、导出报告 |
| 只读用户 | 查看融合结果与报表，不可修改配置 |

### 1.5 运行环境

- **客户端**：PC Web 浏览器（Chrome 90+、Edge 90+）
- **操作系统**：Windows 10 及以上
- **分辨率**：1920×1080 及以上

## 三、基础管理模块

### 3.1 用户管理

#### 3.1.1 功能描述

系统管理员对平台用户账号进行全生命周期管理。

#### 3.1.2 功能列表

| 功能项 | 描述 |
|--------|------|
| 用户列表 | 分页展示用户，支持按姓名、账号、角色、状态筛选 |
| 新增用户 | 填写姓名、账号、手机号、部门、初始密码，绑定角色 |
| 编辑用户 | 修改用户基本信息及关联角色 |
| 禁用/启用 | 切换账号状态，禁用后不可登录 |
| 重置密码 | 重置为系统默认初始密码 |
| 删除用户 | 逻辑删除，操作日志保留 |

#### 3.1.3 字段规则

- 登录账号：6~20 位字母数字，全局唯一
- 密码：8~20 位，须包含大小写字母与数字
- 手机号：11 位国内手机号格式校验

### 3.2 角色管理

| 功能项 | 描述 |
|--------|------|
| 角色列表 | 展示角色名称、标识、状态、关联用户数 |
| 新增角色 | 填写名称、标识、描述 |
| 角色授权 | 为角色分配菜单权限与按钮权限 |
| 删除角色 | 仅允许删除无绑定用户的角色 |

**内置角色：**

| 角色名称 | 标识 | 权限范围 |
|---------|------|---------|
| 超级管理员 | SUPER_ADMIN | 全部权限 |
| 融合配置工程师 | FUSION_ENG | 数据源、融合配置、决策规则全权限 |
| 决策分析员 | ANALYST | 融合结果、决策结果查询及导出 |
| 只读用户 | READONLY | 融合结果、报表只读查看 |

### 3.3 权限管理

采用 RBAC 模型，支持菜单级、按钮级权限控制。

| 权限层级 | 说明 |
|---------|------|
| 菜单权限 | 控制导航菜单的可见性 |
| 按钮权限 | 控制新增、编辑、删除、导出按钮的可见性 |

### 3.4 菜单管理

| 功能项 | 描述 |
|--------|------|
| 菜单树展示 | 树形展示目录、菜单、按钮节点 |
| 新增菜单 | 选择节点类型，填写名称、路径、图标、排序 |
| 编辑菜单 | 修改菜单信息 |
| 删除菜单 | 仅可删除无子节点的叶子菜单 |

## 四、数据源管理模块

### 4.1 场景数据源配置

配置各场景的影像传感数据接入来源，支持多场景并行接入。

| 字段 | 说明 |
|------|------|
| 数据源编号 | 系统自动生成 |
| 数据源名称 | 显示名称 |
| 所属场景 | 如：质检产线 / 仓储 / 物流 / 安防 |
| 数据源类型 | 设备直连 / 文件服务器 / 数据库 / 对象存储 |
| 连接地址 | IP 地址或 URL |
| 端口 | 连接端口号 |
| 认证方式 | 无认证 / 账号密码 / 密钥 |
| 数据字段映射 | 定义接入数据的字段与系统标准字段的映射关系 |
| 状态 | 启用 / 停用 |
| 备注 | 说明信息 |

**功能：** 新增数据源、编辑数据源、停用数据源、连通性测试。

### 4.2 数据源状态查看

- 展示所有场景数据源的接入状态（正常 / 异常）
- 显示最近一次数据更新时间
- 异常数据源提供告警标记

## 五、融合配置管理模块

### 5.1 融合方案管理

融合方案是融合规则与权重配置的集合，一个方案对应一种融合逻辑。

| 字段 | 说明 |
|------|------|
| 方案编号 | 系统自动生成 |
| 方案名称 | 描述性名称 |
| 参与场景 | 选择参与融合的场景（多选） |
| 融合目标 | 融合结果的业务说明 |
| 状态 | 启用 / 停用 |
| 创建人 | 自动记录 |
| 创建时间 | 自动记录 |

**功能：** 新增方案、编辑方案、停用方案、查看方案详情（含融合规则与权重配置）。

### 5.2 融合规则配置

在融合方案下，定义各场景数据参与融合的方式。

| 字段 | 说明 |
|------|------|
| 规则名称 | 描述性名称 |
| 所属方案 | 关联融合方案 |
| 融合类型 | 加权融合 / 投票融合 / 优先级融合 |
| 融合字段 | 指定参与融合的数据字段 |
| 触发条件 | 满足什么条件时触发本规则（如：所有场景均有数据）|
| 备注 | 规则说明 |

### 5.3 权重参数设置

为加权融合类型配置各场景数据源的权重值。

| 字段 | 说明 |
|------|------|
| 所属方案 | 关联融合方案 |
| 数据源 | 参与融合的数据源 |
| 权重值 | 0.0~1.0 之间的数值，所有数据源权重之和须为 1 |
| 调整原因 | 说明权重设置依据 |

**功能：** 编辑权重值，系统自动校验各数据源权重之和是否为 1。

## 六、决策规则管理模块

### 6.1 决策规则配置

基于融合结果定义决策触发条件与决策输出内容。

| 字段 | 说明 |
|------|------|
| 规则编号 | 系统自动生成 |
| 规则名称 | 描述性名称 |
| 关联融合方案 | 基于哪个融合方案的结果进行决策 |
| 触发条件 | 融合结果字段满足的条件表达式 |
| 决策输出 | 满足条件时输出的决策结论（文本描述）|
| 优先级 | 数值越小优先级越高 |
| 状态 | 启用 / 停用 |

### 6.2 决策条件维护

维护触发条件中使用的条件项，支持常用条件的复用。

| 字段 | 说明 |
|------|------|
| 条件名称 | 描述性名称 |
| 条件字段 | 作用于融合结果的哪个字段 |
| 比较运算符 | 大于 / 小于 / 等于 / 介于 / 包含 |
| 阈值 | 比较的目标值 |
| 说明 | 条件用途描述 |

## 七、融合结果查询模块

### 7.1 结果列表查询

查询历次融合任务执行后产生的融合结果。

| 筛选条件 | 说明 |
|---------|------|
| 融合方案 | 下拉选择 |
| 时间范围 | 融合执行时间范围 |
| 结果状态 | 成功 / 异常 |

**列表字段：** 结果编号、融合方案名称、执行时间、参与场景数、数据条数、结果状态、操作

### 7.2 结果详情查看

点击查看单次融合结果的详细内容。

- 展示参与融合的各场景原始数据摘要
- 展示融合后的综合数据字段与数值
- 展示已触发的决策结论（如有）
- 支持导出本次结果为 Excel

---

## 八、决策结果查询模块

### 8.1 决策结果列表

查询历次决策规则触发产生的决策结果。

| 筛选条件 | 说明 |
|---------|------|
| 决策规则 | 下拉选择 |
| 关联融合方案 | 下拉选择 |
| 时间范围 | 决策触发时间范围 |
| 决策输出关键字 | 模糊搜索 |

**列表字段：** 结果编号、规则名称、关联融合结果编号、触发时间、决策输出内容、操作

### 8.2 决策历史追溯

- 根据决策结果编号查看完整追溯链路：原始数据 → 融合结果 → 决策输出
- 支持按融合方案或时间段查看决策触发频次统计

## 九、报表分析模块

### 9.1 融合数据统计

| 指标 | 说明 |
|------|------|
| 融合执行次数 | 指定周期内各方案执行次数 |
| 成功率 | 融合成功次数 / 总执行次数 |
| 各场景数据贡献比例 | 饼图 |
| 融合执行量趋势 | 折线图，按日/周/月展示 |

### 9.2 决策结果分析

| 指标 | 说明 |
|------|------|
| 决策触发总次数 | 指定周期内触发次数 |
| 各决策规则触发频次排行 | 柱状图 |
| 决策输出类型分布 | 饼图 |
| 决策时效分析 | 从融合完成到决策输出的平均耗时 |

**功能：** 选择时间范围、选择融合方案，查看图表，支持导出 Excel 报表。
