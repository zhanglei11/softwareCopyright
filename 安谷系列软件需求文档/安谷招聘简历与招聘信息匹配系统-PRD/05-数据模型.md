# 五、数据模型

## 5.1 实体关系简图

```
sys_user ──── sys_user_role ──── sys_role ──── sys_role_menu ──── sys_menu
job_position ←─── job_application ───→ resume_main
                        │
                   interview_record
resume_main ──── resume_education
             ──── resume_work_exp
             ──── resume_skill
match_result(job_position → resume_main)
```

## 5.2 核心表字段定义

### sys_user（用户表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| username | VARCHAR(64) | 登录用户名，唯一 |
| real_name | VARCHAR(64) | 真实姓名 |
| phone | VARCHAR(20) | 手机号，唯一 |
| password | VARCHAR(255) | BCrypt 密文 |
| status | TINYINT | 0 禁用 1 启用 |
| error_count | INT | 连续密码错误次数 |
| locked_until | DATETIME | 锁定截止时间 |
| deleted | TINYINT | 0 正常 1 已删除 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

### sys_role（角色表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| role_name | VARCHAR(64) | 角色名称 |
| role_code | VARCHAR(64) | 角色标识，唯一 |
| builtin | TINYINT | 1=内置不可删除 |
| status | TINYINT | 0 禁用 1 启用 |
| remark | VARCHAR(255) | 备注 |

### sys_menu（菜单表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| parent_id | BIGINT | 父节点 id（0=根） |
| menu_type | TINYINT | 0 目录 1 菜单 2 按钮 |
| menu_name | VARCHAR(64) | 菜单名称 |
| path | VARCHAR(255) | 路由 path |
| perm_code | VARCHAR(128) | 权限标识 |
| icon | VARCHAR(64) | 图标 |
| sort | INT | 排序 |

### job_position（职位表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| title | VARCHAR(128) | 职位名称 |
| department | VARCHAR(64) | 所属部门 |
| job_type | VARCHAR(20) | FULL_TIME / PART_TIME / INTERN |
| location | VARCHAR(128) | 工作地点 |
| salary_min | INT | 薪资下限（元/月） |
| salary_max | INT | 薪资上限（元/月） |
| edu_require | VARCHAR(20) | 学历要求（枚举，见下） |
| exp_require | INT | 经验要求（年） |
| description | TEXT | 职位描述 |
| skill_tags | JSON | 技能标签列表 |
| status | VARCHAR(20) | DRAFT / OPEN / CLOSED |
| deleted | TINYINT | 逻辑删除 |
| creator_id | BIGINT | 创建人 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

**学历枚举（edu_require）：** `HIGH_SCHOOL < ASSOCIATE < BACHELOR < MASTER < DOCTOR`

### resume_main（简历主表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| name | VARCHAR(64) | 姓名 |
| phone | VARCHAR(20) | 手机 |
| email | VARCHAR(128) | 邮箱 |
| gender | TINYINT | 0 未知 1 男 2 女 |
| birth_date | DATE | 出生日期 |
| city | VARCHAR(64) | 居住城市 |
| desired_position | VARCHAR(128) | 期望职位 |
| desired_city | VARCHAR(64) | 期望城市 |
| desired_salary_min | INT | 期望薪资下限 |
| desired_salary_max | INT | 期望薪资上限 |
| job_status | VARCHAR(20) | 求职状态 |
| highest_edu | VARCHAR(20) | 最高学历（冗余字段，加速匹配） |
| total_exp_years | INT | 总工作年限（冗余，加速匹配） |
| file_path | VARCHAR(512) | 上传文件存储路径 |
| parse_success | TINYINT | 文件解析是否成功 |
| source | VARCHAR(20) | MANUAL / FILE / THIRD_PARTY |
| self_intro | TEXT | 自我介绍 |
| deleted | TINYINT | 逻辑删除 |
| creator_id | BIGINT | 录入人 |
| created_time | DATETIME | 创建时间 |

### job_application（投递记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| position_id | BIGINT | 职位 id（FK） |
| resume_id | BIGINT | 简历 id（FK） |
| status | VARCHAR(30) | 投递状态（见下） |
| operate_time | DATETIME | 最后一次状态变更时间 |
| operator_id | BIGINT | 操作人 |
| remark | VARCHAR(512) | 备注 |
| created_time | DATETIME | 投递创建时间 |

**投递状态枚举：** `PENDING → RESUME_PASSED / RESUME_REJECTED → INTERVIEW_WAITING → INTERVIEWING → INTERVIEW_PASSED / INTERVIEW_REJECTED → HIRED`

### interview_record（面试记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| application_id | BIGINT | 投递记录 id（FK） |
| interview_time | DATETIME | 面试时间 |
| interviewer | VARCHAR(64) | 面试官姓名 |
| location | VARCHAR(255) | 地点/链接 |
| score | TINYINT | 评分 1-5 |
| comment | TEXT | 评价内容 |
| result | VARCHAR(20) | PASS / REJECT |
| created_time | DATETIME | 创建时间 |

### match_result（匹配结果表，可作为临时缓存）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| position_id | BIGINT | 职位 id |
| resume_id | BIGINT | 简历 id |
| total_score | DECIMAL(5,2) | 综合分（0~100） |
| skill_score | DECIMAL(5,2) | 技能分 |
| edu_score | DECIMAL(5,2) | 学历分 |
| exp_score | DECIMAL(5,2) | 经验分 |
| matched_at | DATETIME | 匹配时间 |

### match_config（匹配规则配置表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键（全局唯一一条） |
| skill_weight | INT | 技能权重（默认 50） |
| edu_weight | INT | 学历权重（默认 30） |
| exp_weight | INT | 经验权重（默认 20） |
| updated_time | DATETIME | 最后修改时间 |
| updater_id | BIGINT | 修改人 |
