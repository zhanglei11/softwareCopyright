# 六、接口设计

## 6.0 通用规范

- **Base URL：** `/api`
- **认证：** 请求头 `Authorization: Bearer <accessToken>`（登录接口除外）
- **统一响应格式：**
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {}
  }
  ```
- **分页请求统一参数：** `page`（页码，从1起）、`size`（每页条数，默认20）
- **分页响应 data 结构：**
  ```json
  {
    "total": 100,
    "pages": 5,
    "list": []
  }
  ```

## 6.1 认证模块

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/login | 登录，返回 accessToken + refreshToken |
| POST | /api/auth/refresh | 刷新 token |
| POST | /api/auth/logout | 退出登录 |
| GET | /api/auth/me | 获取当前登录用户信息 |
