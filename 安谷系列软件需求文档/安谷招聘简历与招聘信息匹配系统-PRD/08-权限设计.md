# 八、权限设计

## 8.1 功能权限矩阵

| 功能模块 | 超级管理员 | HR 管理员 | 普通 HR |
|----------|-----------|-----------|---------|
| 用户管理 | 全部 | 无 | 无 |
| 角色管理 | 全部 | 无 | 无 |
| 菜单管理 | 全部 | 无 | 无 |
| 职位管理 | 全部 | 全部 | 仅查看 |
| 简历录入/上传 | 有 | 有 | 有 |
| 简历库管理 | 全部 | 全部 | 查看+编辑 |
| 简历导出 | 有 | 有 | 无 |
| 智能匹配 | 有 | 有 | 有 |
| 匹配规则配置 | 有 | 有 | 无 |
| 投递记录 | 有 | 有 | 有 |
| 面试管理 | 有 | 有 | 有 |
| 统计报表 | 有 | 有 | 无 |
| 报表导出 | 有 | 有 | 无 |

## 8.2 数据权限

| 角色 | 数据范围 |
|------|----------|
| 超级管理员 | 全部数据 |
| HR 管理员 | 全部数据 |
| 普通 HR | 本人录入的简历 + 分配给本人跟进的投递记录 |

## 8.3 权限标识规范

格式：`模块:资源:操作`

| 权限标识 | 说明 |
|----------|------|
| system:user:list | 用户列表查看 |
| system:user:add | 新增用户 |
| system:user:edit | 编辑用户 |
| system:user:delete | 删除用户 |
| job:job:publish | 发布职位 |
| job:job:close | 关闭职位 |
| resume:resume:add | 录入简历 |
| resume:resume:export | 简历导出 |
| match:match:execute | 执行匹配 |
| match:config:edit | 匹配规则配置 |
| stats:dashboard:view | 看板查看 |
| stats:report:export | 报表导出 |
