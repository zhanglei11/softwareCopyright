# 三、功能模块说明

## 3.1 基础管理模块

### 3.1.1 用户管理

| 功能点 | 说明 |
|--------|------|
| 用户列表 | 分页查询，支持按姓名/手机号/状态筛选 |
| 新增用户 | 填写姓名、用户名、手机号、初始密码、分配角色 |
| 编辑用户 | 修改姓名、手机号、状态、角色（用户名不可修改） |
| 删除用户 | 逻辑删除，删除前检查是否为当前登录账号 |
| 重置密码 | 管理员为指定用户生成新密码 |
| 账号启用/禁用 | 禁用后该账号无法登录 |

### 3.1.2 角色管理

| 功能点 | 说明 |
|--------|------|
| 角色列表 | 展示角色名、标识、状态、备注 |
| 新增角色 | 填写角色名、唯一标识、备注 |
| 角色授权 | 树形菜单多选，分配可见菜单及操作权限 |
| 删除角色 | 删除前检查是否有绑定用户，有则拒绝 |
| 内置角色 | SUPER_ADMIN 不可删除不可编辑标识 |

### 3.1.3 菜单管理

| 功能点 | 说明 |
|--------|------|
| 菜单树 | 以树形结构展示所有菜单及按钮权限 |
| 新增菜单 | 可选类型：目录/菜单/按钮，填写路由、图标、权限标识 |
| 编辑/删除 | 有子节点时不允许删除 |
| 排序 | 同层菜单支持拖拽排序（或输入 sort 字段） |

## 3.2 招聘管理模块（职位管理）

**职位状态流转：** `DRAFT（草稿）→ OPEN（发布）→ CLOSED（关闭）`

| 功能点 | 说明 |
|--------|------|
| 职位列表 | 分页，支持按名称/部门/状态/类型/学历/经验/薪资范围筛选 |
| 创建职位 | 填写职位名称、所属部门、岗位类型（全职/兼职/实习）、工作地点、薪资范围（min~max）、学历要求、工作经验要求、职位描述、技能标签列表 |
| 编辑职位 | DRAFT/OPEN 状态均可编辑 |
| 发布职位 | DRAFT → OPEN；CLOSED → OPEN（重新开放） |
| 关闭职位 | OPEN → CLOSED；关闭后不接收新投递 |
| 删除职位 | 仅 DRAFT 状态可删除（逻辑删除） |
| 职位详情 | 展示完整信息 + 已投递候选人人数 |

## 3.3 简历管理模块

### 3.3.1 结构化录入

手动填写候选人信息：
- 基本信息：姓名、手机、邮箱、性别、出生日期、居住城市
- 求职意向：期望职位、期望城市、期望薪资、求职状态
- 教育经历（多条）：学校、专业、学历、起止时间
- 工作经历（多条）：公司、职位、行业、起止时间、工作描述
- 技能列表：标签形式
- 自我介绍
- 来源渠道（手动录入/文件上传/第三方）

### 3.3.2 文件上传解析

- 支持格式：PDF、DOC、DOCX，大小 ≤ 10MB
- 上传后异步解析，解析结果自动回填表单
- 解析失败不阻断：保留文件引用，提示"解析失败，请手动填写"
- 解析成功字段：`parseSuccess: true`；失败：`parseSuccess: false`，`parseResult` 为空对象

### 3.3.3 简历库

| 功能点 | 说明 |
|--------|------|
| 简历列表 | 分页，支持多维度搜索：姓名/手机/学历/经验/技能标签/来源 |
| 简历详情 | 展示全部结构化信息 + 上传文件预览（PDF）/下载 |
| 编辑简历 | 任意字段可修改 |
| 删除简历 | 逻辑删除，关联投递记录保留并标记"简历已删除" |
| 导出简历 | 导出 Excel（HR_ADMIN 及以上） |

## 3.4 智能匹配模块

### 3.4.1 发起匹配

1. 用户选择一个 OPEN 状态的职位
2. 系统从简历库中取所有有效简历
3. 按匹配规则计算综合得分并排序
4. 返回候选人列表，每人展示：综合分、技能分、学历分、经验分
5. 支持一键将候选人创建投递记录（状态初始为"待筛选"）

**匹配维度权重（可配置）：**

| 维度 | 默认权重 | 匹配逻辑 |
|------|----------|----------|
| 技能匹配 | 50% | 候选人技能标签与职位技能标签交集 / 职位标签总数 |
| 学历匹配 | 30% | 候选人学历 ≥ 职位要求学历得满分；低一级别得 0.5；更低得 0 |
| 经验匹配 | 20% | 候选人经验年限 ≥ 要求年限得满分；线性插值计算不足部分 |

### 3.4.2 匹配规则配置

- HR_ADMIN 可调整三个维度权重（整数，合计必须 = 100）
- 保存前校验，不通过不保存
- 配置全局生效，立即影响下次匹配

## 3.5 招聘流程模块

### 3.5.1 投递记录

**投递状态流转：**
```
待筛选 → 简历通过 / 简历淘汰
简历通过 → 待面试
待面试 → 面试中
面试中 → 面试通过 / 面试淘汰
面试通过 → 已录用
```

| 功能点 | 说明 |
|--------|------|
| 投递列表 | 按职位/状态/创建时间筛选 |
| 创建投递 | 手动为简历+职位创建投递记录（状态=待筛选） |
| 状态变更 | HR 点击对应操作按钮触发合法状态流转 |
| 备注 | 每次状态变更可填写操作备注 |
| 操作日志 | 记录每次状态变更人、时间、备注 |

### 3.5.2 面试管理

| 功能点 | 说明 |
|--------|------|
| 面试列表 | 按投递记录展示，支持按面试时间/面试官/状态筛选 |
| 新增面试安排 | 选择投递、填写面试时间、面试官、面试地点/会议室/线上链接 |
| 面试评价 | 面试结束后填写评分（1-5分）、评价内容 |
| 面试结果 | 填写"通过/淘汰"并触发投递状态流转 |

## 3.6 统计报表模块

### 3.6.1 数据看板

| 卡片 | 数据 |
|------|------|
| 本月投递总数 | count |
| 本月简历通过率 | 通过/投递 |
| 本月面试完成数 | count |
| 本月录用数 | count |
| 招聘漏斗图 | 投递→通过→面试→录用各阶段人数 |
| 职位招聘进度 | 各 OPEN 职位已投递/目标招聘人数 |

### 3.6.2 来源统计

| 功能点 | 说明 |
|--------|------|
| 来源分布 | 按来源渠道（手动/文件/第三方）统计简历数量，饼图展示 |
| 时间筛选 | 支持按日/周/月/自定义区间筛选 |
| 漏斗分析 | 各来源渠道候选人投递→录用转化率对比 |
| 数据导出 | 导出 Excel（HR_ADMIN 及以上） |
