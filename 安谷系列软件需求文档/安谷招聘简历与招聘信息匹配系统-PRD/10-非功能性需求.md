# 十、非功能性需求

## 10.1 性能指标

| 指标 | 要求 |
|------|------|
| 列表页加载（<1000条） | P99 ≤ 1s |
| 简历文件解析 | P95 ≤ 5s |
| 智能匹配（<5000条简历） | P90 ≤ 3s |
| 并发用户 | 支持 50 人同时在线 |
| 文件存储单次上传上限 | 10MB |
| 支持文件格式 | PDF、DOC、DOCX |

## 10.2 安全要求

| 类别 | 要求 |
|------|------|
| 认证 | JWT 双 Token（accessToken 2h + refreshToken 7d） |
| 授权 | RBAC；未授权请求返回 403 |
| 密码 | BCrypt 加密存储；复杂度：8位+，大小写+数字+特殊字符 |
| 会话锁定 | 连续 5 次密码错误锁定 30 分钟 |
| OWASP | 防 SQL 注入（JPA 参数化）、XSS 过滤、CSRF Token |
| HTTPS | 生产环境强制 TLS 1.2+ |
| 敏感字段 | 手机号、身份证返回前端时部分脱敏 |

## 10.3 兼容性

| 维度 | 要求 |
|------|------|
| 浏览器 | Chrome / Edge / Firefox 最新版及向前 2 个主版本 |
| 分辨率 | 最低 1280×800 |
| 终端 | PC 端，不要求移动端适配 |

## 10.4 技术选型

| 层次 | 技术 |
|------|------|
| 后端框架 | Spring Boot 4.x |
| 数据库 | MySQL 9.x |
| 缓存 | Redis（会话/验证码/分布式锁） |
| 认证 | Spring Security 或 Sa-Token |
| 前端框架 | Vue 3 + Element Plus |
| 前端构建 | Vite |
| 文件解析 | Apache POI / PDFBox |
| 接口文档 | OpenAPI 3.0（Swagger UI） |
