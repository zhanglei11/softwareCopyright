## 一、项目概述

### 1.1 项目背景

随着企业招聘需求的快速增长，传统人工筛选简历方式效率低下、成本高昂，且主观性强，难以实现精准匹配。安谷招聘简历与招聘信息匹配系统旨在通过智能化手段，将求职者简历与企业招聘职位进行高效匹配，提升招聘效率，降低人力资源管理成本。

### 1.2 项目目标

- 构建统一的招聘信息管理平台，支持职位的发布与管理
- 实现简历的在线录入、上传与结构化存储
- 提供智能匹配引擎，自动对简历与职位进行相似度评分
- 覆盖完整的招聘业务流程，从投递到录用全程可追踪
- 提供数据统计与分析能力，辅助招聘决策

### 1.3 系统定位

- **客户端类型：** PC端 Web 应用
- **前端仓库名：** angu-resume-job-matcher-web
- **后端仓库名：** angu-resume-job-matcher
- **开发库名：** angu_resume_job_matcher_dev
- **目标用户：** HR专员、招聘负责人、系统管理员
- **运行环境：** 主流浏览器（Chrome、Edge、Firefox）

## 三、功能模块详细说明

### 3.1 基础管理模块

#### 3.1.1 用户管理

**功能描述：** 对系统使用人员进行统一管理，支持用户的增删改查及状态控制。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 用户列表 | 分页展示所有用户，支持按姓名、账号、状态筛选 |
| 新增用户 | 填写用户基本信息（姓名、账号、手机号、邮箱、所属部门、角色） |
| 编辑用户 | 修改用户基本信息及角色分配 |
| 删除用户 | 逻辑删除，保留历史数据 |
| 启用/禁用 | 控制用户登录权限，禁用后无法登录系统 |
| 重置密码 | 管理员可为用户重置初始密码 |

**字段说明：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 用户姓名 | 文本 | 是 | 最长20字符 |
| 登录账号 | 文本 | 是 | 唯一，字母数字组合，6-20位 |
| 登录密码 | 文本 | 是 | 加密存储，8位以上 |
| 手机号码 | 文本 | 是 | 11位手机号 |
| 邮箱地址 | 文本 | 否 | 标准邮箱格式 |
| 所属部门 | 下拉 | 否 | 关联部门数据 |
| 用户角色 | 多选 | 是 | 关联角色列表 |
| 用户状态 | 枚举 | 是 | 启用/禁用，默认启用 |

#### 3.1.2 角色管理

**功能描述：** 定义系统角色，将权限集合绑定到角色，再将角色分配给用户，实现基于角色的访问控制（RBAC）。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 角色列表 | 展示系统所有角色及其描述 |
| 新增角色 | 填写角色名称、描述，并分配菜单权限 |
| 编辑角色 | 修改角色信息及权限配置 |
| 删除角色 | 删除未绑定用户的角色 |
| 权限分配 | 通过树形结构勾选菜单与功能操作权限 |

**预设角色：**

| 角色名称 | 说明 |
|----------|------|
| 超级管理员 | 拥有全部权限，系统内置，不可删除 |
| HR管理员 | 负责招聘流程的全面管理 |
| 普通HR | 负责简历筛选与面试安排 |

#### 3.1.3 权限管理

**功能描述：** 对系统功能操作权限进行细粒度控制，权限粒度精确到按钮级别。

**权限类型：**

| 权限类型 | 说明 |
|----------|------|
| 菜单权限 | 控制用户可见的菜单项 |
| 操作权限 | 控制用户可执行的操作（新增、编辑、删除、导出等） |
| 数据权限 | 控制用户可查看的数据范围（本人/本部门/全部） |

#### 3.1.4 菜单管理

**功能描述：** 对系统导航菜单进行动态配置，支持多级菜单结构。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 菜单列表 | 树形结构展示所有菜单 |
| 新增菜单 | 配置菜单名称、图标、路径、排序、父级菜单 |
| 编辑菜单 | 修改菜单配置信息 |
| 删除菜单 | 删除无子菜单的菜单项 |
| 菜单排序 | 拖拽或输入序号调整菜单显示顺序 |

**菜单字段：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 菜单名称 | 文本 | 显示在导航栏的名称 |
| 菜单类型 | 枚举 | 目录/菜单/按钮 |
| 菜单图标 | 图标选择 | 对应前端图标库 |
| 路由地址 | 文本 | 前端路由路径 |
| 权限标识 | 文本 | 后端权限校验标识符 |
| 显示排序 | 数字 | 同级菜单排序值 |
| 是否显示 | 枚举 | 显示/隐藏 |

### 3.2 招聘管理模块

#### 3.2.1 职位管理

**功能描述：** 管理企业对外发布的招聘职位信息，支持职位全生命周期管理。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 职位列表 | 分页展示职位，支持按部门、状态、职位名称筛选 |
| 发布职位 | 填写职位详细信息并发布 |
| 编辑职位 | 修改已有职位信息 |
| 关闭职位 | 停止招聘，不再接收投递 |
| 复制职位 | 基于已有职位快速创建相似职位 |
| 删除职位 | 删除草稿状态职位 |

**职位信息字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 职位名称 | 文本 | 是 | 如：Java高级工程师 |
| 所属部门 | 下拉 | 是 | 用人部门 |
| 工作地点 | 文本 | 是 | 城市/具体地址 |
| 招聘人数 | 数字 | 是 | 本次招聘名额 |
| 薪资范围 | 区间 | 否 | 月薪范围，如：15K-25K |
| 学历要求 | 下拉 | 是 | 大专/本科/硕士/博士/不限 |
| 工作年限 | 下拉 | 是 | 应届/1-3年/3-5年/5年以上/不限 |
| 职位类型 | 下拉 | 是 | 全职/兼职/实习 |
| 技能标签 | 多选标签 | 否 | 如：Java、Spring Boot、MySQL |
| 岗位职责 | 富文本 | 是 | 详细描述工作内容 |
| 任职要求 | 富文本 | 是 | 详细描述任职条件 |
| 有效期至 | 日期 | 否 | 职位截止日期 |
| 职位状态 | 枚举 | 是 | 草稿/招聘中/已关闭 |

### 3.3 简历管理模块

**功能描述：** 提供在线表单，手动录入候选人简历信息，适用于线下收集的简历数字化。

**简历信息字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 姓名 | 文本 | 是 | |
| 性别 | 枚举 | 是 | 男/女 |
| 出生年月 | 日期 | 否 | |
| 手机号码 | 文本 | 是 | |
| 邮箱地址 | 文本 | 否 | |
| 现居城市 | 文本 | 否 | |
| 最高学历 | 下拉 | 是 | |
| 毕业院校 | 文本 | 否 | |
| 专业方向 | 文本 | 否 | |
| 工作年限 | 数字 | 否 | 单位：年 |
| 期望职位 | 文本 | 否 | |
| 期望薪资 | 文本 | 否 | |
| 技能标签 | 多选标签 | 否 | |
| 工作经历 | 动态列表 | 否 | 公司、职位、时间、描述 |
| 教育经历 | 动态列表 | 否 | 学校、专业、时间、学历 |

#### 3.3.2 简历上传

**功能描述：** 支持上传 PDF、Word 格式简历文件，系统自动解析基本信息并填充表单。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 文件上传 | 支持 .pdf、.doc、.docx 格式，单文件不超过10MB |
| 信息解析 | 自动提取姓名、手机、邮箱、学历等关键字段 |
| 人工校验 | 解析完成后展示预填结果，允许人工修正后保存 |
| 原件预览 | 保留原始附件，支持在线预览 |

#### 3.3.3 简历库管理

**功能描述：** 对所有已入库简历进行统一管理与检索。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 简历列表 | 分页展示，支持多条件筛选 |
| 简历详情 | 查看完整简历信息及附件 |
| 编辑简历 | 修改简历信息 |
| 删除简历 | 逻辑删除 |
| 简历导出 | 导出简历信息为 Excel |
| 添加备注 | 为简历添加内部评价标签与备注 |

**简历筛选条件：**

- 姓名关键字、手机号
- 学历、工作年限
- 期望职位、技能标签
- 简历来源
- 录入时间范围

### 3.4 智能匹配模块

#### 3.4.1 匹配功能

**功能描述：** 基于职位要求与简历信息的关键维度进行相似度计算，自动生成匹配分数，辅助HR快速筛选候选人。

**匹配维度：**

| 维度 | 权重说明 |
|------|----------|
| 学历匹配 | 候选人学历是否满足职位要求 |
| 工作年限匹配 | 工作经验年限与职位要求的符合程度 |
| 技能标签匹配 | 候选人技能与职位技能标签的重合率 |
| 期望职位匹配 | 候选人期望职位与招聘职位的相关度 |
| 薪资匹配 | 候选人期望薪资与职位薪资范围的吻合度 |

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 职位找简历 | 选定职位后，从简历库中推荐匹配候选人列表，按分数排序 |
| 简历找职位 | 选定简历后，推荐最匹配的在招职位列表 |
| 匹配分数 | 展示综合匹配分（0-100分），并细化各维度得分 |
| 筛选过滤 | 支持设置最低匹配分阈值过滤结果 |

#### 3.4.2 匹配规则配置

**功能描述：** 管理员可调整各匹配维度的权重，优化匹配算法效果。

| 功能点 | 说明 |
|--------|------|
| 权重配置 | 设置各维度匹配的权重比例，总和为100% |
| 一键重置 | 恢复默认权重配置 |

### 3.5 招聘流程模块

#### 3.5.1 投递记录

**功能描述：** 记录候选人对职位的投递信息，追踪招聘进度。

**功能清单：**

| 功能点 | 说明 |
|--------|------|
| 投递列表 | 展示所有投递记录，支持按职位、状态筛选 |
| 创建投递 | 将简历关联到指定职位，开始招聘流程 |
| 状态流转 | 手动推进招聘状态 |
| 备注记录 | 记录每次状态变更的原因与备注 |

**投递状态流转：**

```
待筛选 → 简历通过 → 待面试 → 面试中 → 面试通过 → 已录用
         ↓                              ↓
       简历淘汰                       面试淘汰
```

#### 3.5.2 面试管理

**功能描述：** 安排与记录候选人的面试信息。

| 功能点 | 说明 |
|--------|------|
| 安排面试 | 设置面试时间、地点、面试官 |
| 面试记录 | 填写面试评价与结论 |
| 面试提醒 | 页面通知提醒面试时间 |

**面试记录字段：**

| 字段名 | 说明 |
|--------|------|
| 面试类型 | 初试/复试/终试/HR面 |
| 面试时间 | 具体日期与时间 |
| 面试官 | 关联系统用户 |
| 面试地点 | 线下地址 或 线上会议链接 |
| 综合评分 | 1-5星评分 |
| 面试评价 | 文字描述面试情况 |
| 面试结论 | 通过/淘汰/待定 |

## 四、非功能性需求

### 4.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面响应时间 | 普通列表页面 ≤ 2秒 |
| 文件上传速度 | 10MB文件上传 ≤ 30秒 |
| 并发用户数 | 支持50个用户同时在线 |

### 4.2 安全需求

| 要求 | 说明 |
|------|------|
| 身份认证 | 账号密码登录，支持验证码防暴力破解 |
| 会话管理 | 登录 Token 过期时间可配置，默认8小时 |
| 密码安全 | 密码加密存储（BCrypt），强制8位以上含字母数字 |
| 操作日志 | 记录关键操作日志（登录、数据变更、导出等） |
| 数据权限 | 按角色控制数据访问范围 |

### 4.3 兼容性需求

| 浏览器 | 版本要求 |
|--------|----------|
| Chrome | 最新版及往前2个主版本 |
| Edge | 最新版及往前2个主版本 |
| Firefox | 最新版及往前2个主版本 |
