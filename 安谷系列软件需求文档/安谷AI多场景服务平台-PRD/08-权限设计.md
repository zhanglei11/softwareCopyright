# 八、权限设计

## 8.1 功能权限矩阵

| 功能模块 | 超级管理员 | AI 管理员 | 普通用户 |
|----------|-----------|-----------|---------|
| 用户管理 | 全部 | 无 | 无 |
| 角色管理 | 全部 | 无 | 无 |
| 菜单管理 | 全部 | 无 | 无 |
| 场景分类管理 | 全部 | 全部 | 无 |
| 场景配置（CRUD/上下架） | 全部 | 全部 | 无 |
| 场景广场（查看/收藏） | 有 | 有 | 有（仅已授权场景） |
| 智能对话 | 有 | 有 | 有 |
| 文档分析 | 有 | 有 | 有 |
| 内容生成 | 有 | 有 | 有 |
| 知识库管理 | 全部 | 全部 | 无 |
| AI 模型配置 | 全部 | 全部 | 无 |
| 本人历史会话 | 有 | 有 | 有 |
| 全体用户会话 | 有 | 有 | 无 |
| 统计报表 | 有 | 有 | 无 |
| 报表导出 | 有 | 有 | 无 |

## 8.2 数据权限

| 角色 | 数据范围 |
|------|----------|
| 超级管理员 | 全部数据 |
| AI 管理员 | 全部数据（含所有用户会话记录） |
| 普通用户 | 仅本人发起的会话记录；仅已授权场景 |

## 8.3 场景级权限

- 场景权限绑定在角色上（`sys_role_scene` 关联表）
- 普通用户只能看到其角色被授权的已上架场景
- 超级管理员和 AI 管理员默认可使用全部已上架场景
