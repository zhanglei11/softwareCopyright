# 七、异常流程

| 场景 | HTTP 状态码 | 处理逻辑 |
|------|------------|----------|
| 账号或密码错误 | 401 | 提示"账号或密码不正确"，返回剩余错误次数 |
| 连续错误 ≥ 5 次 | 423 | 账号锁定 30 分钟，提示"账号已锁定，请 30 分钟后重试" |
| Access Token 过期 | 401 | 前端自动用 refreshToken 换新 token |
| Refresh Token 过期/无效 | 401 | 前端跳转登录页 |
| 账号被禁用 | 423 | 登录时提示"账号已被禁用，请联系管理员" |
| 验证码错误 | 400 | 提示"验证码不正确"，刷新验证码 |
| 每日调用超限额 | 429 | 提示"今日调用次数已达上限（N 次），请明日再试" |
| 调用已下架场景 | 403 | 提示"该场景已下架，无法使用" |
| 无权限使用该场景 | 403 | 提示"您没有使用该场景的权限" |
| AI 模型接口超时（>30s） | 504 | 提示"AI 服务响应超时，请稍后重试"，记录失败日志 |
| AI 模型接口返回错误 | 502 | 提示"AI 服务暂时不可用，请稍后重试"，记录错误信息 |
| 文件格式不支持 | 400 | 提示"仅支持 PDF、DOC、DOCX、TXT 格式" |
| 文件大小超限（>20MB） | 400 | 提示"文件大小不能超过 20MB" |
| 文档解析失败 | 200 | 不阻断流程，标记 FAILED，提示"文档解析失败，可重试" |
| 知识库被场景引用时删除 | 409 | 提示"该知识库被 N 个场景引用，请先解除关联" |
| 删除有子节点菜单 | 400 | 提示"请先删除子菜单" |
| 删除有绑定用户的角色 | 409 | 提示"该角色下有 N 个用户，请先解绑用户" |
| 连通性测试失败 | 200 | 返回 `{success: false, message: "xxx error"}`，不抛异常 |
| 服务器内部错误 | 500 | 提示"系统异常，请联系管理员"，记录完整错误堆栈 |
