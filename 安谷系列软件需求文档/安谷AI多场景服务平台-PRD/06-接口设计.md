# 六、接口设计

## 6.0 通用规范

- **Base URL：** `/api`
- **认证：** 请求头 `Authorization: Bearer <accessToken>`（登录接口除外）
- **统一响应格式：**
  ```json
  { "code": 200, "message": "success", "data": {} }
  ```
- **分页请求通用参数：** `page`（从1起）、`size`（默认20）
- **分页响应 data：** `{ "total": 100, "pages": 5, "list": [] }`
- **流式输出（智能对话/内容生成）：** 使用 SSE（`text/event-stream`），每帧格式 `data: {"delta": "...", "done": false}`，结束帧 `data: {"done": true}`

## 6.1 认证模块

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/auth/captcha | 获取图形验证码（Base64 图片 + captchaKey） |
| POST | /api/auth/login | 登录，Body: `{username, password, captchaKey, captchaCode}` |
| POST | /api/auth/refresh | 刷新 Token，Body: `{refreshToken}` |
| POST | /api/auth/logout | 退出登录 |
| GET | /api/auth/me | 获取当前登录用户信息（含权限/场景列表） |
| PUT | /api/auth/password | 当前用户修改密码 |
