## 技术栈速览

| 层次 | 技术 |
|------|------|
| 前端 | Vue 3 + Element Plus + Vite |
| 后端 | Spring Boot 3.x |
| 数据库 | MySQL 8.0 |
| 向量数据库 | Milvus / Chroma |
| 缓存 | Redis |
| 文件存储 | 本地存储 / 阿里云 OSS |
| AI接入层 | LangChain4j / Spring AI |
| 权限框架 | Sa-Token |
