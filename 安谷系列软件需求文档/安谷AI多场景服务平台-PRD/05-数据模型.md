# 五、数据模型

## 5.1 实体关系简图

```
sys_user ────── sys_user_role ────── sys_role ────── sys_role_menu ────── sys_menu
    │                                    │
    │                              sys_role_scene
    │                                    │
    └──── ai_conversation ──────> ai_scene ─────────> ai_model_config
              │                      │
         ai_message            kb_knowledge_base ──── kb_document
                                                           │
                                                    (向量数据库: Milvus)
ai_call_log (统计来源)
```

## 5.2 核心表字段定义

### sys_user（用户表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| username | VARCHAR(32) | 登录账号，唯一 |
| real_name | VARCHAR(64) | 真实姓名 |
| phone | VARCHAR(20) | 手机号，唯一 |
| email | VARCHAR(128) | 邮箱 |
| department | VARCHAR(64) | 所属部门 |
| password | VARCHAR(255) | BCrypt 密文 |
| daily_limit | INT | 每日调用限额，NULL 不限制 |
| status | TINYINT | 0 禁用 / 1 启用 |
| error_count | INT | 连续密码错误次数，默认 0 |
| locked_until | DATETIME | 锁定截止时间 |
| deleted | TINYINT | 0 正常 / 1 已删除 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

### sys_role（角色表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| role_name | VARCHAR(64) | 角色名称 |
| role_code | VARCHAR(64) | 角色标识，唯一 |
| builtin | TINYINT | 1=内置不可删除 |
| status | TINYINT | 0 禁用 / 1 启用 |
| description | VARCHAR(255) | 描述 |

### ai_scene_category（场景分类表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| name | VARCHAR(64) | 分类名称 |
| icon | VARCHAR(128) | 图标 |
| sort | INT | 排序 |
| deleted | TINYINT | 逻辑删除 |

### ai_scene（AI 场景表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| name | VARCHAR(128) | 场景名称 |
| category_id | BIGINT | 分类 id（FK） |
| icon | VARCHAR(512) | 场景图标 |
| description | VARCHAR(512) | 场景描述 |
| usage_guide | TEXT | 使用说明（富文本） |
| model_id | BIGINT | 关联模型 id（FK） |
| kb_id | BIGINT | 关联知识库 id（FK，可 NULL） |
| system_prompt | TEXT | 系统提示词 |
| user_prompt_tpl | TEXT | 用户提示词模板 |
| input_variables | JSON | 输入变量定义列表 |
| max_tokens | INT | 最大输出 Token，默认 2048 |
| temperature | DECIMAL(3,2) | 温度参数，默认 0.70 |
| multi_turn | TINYINT | 0 单轮 / 1 多轮 |
| status | VARCHAR(20) | DRAFT / ONLINE / OFFLINE |
| deleted | TINYINT | 逻辑删除 |
| creator_id | BIGINT | 创建人 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

### ai_model_config（AI 模型配置表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| model_name | VARCHAR(128) | 显示名称 |
| model_id | VARCHAR(128) | API model ID |
| provider | VARCHAR(32) | 服务提供商枚举 |
| api_url | VARCHAR(512) | API 地址 |
| api_key_encrypted | VARCHAR(512) | AES 加密存储的密钥 |
| max_context_tokens | INT | 最大上下文长度 |
| status | TINYINT | 0 禁用 / 1 启用 |
| remark | VARCHAR(255) | 备注 |
| created_time | DATETIME | 创建时间 |

### ai_conversation（会话表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| user_id | BIGINT | 用户 id（FK） |
| scene_id | BIGINT | 场景 id（FK，NULL 表示通用对话） |
| title | VARCHAR(255) | 会话标题（首条消息截取或手动命名） |
| deleted | TINYINT | 逻辑删除 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 最后消息时间 |

### ai_message（消息表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| conversation_id | BIGINT | 会话 id（FK） |
| role | VARCHAR(20) | USER / ASSISTANT / SYSTEM |
| content | TEXT | 消息内容（Markdown） |
| token_count | INT | 本条消息 Token 数 |
| created_time | DATETIME | 消息时间 |

### ai_call_log（AI 调用日志表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| user_id | BIGINT | 用户 id |
| scene_id | BIGINT | 场景 id |
| model_id | BIGINT | 模型 id |
| conversation_id | BIGINT | 会话 id |
| prompt_tokens | INT | 输入 Token 数 |
| completion_tokens | INT | 输出 Token 数 |
| total_tokens | INT | 总 Token 数 |
| latency_ms | INT | 首字延迟（毫秒） |
| success | TINYINT | 0 失败 / 1 成功 |
| error_msg | VARCHAR(512) | 错误信息 |
| call_time | DATETIME | 调用时间 |

### kb_knowledge_base（知识库表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| name | VARCHAR(128) | 知识库名称 |
| description | VARCHAR(512) | 描述 |
| doc_count | INT | 文档数量（冗余统计） |
| deleted | TINYINT | 逻辑删除 |
| creator_id | BIGINT | 创建人 |
| created_time | DATETIME | 创建时间 |

### kb_document（知识库文档表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| kb_id | BIGINT | 知识库 id（FK） |
| file_name | VARCHAR(255) | 原始文件名 |
| file_path | VARCHAR(512) | 存储路径 |
| file_size | BIGINT | 文件大小（字节） |
| file_type | VARCHAR(20) | pdf / docx / txt / md |
| parse_status | VARCHAR(20) | PENDING / PROCESSING / DONE / FAILED |
| chunk_count | INT | 切分片段数 |
| error_msg | VARCHAR(512) | 解析失败原因 |
| deleted | TINYINT | 逻辑删除 |
| created_time | DATETIME | 上传时间 |

### user_scene_favorite（场景收藏表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| user_id | BIGINT | 用户 id |
| scene_id | BIGINT | 场景 id |
| created_time | DATETIME | 收藏时间 |
